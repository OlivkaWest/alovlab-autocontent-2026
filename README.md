# Автоконтент 2026 — лендинг AlovLab

Одностраничный сайт бесплатного практического интенсива AlovLab **«Автоконтент 2026»**:
как собрать ИИ-контент-завод для бизнеса — программа, материалы, регистрация и полезные ссылки.

Это статический сайт (HTML + CSS + JavaScript, без сборки и зависимостей). Его можно
открыть локально, положить на любой хостинг или опубликовать на домене AlovLab.

## Быстрый старт

```bash
# из корня проекта — локальный предпросмотр
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Открывать `index.html` двойным кликом (протокол `file://`) не рекомендуется:
браузер блокирует загрузку локальных шрифтов по CORS. Через любой веб-сервер всё работает.

## Что нужно сделать владельцу перед публикацией

Три обязательных шага (подробности — в [`docs/README.md`](docs/README.md)):

1. **Ссылка на регистрацию.** В `js/main.js` заполните `CONFIG.REGISTRATION_URL`
   **или** подключите приём формы через `CONFIG.FORM_ENDPOINT` (webhook / Telegram-бот / CRM).
2. **Фото Ильи Алова.** Положите файл `assets/img/ilya-alov.jpg` и раскомментируйте `<img>`
   в блоке «Об авторе» (см. инструкцию в docs).
3. **Политика конфиденциальности + аналитика.** Заполните `CONFIG.PRIVACY_URL` и вставьте
   счётчики (Яндекс.Метрика / VK Pixel) в функцию `track()`.

Всё остальное (тексты, программа, материалы, ссылки на соцсети) уже готово и проверено.

## Структура проекта

```
.
├── index.html                     # весь контент страницы (семантическая разметка)
├── css/styles.css                 # дизайн-система и адаптив
├── js/main.js                     # интерактив, настройки владельца (CONFIG), аналитика
├── assets/
│   ├── img/
│   │   ├── logo.svg               # логотип-заглушка (заменить на официальный)
│   │   ├── favicon.svg            # favicon из логотипа
│   │   └── og-image.png           # превью для соцсетей (1200×630)
│   ├── fonts/                     # Manrope (self-hosted, латиница + кириллица)
│   └── pdf/
│       ├── startovy-gayd-avtokontent-2026.pdf     # Стартовый гайд (скачивается)
│       └── rabochaya-tetrad-avtokontent-2026.pdf  # Рабочая тетрадь (скачивается)
├── scripts/build_pdfs.py          # генератор PDF-материалов (reportlab)
└── docs/README.md                 # полная документация, отчёты и инструкции
```

## Пересборка PDF-материалов

PDF собраны из подтверждённого содержания методички. Чтобы изменить и пересобрать:

```bash
pip install reportlab
python3 scripts/build_pdfs.py
```

## Публикация на домене AlovLab

Сайт статический — подойдёт любой способ.

**GitHub Pages (текущий способ).** Сайт уже в ветке `main`. Включите Pages один раз:
Settings → Pages → Source: **Deploy from a branch** → Branch `main`, папка `/ (root)` → Save.
Через минуту сайт будет на **https://olivkawest.github.io/alovlab-autocontent-2026/**
и станет пересобираться при каждом пуше в `main`.

**Свой домен alovlab.ru.** Скопировать содержимое папки в корень сайта (nginx) или
привязать домен к GitHub Pages. Полная инструкция — в [`docs/README.md`](docs/README.md).
