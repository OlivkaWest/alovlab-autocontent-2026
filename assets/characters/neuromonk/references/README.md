# Референсы Нейромонаха

Сюда кладутся **утверждённые** фотографии/кадры персонажа (лицо, ракурсы, одежда).
Именно по ним сверяется каждый сгенерированный кадр (`../approved/`, `../rejected/`).

Пока папка пустая — реальных референсов в проекте нет. Идентичность держится на:
1. постоянном HeyGen avatar (`HEYGEN_AVATAR_ID`),
2. правилах из `../CHARACTER.md` и `../visual_rules.json`.

Soul ID (Higgsfield) и обучение новой identity-модели — только по отдельной команде.
Не заполняй `reference_index.json` выдуманными файлами.
