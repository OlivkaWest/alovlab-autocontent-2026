# Библиотека форматов

Готовые структуры под каждый тип текста. Голос и запреты — в SKILL.md, соблюдать всегда.
Каждая структура — это скелет, а не шаблон для копирования. Наполняй живой речью.

---

## Пост для соцсетей (Telegram / VK)

1. **Хук** — первый абзац цепляет (см. `hooks.md`).
2. **Ситуация** — короткий контекст, чтобы читатель узнал себя.
3. **Одна сильная мысль** — ядро поста. Только одна.
4. **Пример** — из практики, с конкретной деталью.
5. **Применение** — что сделать читателю уже сегодня.
6. **Естественный призыв** — без давления. Не вопросом каждый раз.

Длина: столько, сколько нужно мысли. Обычно 800–1500 знаков. Абзацы разной длины.

---

## Сценарий для reels / короткого видео

Формат — по секундам, потому что удержание решает всё.

- **0–2 сек — крючок.** Фраза или кадр, после которого нельзя пролистнуть. Никаких «привет, друзья».
- **2–8 сек — проблема.** Назови боль конкретно.
- **8–25 сек — один приём.** Ровно один. Показать, а не рассказать.
- **25–35 сек — результат.** Что меняется, если применить.
- **финал — CTA.** Подписка / сохранить / прийти на интенсив. Спокойно, одной строкой.

Пиши сценарий двумя колонками смысла: **что говорим** (закадр/реплика) и **что в кадре** (действие/текст на экране).

## Продающий текст

Формула: **контекст → проблема → гипотеза → решение → простой следующий шаг.**

Правила:
- Не дави. Не используй громкие обещания.
- Не начинай с рассказа об AlovLab — начни с задачи клиента.
- Каждое предложение звучит так, будто написано конкретному человеку.
- Следующий шаг — маленький и понятный (прийти на бесплатный интенсив, скачать гайд, ответить в личку).

## Оффер

1. **Для кого** — точная аудитория, одной фразой.
2. **Какая задача** — что человек хочет закрыть.
3. **Что даём** — суть, без списка из 30 пунктов.
4. **Почему это работает** — механика («конвейер», процесс, система), а не магия ИИ.
5. **Что на выходе** — конкретный артефакт или результат.
6. **Следующий шаг** — одно действие.

Никаких выдуманных цифр, кейсов, отзывов, «осталось N мест» и таймеров. Только честное.

---

## Письмо для рассылки / прогрев

- **Тема письма** — как хук: коротко, по-человечески, без капса и спама.
- **Первая строка** — продолжает тему, а не повторяет её.
- **Тело** — одна мысль, один пример, одна польза.
- **Один призыв** в конце. Не три ссылки, а одна.

Серия прогрева: письмо 1 — узнавание боли; письмо 2 — как устроено решение; письмо 3 — приглашение к шагу. См. `content-plan.md`.

---

## Карусель (VK / Telegram-альбом)

- **Слайд 1** — хук + обещание, ради чего листать.
- **Слайды 2–N** — один слайд = одна мысль/шаг. Коротко, крупно.
- **Последний слайд** — вывод + призыв.

Держи 5–8 слайдов. Если мыслей больше — это два поста, а не один.

---

## Сторис (серия)

- **Сторис 1** — крючок/вопрос/обещание.
- **Середина** — раскрытие по одному кадру, с интерактивом (опрос, реакция).
- **Финал** — призыв: свайп, ответ, переход.

Каждый кадр читается за 2 секунды. Текста мало, смысл крупный.
