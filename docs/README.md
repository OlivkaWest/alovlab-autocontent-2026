## 1. Карта смыслов и материалов

Единственный исходный материал — методичка интенсива. Из неё построен весь лендинг.

| Что | Роль в проекте | Где используется |
|---|---|---|
| Методичка «Автоконтент 2026» | источник всех смыслов, программы, FAQ | весь сайт (тексты, программа, пайплайн, FAQ) |
| Концепция «конвейер, а не генерации» | главный смысл / хук | первый экран, блок «В чём разница» |
| Общая карта 3 дней + VIP | блок «Программа» | секция `#program` |
| Схема конвейера (10 шагов) | интерактивный пайплайн (8 шагов для новичка) | секция `#how` |
| Итоговый результат (14 артефактов) | блок «Что вы получите» | секция `#result` |
| Целевая аудитория | блок «Для кого» | секция `#audience` |
| Приложение B (минимальный стек) | блок «Минимальный стек» | секция `#stack` |
| Разделы про автоматизацию/аватар | ответы FAQ | секция `#faq` |
| Подготовка участника (разделы 7–8) | **Стартовый гайд (PDF)** | скачиваемый файл |
| Шаблоны и чек-листы (разделы 15–17) | **Рабочая тетрадь (PDF)** | скачиваемый файл |
| Полная методичка | выдаётся участникам на интенсиве | кнопка «Получить после интенсива» |

**Что намеренно НЕ вынесено на страницу:** внутренние пометки ведущего (`[ВЕДУЩЕМУ]`),
тайминги блоков, скрипты продаж, расчёт цен, полные тексты промптов — это остаётся
внутри методички и рабочих материалов, чтобы лендинг был точкой входа, а не копией PDF.

**Принцип честности соблюдён:** нет выдуманных цифр, кейсов, отзывов, цен, дат, таймеров
и «количества мест». Всё, чего нет в материалах, помечено как «уточняется» и вынесено
в раздел 4 ниже.

## 7. Как заменить PDF, тексты и ссылки

### Ссылка на регистрацию
`js/main.js`, блок `CONFIG`:
```js
REGISTRATION_URL: "https://ваша-ссылка-на-регистрацию/",
```
Если задано — все кнопки «Записаться» открывают её в новой вкладке. Если пусто —
кнопки ведут к форме на странице.

### Приём заявок формой (если регистрация прямо на сайте)
`js/main.js`, `CONFIG.FORM_ENDPOINT` — адрес, принимающий `POST` с JSON:
```json
{ "name": "...", "contact": "...", "telegram": "...", "source": "avtokontent-2026-landing" }
```
Подойдёт webhook Make/n8n, Telegram-бот, CRM или email-сервис. После успешного `POST`
форма покажет благодарность и очистится.

### Замена PDF
Положите новый файл в `assets/pdf/` под тем же именем — ссылки обновятся автоматически.
Либо отредактируйте `scripts/build_pdfs.py` и пересоберите:
```bash
python3 scripts/build_pdfs.py
```

### Тексты
Все тексты — прямо в `index.html` (без шаблонизаторов). Ищите нужную секцию по
`id` (`#program`, `#faq` и т.д.) и правьте. Заголовки короткие — не удаляйте пробелы
ради вёрстки, шрифт спокойно переносит длинные слова.

### Логотип и фото автора
Разметка уже подключена — нужно **просто заменить два файла** (те же имена, те же пути):

- **Логотип:** `assets/img/logo-mark.png` — квадратный знак AlovLab (рекомендуется PNG
  с прозрачным фоном, ~256×256). Используется в шапке, подвале и как favicon.
- **Фото автора:** `assets/img/ilya-alov.jpg` — портрет Ильи в студии, формат ~4:5.
  Автоматически подставится и в первый экран (рядом с цепочкой), и в блок «Об авторе».

Загрузить можно через GitHub: **Add file → Upload files** в папку `assets/img/`
(перетащить файлы с теми же именами) → Commit. Сайт пересоберётся сам.
Пока файлы — плейсхолдеры, вёрстка не ломается и консоль без ошибок; после замены
всё встаёт на место без правок кода. При желании пересоберите `og-image.png`
с настоящим знаком.

### FAQ «уточняется»
Два вопроса помечены атрибутом `data-needs-owner="true"`. Замените текст ответа и
удалите `<span class="faq-flag">уточняется</span>` и атрибут.

## 8. Подключение аналитики

`js/main.js` содержит единую функцию `track(event, params)`. События уже расставлены:

| Событие | Когда |
|---|---|
| `register_click` | клик по любой «Записаться» |
| `form_submit` / `form_success` / `form_error` | отправка формы |
| `download_guide` | скачивание PDF |
| `program_open` | раскрытие дня программы |
| `pipeline_stage` | клик по этапу конвейера |
| `social_click` | переход в соцсети |
| `to_top` | кнопка «Наверх» |

Чтобы включить отправку — раскомментируйте в `track()` нужные строки и подставьте ID:
```js
// Яндекс.Метрика:  window.ym && ym(XXXXXXXX, 'reachGoal', event, params);
// VK Pixel:        window.VK && VK.Goal && VK.Goal(event, params);
```
И вставьте сам код счётчика в `<head>` `index.html`. Без разрешения владельца счётчики
не подключены.

## 9. Публикация

Сайт статический, сборка не нужна.

### Вариант A — GitHub Pages (текущий способ)

Сайт лежит в ветке `main`. Осталось один раз включить Pages:

1. Откройте **Settings → Pages** репозитория.
2. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
3. **Branch:** `main`, папка **`/ (root)`** → **Save**.
4. Через ~1 минуту сайт будет доступен по адресу:
   **https://olivkawest.github.io/alovlab-autocontent-2026/**

Дальше при каждом пуше в `main` GitHub пересобирает сайт сам. Файл `.nojekyll`
в корне гарантирует, что все ресурсы (шрифты, PDF, картинки) отдаются как есть.

### Вариант B — свой домен alovlab.ru (nginx)

```bash
scp -r * user@server:/var/www/alovlab.ru/avtokontent-2026/
```
```nginx
location /avtokontent-2026/ {
    root /var/www/alovlab.ru;
    try_files $uri $uri/ /avtokontent-2026/index.html;
}
```
Все пути относительные — в корне домена ничего менять не нужно.
Можно также привязать свой домен прямо к GitHub Pages (Settings → Pages → Custom domain).

### После публикации

1. Обновите `og:url` в `<head>` `index.html`, если адрес отличается от GitHub Pages.
2. Проверьте OG-превью (Telegram, ВК) — при необходимости пересоберите `og-image.png`.
3. Убедитесь, что PDF открываются по прямым ссылкам.
4. Заполните `CONFIG` (регистрация, endpoint, политика) и подключите аналитику.

## 10. Технические характеристики

- Семантический HTML5, доступность: skip-link, `aria`-атрибуты, клавиатурная навигация
  по пайплайну (стрелки/Enter), видимый фокус, `alt` у изображений.
- Контраст: тёплый белый текст на почти чёрном фоне — с запасом по WCAG.
- Производительность: без внешних запросов, шрифт self-hosted и `preload`, PDF грузятся
  только по клику, изображения лёгкие, анимации на `transform/opacity`.
- Совместимость: современные браузеры; при отсутствии `IntersectionObserver` контент
  показывается сразу.
- Запрещённые визуальные клише (роботы, неон, мозги, деньги, рукопожатия) — не использованы.
