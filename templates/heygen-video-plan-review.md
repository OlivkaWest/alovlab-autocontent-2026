# Шаблон проверки Video Plan (команда /heygen-review)

> Правило — `content/rules/ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §16. Заполнять по присланному
> Video Plan перед запуском платной генерации. Любой пункт "нет"/"не совпадает" — корректирующее
> сообщение, не запуск.

```
ПРОВЕРКА VIDEO PLAN — [название выпуска]

[ ] 1. Сохранён выбранный аватар (не подменён, не пересоздан).
[ ] 2. Сохранён выбранный голос.
[ ] 3. Реплики совпадают с утверждённым сценарием (EXACT SPOKEN SCRIPT).
[ ] 4. Сохранён русский язык.
[ ] 5. Порядок сцен соответствует STORYBOARD.
[ ] 6. Не добавлены случайные персонажи.
[ ] 7. Визуалы соответствуют смыслу реплик (не декоративны).
[ ] 8. Загруженные референсы использованы по назначению (ATTACHMENTS).
[ ] 9. Нет случайного стокового видео вместо заданного визуала.
[ ] 10. Субтитры не перегружены, совпадают с планом SUBTITLES.
[ ] 11. Seedance-сцены решают именно заданную визуальную задачу, не превращены в случайный B-roll.
[ ] 12. Хронометраж не изменился существенно относительно FORMAT.

ЕСЛИ ЕСТЬ РАСХОЖДЕНИЯ — корректирующее сообщение:
[Что именно не совпадает и что нужно вернуть к утверждённому плану, по пунктам выше.]

СТАТУС: [ГОТОВ К ГЕНЕРАЦИИ / ТРЕБУЕТ ПРАВКИ ПЛАНА]
```
