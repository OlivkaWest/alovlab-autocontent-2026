# Шаблон запроса на локальную правку (команда /heygen-fix)

> Правило — `content/rules/ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §17. На конкретную жалобу по
> готовому ролику — точная команда на правку именно этой сцены, не пересборка всего ролика. Если
> правильнее поправить в AI Studio, а не перегенерировать через Video Agent — сказать это прямо.

```
ПРАВКА ПОСЛЕ ГЕНЕРАЦИИ — [название выпуска]

ЗАМЕЧАНИЕ ПОЛЬЗОВАТЕЛЯ:
«[дословно — например: "на седьмой секунде субтитры закрывают промпт"]»

СЦЕНА: [номер/таймкод из STORYBOARD, к которой относится замечание]

ДИАГНОЗ:
[Что именно пошло не так — коротко, по делу.]

КОМАНДА НА ПРАВКУ (для Video Agent или AI Studio):
[Точная инструкция: что изменить, что оставить без изменений. По умолчанию добавлять: "Keep the
selected avatar, selected voice, approved Russian dialogue, and scene order unchanged. Refine only
scene [N]. Preserve the AlovLab visual style."]

ГДЕ ПРАВИТЬ: [Video Agent (перегенерировать сцену) / AI Studio (точечно: текст/тайминг/раскладка/
цвет) — выбрать одно и объяснить почему.]

НЕ ТРЕБУЕТ ПЕРЕСБОРКИ ВСЕГО РОЛИКА: [да/нет — почему].
```
