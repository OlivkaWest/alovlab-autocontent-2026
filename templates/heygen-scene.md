# Шаблон сцены (для STORYBOARD master-промпта)

> Правило — `content/rules/ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §15. Один блок на сцену,
> копируется столько раз, сколько сцен в выпуске. В финальном промпте — только реальные реплики
> текущего выпуска, этот файл — пустой шаблон, не пример для озвучки.

```
SCENE [NN]
TIME:
[00:00–00:04]

PURPOSE:
[Что эта сцена делает в драматургии — хук / проблема / поворот / демонстрация / payoff / CTA.]

SHOT TYPE:
[Avatar close-up / Screen demonstration / Seedance cinematic shot / Split-screen / ...]

SPEAKER:
[Selected primary avatar / Selected second avatar — только если паспорт утверждён.]

SPOKEN LINE:
«[Точная реплика, без тире, без техпометок.]»

VISUAL:
[Что именно в кадре — конкретное действие/объект/интерфейс, не абстракция.]

ON-SCREEN TEXT:
[Текст на экране, если есть — синхронно со словом, которое его вызывает. "нет", если пусто.]

MOTION GRAPHICS:
[Подсветка/анимация элемента интерфейса, если есть. "нет", если не нужно.]

SUBTITLES:
[ON / OFF — и почему, если OFF (например: "OFF — на экране читаемый промпт").]

TRANSITION:
[Как сцена переходит в следующую — осмысленная склейка, не случайный зум.]
```
