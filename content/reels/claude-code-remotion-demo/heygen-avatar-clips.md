# HeyGen-клипы для вставки (фетровый аватар) — вместо статичных поз

> Заменяет `character-prompts.md` как основной путь (тот остаётся запасным, если вставлять HeyGen-клипы
> не захочешь). Прогонять самостоятельно в HeyGen Video Agent — я туда не подключён и не выбираю
> аватар/голос за тебя (абсолютное правило проекта). В каждом промпте уже есть обязательная фраза:
> «использовать аватар и голос, уже выбранные пользователем в HeyGen».
>
> Разбивка 1:1 по сценам Remotion-проекта (`remotion/src/scenes/`) — реплики взяты из уже
> утверждённого FINAL VOICEOVER в `kit.md`, без изменений и без тире.
>
> **Фон:** если в твоём HeyGen-тарифе/аватаре есть опция однотонного/зелёного фона — выбери её, так
> проще выкадровать кружок. Если нет — не страшно, в Remotion клип всё равно идёт через круглую
> маску (`clip-path: circle`), поэтому лишний фон за кадром просто обрежется по краям кружка.
>
> **Формат клипа:** вертикальное видео, длительность — под тайминг сцены (указана в каждом блоке).
> Сохранить готовые файлы как `remotion/public/character/<имя>.mp4`.

Когда файлы `s1.mp4` … `s5.mp4` будут в `remotion/public/character/` — сообщи, пересоберу рендер:
код сцен уже обновлён и умеет подхватывать видео вместо плейсхолдера автоматически.

**Важно по звуку:** если отдаёшь эти клипы со своей речью HeyGen, финальная озвучка ролика — это
речь из клипов, а не отдельная закадровая дорожка. Общий FINAL VOICEOVER в `kit.md` остаётся
источником текста (реплики 1:1 совпадают), просто звучит он уже из видео-вставок, а не поверх.
