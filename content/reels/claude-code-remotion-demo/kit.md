Главный хук — газетная вырезка «ВАЙБ КОДИНГ» крупно в центре, вокруг — скотч и красный маркер.

посторонние предметы. Запрещено — стоковые «нейросетевые» картинки, несвязанные с коллаж-стилем.

## Технический проект

`remotion/` — рабочий Remotion-проект, структура сцен 1:1 по SCENE MAP выше. Сборка и рендер:
`cd remotion && npm install && npm run render`. До замены плейсхолдера на реальные PNG персонажа
рендер проходит с временной заглушкой (кружок с инициалом «И») — весь остальной пайплайн (тайминг,
текст, карта, терминал, промпт на экране, CTA-карточка) уже реальный и проверен рендером.
