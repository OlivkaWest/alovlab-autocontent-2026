# ALOVLAB PODCAST ACADEMY — обязательный аудиоподкаст для ElevenLabs (с 16.10.2026, высший приоритет)

> Применять при каждом образовательном Reels/карусели/методичке. Система производства:
> ТЕМА → REELS → КАРУСЕЛЬ → ПОЛНАЯ МЕТОДИЧКА → ПОДКАСТ ДЛЯ ELEVENLABS. Если не все форматы
> создаются по теме — всё равно готовить подкаст по доступным материалам и источникам. Один
> экспертный разбор темы — содержательная основа всех форматов, не дублировать исследование.

## 0. Принцип

Подкаст — самостоятельный образовательный продукт. Человек может не смотреть Reels и не читать
методичку, но после прослушивания должен получить законченное объяснение темы. Не короткий
пересказ — полноценный аудиоурок, который хочется дослушать, сохранить и переслать.

## 1. Продолжительность

Не менее 10 минут, целевая 11-12 минут, допустимо 13-15 при необходимости. Не сокращать
искусственно до 3-5 минут и не растягивать повторением одной мысли. Ориентир сценария — 1400-1700
русских слов с поправкой на реальную скорость голоса. Если есть возможность — тестовая генерация в
ElevenLabs и замер фактической длительности; если нет — расчётная длительность, честно помеченная
как расчёт, не как измерение.

## 2. Главное правило — готовый текст для озвучки

Основной файл (`PODCAST_ELEVENLABS_READY.txt`) — чистый текст, который копируют прямо в ElevenLabs.
Внутри запрещены: markdown, заголовки глав, нумерованные технические блоки, режиссёрские
комментарии, таймкоды, названия файлов, пометки «пауза», инструкции для монтажа, ссылки, голые URL,
код, английские служебные команды, текст в квадратных скобках для заполнения. Всё, что попало в
текст, ElevenLabs произнесёт вслух буквально — там должны быть только слова для слушателя. Текст
начинается сразу с первой произносимой фразы, без служебных подписей в начале и в конце.

## 3. Стиль голоса

Спокойный, уверенный, разговорный, немного ироничный, с профессиональной экспертизой, без
театральной дикторской манеры и искусственного пафоса — будто автор лично объясняет тему за столом.
Без дашей (тире) в тексте речи — та же причина, что в GLOBAL-REELS-VOICE-RULE: синтез может читать
их как незапланированную паузу. Числа — словами, как их должен произнести голос («одиннадцать
минут», не «11 минут»). Запрещённые обороты — те же, что в CLAUDE.md §8, плюс специфичные для
подкаста: «сегодня мы погрузимся», «искусственный интеллект стремительно развивается», «подведём
итоги нашего увлекательного путешествия».

## 4. Как начинается подкаст

Первые 15-30 секунд держат внимание: конкретная проблема, необычный факт, результат или ситуация —
без «здравствуйте, дорогие слушатели, сегодня мы поговорим о».

## 5. Архитектура (ориентир, не жёсткая сетка)

Хук (30-60 сек) → объяснение простыми словами с аналогией (1-2 мин) → основной практический разбор
(4-5 мин, шаги интерфейса человеческим языком, названия разделов проверены по источникам) →
профессиональные приёмы (2 мин, 3-5 не очевидных наблюдений) → ошибки и исправления (1-2 мин, с
решением, не только списком) → конкретный результат (60-90 сек: рабочий маршрут, одно практическое
задание, закрытие обещания хука, один естественный CTA).

## 6. Не пересказ методички

Содержание то же, подача другая — методичка показывает шаги списком, подкаст объясняет происходящее
разговорной речью, не читает инструкцию сухим текстом. Важные технические детали не выбрасывать ради
красивой фразы.

## 7. Источники и честность

Исследовать официальную документацию и уже подготовленные материалы темы (методичка, Reels,
карусель) перед написанием — не дублировать исследование заново. Не копировать текст документации
дословно. Факт не подтверждён — не выдавать за установленный. Ссылки — в отдельный файл
(production notes), не в текст озвучки. Примеры — не выдумывать личные результаты, заработки,
цифры от лица автора; условный пример подавать как условный.

## 8. Формат выдачи — четыре файла на выпуск

1. `script/PODCAST_ELEVENLABS_READY.txt` (или `PODCAST_PART_01.txt`, `_02.txt`... если превышен
   лимit интерфейса — каждая часть заканчивается на смысловой паузе, не обрывает предложение).
2. `elevenlabs/PODCAST_PRODUCTION_NOTES.md` — название, тема, аудитория, число слов, расчётная/
   фактическая длительность, рекомендации по озвучке, модель ElevenLabs если известна, источники.
3. `prompts/PODCAST_BONUS_PROMPTS.md` — полные промпты, упомянутые в выпуске (роль, контекст,
   задача, входные данные, ограничения, формат ответа, пример результата).
4. `description/PODCAST_DESCRIPTION.md` — заголовок, короткое описание, что узнает слушатель, для
   кого, что сможет сделать, один CTA, три коротких анонса (TG/VK/др.).

## 9. CTA

Не рекламный монолог — основная часть обучает. Если есть методичка — естественно предложить её в
конце, без выдуманных ссылок и без обещания ещё не созданного файла.

## 10. Структура папки на выпуск

`content/october-2026-system/podcasts/<topic-slug>/{source,research,script,elevenlabs,prompts,
description,exports,qa}/`

## 11. Процесс на каждую тему

Главная тема → прочитать доступные материалы (Reels/карусель/методичка) → найти, что уже есть
практического → исследовать недостающее → структура 11-12 минут → полный сценарий → убрать
канцелярит/повторы → проверить актуальность → адаптировать под синтез (дашей нет, числа словами) →
проверить расчётную длительность → четыре файла → финальная проверка по 10 критериям (§12).

## 12. Критерии приёмки

Хук · удержание · практическая польза · экспертность · понятность новичку · естественность речи ·
логика объяснения · качество примеров · актуальность фактов · готовность к ElevenLabs (ничего, кроме
текста для озвучки, в основном файле). Не присваивать оценку формально — если фраза прозвучит
неестественно у AI-голоса, исправить; нет практического результата — добавить; тема раскрыта
поверхностно — углубить; не хватает длины — расширить пользу, не вступление.

## 13. Команды

`/alovlab-podcast [тема]` — полный цикл с нуля. `/alovlab-podcast-from-reel` — на основе готового
Reels. `/alovlab-podcast-from-guide` — на основе готовой методички. `/alovlab-podcast-review` —
проверка длительности, речи, экспертности, актуальности и готовности сценария к синтезу. Реализация
— скилл `.claude/skills/alovlab-podcast/SKILL.md`.
