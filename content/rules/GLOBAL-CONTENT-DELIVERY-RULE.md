# GLOBAL CONTENT DELIVERY RULE — FULL PRODUCTION KIT (обязательно)

> Применять автоматически, когда просят: сделай Reels · сценарий Reels · карусель · Reels+карусель ·
> контент на тему · выпуск · ролик для HeyGen. Приоритетно. Работает вместе с
> GLOBAL-REELS-VOICE-RULE (голос озвучки) и GLOBAL-METHODOLOGY-RULE (методичка/система).

## Главный принцип
«Сделай Reels» = **сделай готовый REELS PRODUCTION PACKAGE**. «Сделай карусель» = **готовый CAROUSEL
PRODUCTION PACKAGE**. Не отдавать половину. Пользователь НЕ должен вытягивать по одному: «а теперь промпты»,
«а теперь описание», «а теперь хэштеги», «а теперь обложку», «а теперь сцены для Grok». Всё идёт сразу.

## A. REELS — что обязано быть в ответе (собери как готовый проект)
Сначала определить каркас: **CORE IDEA** (что человек поймёт) · **HOOK** (почему остановится) ·
**PAYOFF** (ради чего досмотрит) · **VISUAL CONCEPT** (почему интересно даже без звука) · **CTA** (что делать после).
Потом — сценарий. Длительность под смысл: работает за 23 сек — не растягивать до 40; нужно 45 — не втискивать в 20. Формат 9:16.

Финальная выдача Reels строго в этом порядке:
1. **REELS SCORE** (10 критериев, ниже)
2. **CORE IDEA**
3. **HOOK**
4. **FINAL VOICEOVER** (по GLOBAL-REELS-VOICE-RULE: живой язык, без канцелярита/штампов/сленга ради сленга,
   БЕЗ ТИРЕ, готов к прямой вставке в HeyGen; без техпометок внутри озвучки)
5. **SCENE MAP** (разбивка по сценам)
6. **HEYGEN AVATAR SCENES** (отдельно сцены с аватаром; текст/UI не перекрывают лицо/рот)
7. **GROK / AI VIDEO PROMPTS** (сцены без аватара; на каждую — полный production prompt, см. C)
8. **ON SCREEN TEXT** (на каждую сцену отдельно; коротко, одна мысль, НЕ дублирует озвучку)
9. **EDITING** (монтажный план по таймингу: 0:00–0:02 аватар · 0:02–0:05 AI scene …; переходы через действие,
   не шаблонные zoom/whip/glitch — курсор нажал → следующий кадр результат; match cut на результат)
10. **CTA** (одна, не три; если есть методичка → на методичку «в комментариях»)
11. **REELS DESCRIPTION** (не повторяет озвучку; даёт новый угол + интригу + поисковый контекст; коротко, живо)
12. **HASHTAGS** (релевантный набор: тематические+поисковые+нишевые+брендовые; не 30 мусорных, без #fyp/#viral без причины)
13. **COVER CONCEPT** (главный хук · визуальный конфликт · главный объект · композиция · эмоция · фон · свет ·
    что крупно · где место под текст · что убрать · что запрещено; задача обложки одна — клик)
14. **COVER TEXT** (3 варианта, каждый 2–5 слов, конфликт/вопрос/обещание/неожиданность; не пересказ темы)
15. **CHATGPT IMAGE COVER PROMPT** (готовый промпт под актуальную модель картинок ChatGPT: формат, композиция,
    персонаж, свет, фон, объекты, эмоция, визуальный конфликт, safe zone под заголовок, качество, запреты.
    Если обложка с Ильёй — Identity Lock: не менять лицо/голову/возраст/бороду/пропорции; выглядит как дорогой key visual, не AI-арт)
16. **GUIDE CONNECTION** (связь с методичкой, если предусмотрена)
17. **COURSE CONNECTION** (мост в курс «Нейросети и ChatGPT для каждого», если органично; через навык, не реклама)
18. **B2B CONNECTION** (мост в AlovLab Studio, если тема коммерческая; если связи нет — не притягивать)

## B. CAROUSEL — что обязано быть (CAROUSEL PRODUCTION KIT)
Финальная выдача карусели строго в этом порядке:
1. **CAROUSEL SCORE** (10 критериев)
2. **CORE IDEA**
3. **SLIDE 1 HOOK** + рекомендации по первому слайду
4. **ALL SLIDES** — на каждый слайд: **SLIDE NUMBER · PURPOSE · HEADLINE · BODY · VISUAL · IMAGE GENERATION PROMPT**
5. **VISUAL DIRECTION** (единый стиль; по VISUAL-SYSTEM.md — кинокадр + знание, не PowerPoint)
6. **IMAGE PROMPTS** (bespoke на каждый нужный визуал)
7. **CAROUSEL DESCRIPTION / CAPTION** (не пересказ слайдов; усилить первый тезис + новый контекст + обсуждение + CTA)
8. **CTA**
9. **HASHTAGS**
10. **GUIDE CONNECTION**
11. **COURSE CONNECTION**
12. **B2B CONNECTION**

## C. Каждый VIDEO PROMPT (сцена без аватара) — полный, не абстрактный
Плохо: «ноутбук с ChatGPT, кинематографично». Хорошо — с полями:
**SCENE NUMBER · DURATION · PURPOSE · SHOT · CAMERA · ACTION · ENVIRONMENT · LIGHTING · STYLE ·
SCREEN CONTENT · MOTION · ENDING FRAME · CONTINUITY · NEGATIVE CONSTRAINTS** → затем **READY TO COPY PROMPT**.
Блок для Grok оформлять как `# GROK VIDEO GENERATION` со Scene 01/02/03. Сцены с HeyGen-аватаром в Grok не дублировать.

**CONTINUITY между сценами:** один фильм, не «8 случайных клипов». Держать цвет, свет, объектив, атмосферу,
интерьер, устройства, руки, одежду, время суток, положение объектов.

## D. AI-интерфейсы и модели (критично, для Reels И каруселей)
- **Актуальный UI, не по памяти.** Показываешь ChatGPT/Claude/Gemini/Grok/Perplexity/Claude Code/Codex — проверь
  актуальный вид, навигацию, названия кнопок/режимов, текущие модели, доступные функции. Есть Web Search — используй.
- **Модели — проверять на дату материала.** Не называть модель «самой новой/лучшей/основной» без проверки.
- **Русский интерфейс** для РФ/СНГ: значимый текст на экране по-русски («Создать изображение», не «Create image»);
  пользовательские запросы внутри интерфейса — тоже по-русски.
- **Кириллица должна читаться.** Никакой псевдорусицы/сломанных слов. Генератор не тянет русский → делать чистую
  область интерфейса и добавлять точный русский текст отдельным слоем при монтаже (наш приём: PNG-панель поверх).
- **Экраны не фейковые.** Не «абстрактный AI dashboard, подписанный ChatGPT». Не воспроизводится надёжно →
  screen recording или нейтральное устройство + compositing реального интерфейса.

## E. Система = одна идея (Reels + карусель + методичка)
Не три разных концепта. **REELS** создаёт желание попробовать · **CAROUSEL** показывает механику ·
**PDF/методичка** даёт полный workflow (по GLOBAL-METHODOLOGY-RULE: workflow, детальные промпты, примеры,
quality check, практика, мост в курс, путь в команду AlovLab). Это одна воронка.
- **B2B CHECK:** AI видео → коммерческие ролики; AI Avatar → корпоративные аватары; AI Agents → агентные системы;
  подкасты → AI-подкасты; автоматизация → процессы. Естественно — встроить мягкий мост; нет — не притягивать.
- **COURSE CHECK:** можно органично связать с курсом — показать, какой навык углубляется. Без бездумной рекламы.
- **SEARCH & FRESHNESS CHECK** перед выдачей: [ ] модели актуальны [ ] интерфейс актуален [ ] названия функций
  актуальны [ ] не вышла ли модель лучше [ ] не изменился ли способ работы [ ] не устарел ли совет.
  Особенно если в публикации «новая функция / последняя модель / лучший инструмент / сейчас можно».

## F. ЖЁСТКАЯ ОЦЕНКА перед production (10 баллов каждый)
HOOK · RETENTION · VISUAL POTENTIAL · NOVELTY · SAVE VALUE · SHARE VALUE · FOLLOW VALUE · AUTHORITY ·
CONVERSION · PRODUCTION QUALITY. Концепт слабее **8/10** → не идём в production, сначала переделать.
Задача не «закрыть запрос», а сделать контент, способный конкурировать за внимание большой аудитории.

## Главное правило
Один запрос → полностью собранный материал, готовый к производству и публикации. Не заставлять пользователя
добирать элементы следующими сообщениями.
