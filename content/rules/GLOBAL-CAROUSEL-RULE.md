# GLOBAL CAROUSEL RULE — карусель = мини-урок + save + вирал + доказательство экспертности (обязательно)

> Применять автоматически ко ВСЕМ каруселям AlovLab. Приоритет над визуальными пунктами Приложения Б.
> Работает вместе с GLOBAL-CONTENT-DELIVERY-RULE (полный кит), VISUAL-SYSTEM (кинокадр+знание),
> GLOBAL-METHODOLOGY-RULE (методичка), GLOBAL-REELS-VOICE-RULE (голос).

## 0. Перед работой — подключить Skills
Найти и реально использовать доступные Skills под: carousel/social · методология обучения · copywriting ·
research · viral hooks/retention · prompt engineering · визуальная иерархия · Instagram/VK. Нет нужного —
искать в доступных GitHub Skills. Skill не для галочки — усиливает содержание. В конце коротко отчитаться,
какие Skills использованы и зачем.

## 1. Главная цель
Не набор красивых слайдов. Каждая карусель = **мини-урок + SAVE-материал + вирал + доказательство экспертности**.
Человек уносит минимум одну вещь, применимую СРАЗУ. Целевой эффект: «этого я не знал» · «сохраню» · «надо попробовать» ·
«где он это взял» · «хочу ещё». Красивый визуал без знания — недостаточно.

## 2. Изображения от пользователя
Даёт тему + смысл + готовые визуалы. **НЕ перерисовывать без причины.** Визуал — кинематографическая основа,
поверх строим информационный слой. НЕ превращать картинку в фон для огромных абзацев. Визуал сильный, знание сильнее.

## 3. Методологический разбор ДО вёрстки
Вопрос: «Убрать красивые картинки — стоит ли содержание сохранения?» Если НЕТ — собирать запрещено, сначала усилить.
Искать под тему: рабочие приёмы · неочевидные настройки · ошибки новичков · алгоритмы · короткие инструкции ·
чек-листы · формулы · шаблоны · промпты · способы проверки · ограничения метода · примеры. Не выдумывать «секреты».
Актуальность функций Claude/ChatGPT — проверять. Из GitHub/доков/Skill брать механику, не копировать чужой текст.

## 4. Правило ценности (HARD)
В каждой карусели минимум **3 из 6**: (1) готовый PROMPT · (2) конкретная техника · (3) пошаговый алгоритм ·
(4) пример ДО → ПОСЛЕ · (5) таблица/карта/чек-лист для сохранения · (6) ошибка + как исправить.
Экспертные темы — 4–5. Только заголовки и объяснения → переделывать.

## 5. Промпты
Не «помоги написать пост». Только COPY→PASTE. Внутри: КОНТЕКСТ → ЗАДАЧА → ВХОДНЫЕ → ОГРАНИЧЕНИЯ → КРИТЕРИИ → ФОРМАТ.
Проектировать под тему, не вставлять одну структуру механически. Полный copy-paste промпт живёт в подписи/комментах/
методичке (с картинки не скопировать), на слайде — читаемый компакт/формула для сохранения.

## 6. Архитектура (меняет ритм, не 7 одинаковых слайдов)
Запрещено: заголовок + 2 строки + картинка ×7. Пример: 1 конфликт/хук · 2 ломаем мнение · 3 первый инсайт ·
4 техника/метод · 5 SAVE (карта/чек-лист) · 6 PROMPT/алгоритм/пример · 7 вывод + шаг + CTA. Структура не фиксирована,
меняется под тему. Каждый свайп открывает новую ценность.

## 7. Retention (микро-open-loop)
Между слайдами — причина свайпнуть. Не закрывать мысль полностью. «но здесь одна проблема →», «вот где ломается
результат →», «есть способ проверить →», «а теперь самое полезное →». НЕ как шаблон — переход из смысла.

## 8. Текст (для новичка в ИИ, не для программиста)
Человек понимает: ЧТО это · ЗАЧЕМ · КУДА нажать/что вставить · ЧТО написать · ЧТО получить · КАК понять что верно.
Живой русский: «закинь», «скормить Claude файл», «не пихай всё в один запрос», «вот где начинается магия»,
«если Claude поплыл — делай так» — только если естественно. Не изображать искусственный сленг.
ЗАПРЕЩЕНО: «в современном мире», «важно понимать», «эффективный инструмент», «вывести на новый уровень»,
«раскрыть потенциал», «революционный подход», «использование ИИ позволяет», «данное решение», «рассмотрим»,
«давайте разберёмся» и всё, что пахнет текстом нейросети.

## 9. Визуальная иерархия (3 уровня на слайде)
LEVEL 1 — мысль, читается за 1 сек (крупно). LEVEL 2 — польза, 3–5 сек (средне). LEVEL 3 — экспертная деталь для
остановившегося (мелко) + PROMPT отдельным блоком. Так появляется глубина.

## 10. Не забивать визуал
Экспертность ≠ тонна текста. Много материала → выдели 3 пункта / карточка / мини-таблица / схема / PROMPT отдельным
блоком / подробности на следующий слайд. НЕ класть 12 строк поверх лица/ключевого объекта.

## 11. Финальный слайд (критично)
Внизу каждого слайда УЖЕ есть маленький фирменный AlovLab. Поэтому НЕ ставить снова большой логотип / гигантскую A /
AlovLab по центру / дублирующий брендинг — особенно на последнем слайде. Финал отдаёт пространство ПОЛЬЗЕ и CTA
(«Сохрани карту», «Забери промпт ↓», «Чек-лист в комментариях ↓»). Маленького нижнего брендинга достаточно.

## 12. CTA
Не «подписывайтесь, чтобы не пропустить». CTA продолжает пользу: «полный промпт в комментариях ↓», «сохрани — в
следующий раз не будешь гадать, какую модель открыть», «шаблон в комментариях ↓», «закинь свой запрос в этот промпт
и сравни».

## 13. Вирал → 100k (без дешёвого кликбейта)
HOOK → CURIOSITY → VALUE → SAVE → SHARE → AUTHORITY → FOLLOW. Подписка — от мысли «если такое отдаёт бесплатно,
что тогда в обучении». Это главный критерий.

## 13-Б. ЭТАЛОННЫЙ ВИЗУАЛЬНЫЙ СТИЛЬ (основной, с 01.09)
**Светлый премиум-инфографик — основной стиль каруселей AlovLab.** Тёмный кинокадр — вторичный (для
атмосферных/конфликт-тем). Эталон: `exports/carousels/day-claude-06-v2` (7 слайдов).
Признаки стиля:
- **Фон** светлый тёплый песочный/кремовый, чистый, много воздуха. Не тёмный.
- **Композиция** редакторская: карточки, мини-таблицы, иконочные ряды, чёткая сетка, 3 уровня иерархии.
- **Цветные иконки сервисов/категорий** (ChatGPT — мягкая бирюза, Claude — оранжевый, поиск/идеи/визуал/код/
  голос — свои мягкие цвета). Не монохром.
- **Брендинг:** логотип AlovLab сверху-справа + маленький снизу-слева, футер-ряд ценностных чипов. Нумерация N/07.
- **Формат** строго 1080×1350 (4:5), единый на всю колоду (иначе Instagram режет).
- Без «оранжевого взрыва», без кислоты, без визуального шума, без тёмных плашек на весь слайд.

**Палитра (слоты):**
- основной фон — тёплый песочный `#FBF4E9` (варианты `#F7EEDD`)
- основной текст — тёмный графит `#20242B`
- вторичный текст — тёплый серо-коричневый `#6E6A63`
- акцент 1 — тёмно-оранжевый `#E1671E`
- акцент 2 — янтарный/мягкий оранжевый `#F2A65A`
- цвет значков — по категории (мягкие: бирюза `#4A8E7E`, синий, сиреневый, розовый, оранжевый)
- подложки карточек — белый `#FFFFFF` и мягкий песок `#FBEFE0`
- разделители — тёплый бежевый `#EBE2D3`

## 14. ФИНАЛЬНАЯ ПРОВЕРКА (HARD GATE)
Оценить /10: HOOK · RETENTION · VALUE · NOVELTY · SAVE · SHARE · AUTHORITY · CLARITY · VISUAL · CONVERSION.
Средняя не важна. **HARD GATE: VALUE ≥ 9 · SAVE ≥ 9 · AUTHORITY ≥ 9 · CLARITY ≥ 9.** Хоть один ниже 9 —
НЕ экспортировать, переписать слабые слайды.
Ответить на 3 вопроса: (1) что конкретно человек научился делать? (2) какой слайд сохранит и зачем?
(3) какое знание нельзя получить из первых 3 результатов Google? Нет ответа на (3) — недостаточно глубоко.
Только после этого — финальные PNG 1080×1350.
