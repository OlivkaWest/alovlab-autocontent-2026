# ВИЗУАЛЬНАЯ СИСТЕМА КАРУСЕЛЕЙ ALOVLAB (обязательно)

> Действует с 19.08.2026 для ВСЕХ каруселей. Отменяет прежний подход «схема/иконки в нижней части».
> Приоритет над визуальными правилами `CLAUDE.md` Приложения Б в части нижнего визуала.

## Главный принцип

**КАРУСЕЛЬ = СИЛЬНАЯ ТИПОГРАФИКА + СМЫСЛОВОЙ КИНОКАДР.**

Не украшать текст картинкой. **Превращать мысль слайда в кадр.** Каждый слайд должен быть
настолько сильным, чтобы работать отдельным рекламным постером.

Больше НЕ использовать как основной визуал: примитивные схемы, пустые карточки, абстрактные
иконки, декоративные стрелки, блоки. У каждого смыслового слайда — своя полноценная сцена.

## Структура слайда

- **Верх 35–45%:** короткий сильный заголовок (белый + AlovLab orange), 1–2 акцента, короткое
  пояснение только при необходимости.
- **Низ 55–65%:** полноценное премиальное изображение, которое буквально или метафорически
  раскрывает мысль. Это не декор, а вторая половина смысла.
- Читатель: прочитал заголовок → посмотрел вниз → понял идею за 1 секунду без объяснений.

## Процесс (обязательный, ДО генерации финала)

Для КАЖДОГО слайда Claude формирует и согласовывает:

```
SLIDE:           главная мысль слайда
VISUAL METAPHOR: что физически показываем
SCENE:           что происходит в кадре
IMAGE PROMPT:    готовый подробный промпт под это изображение
LAYOUT:          где заголовок, где изображение
```

Только после апрува концепции — собираем финальную карусель.
Правила: одну сцену не повторять на разных слайдах; каждый слайд визуально продолжает
предыдущий; вся карусель = серия кадров одного дорогого рекламного ролика.
Не повторять одну композиционную формулу более двух раз (чередовать приёмы: предметная съёмка,
интерфейс, макро, архитектурная метафора, человеческая сцена, документальный кадр).

## Визуальный уровень

Ориентир: premium editorial advertising · cinematic commercial photography · кампания крупного
бренда. Фактура: фотореализм, кинематографический свет, глубокие тени, контролируемый контраст,
натуральные материалы, реалистичная оптика, depth of field, лёгкая плёночная фактура.
Без пластиковых лиц/объектов и ощущения «сделано нейросетью».

## Фирменный код

База — почти чёрный / графит. Акцент — тёплый **AlovLab orange** (янтарный свет, тёплые
практические источники, оранжевые отражения, лёгкое свечение). Оранжевый — акцент, НЕ заливка.
Все изображения одной карусели — часть одной визуальной вселенной.

## Персонаж (Илья Алов / Нейромонах)

Только по предоставленному референсу. **IDENTITY LOCK:** лицо, форма головы, борода, глаза, нос,
телосложение, возраст — не менять. Не омолаживать, не «улучшать», не менять бороду, не создавать
похожего человека. Если присутствие автора не добавляет смысла — не вставлять.

## Текст внутри изображения

Минимум. Основной текст — в дизайне карусели, не в фото. Внутри изображения текст разрешён
только когда он часть сцены: вывеска, экран, указатель, интерфейс, название этапа, Telegram,
брендирование.

## Запрещено как главный визуал

generic UI cards · случайные иконки · простые схемы · пустые прямоугольники · декоративные
стрелки · абстрактные AI-сферы · светящиеся мозги без смысла · роботы ради слова «ИИ» ·
бессмысленные ноутбуки · стоковые сцены · визуал, который можно поставить в любую другую
карусель. **Тест:** если изображение подходит к другой теме без изменений — оно недостаточно
конкретное.

## Пример логики (тема: профиль ведёт в Telegram)

- «Профиль как витрина» → человек перед красивой витриной, путь заканчивается.
- «Полируешь витрину» → человек полирует витрину, рядом — путь в Telegram.
- «Мост — три узла» → настоящий кинематографичный мост: ШАПКА → ЗАКРЕП → ХАЙЛАЙТЫ → TELEGRAM.
- «Шапка по формуле» → крупный смартфон, разобрано КТО ТЫ → ЧТО ДАЁШЬ → КУДА ИДТИ.
- «Указатель, а не витрина» → физический дорожный указатель ведёт от профиля в Telegram.
- Финал → предметная сцена: тетрадь AlovLab + телефон + Telegram + CTA.

НЕ рисовать инфографику о мосте — ПОКАЗАТЬ настоящий мост.

## Технически (сборка)

Заголовки — крепкой векторной типографикой поверх фото (или впечены в кадр, если качество текста
идеальное). Нумерация **N/8** — чип в углу. Экспорт: `slide-01..NN.png` 1080×1350, sRGB.
Эталон исполнения — карусель `day-16` (`exports/carousels/day-16-showcase/`).
