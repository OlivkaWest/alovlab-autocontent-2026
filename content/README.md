# content/ — дни производства

Здесь живёт контент по датам: `content/YYYY-MM/YYYY-MM-DD/`. Тулинг `automation/`
читает эту структуру по дате (команда «Сделай ролик на 5 августа» → `2026-08-05`).

## Структура дня
```
2026-08-05/
  source/            # исходный материал дня
    meta.json        # тема, цель, аудитория, CTA, длительность, кол-во карточек
    carousel.md      # текст карусели (## [role] Заголовок + текст)
    post.md          # текст публикации
  carousel/          # PNG-карточки (b-roll), рендерятся из carousel.md
  visuals/           # готовые изображения/видео дня (если есть)
  reels/             # сценарий, сцены, планы, HeyGen/Grok/Higgsfield, монтаж, субтитры
    render/final_reels_vN.mp4
  status.json        # статус дня и версии
```

## Важно про 5 августа
В репозитории **не было** готового 30-дневного контент-плана — только лендинг и PDF.
День `2026-08-05` заведён из тестового материала задания («Одна идея — это не один
пост»), а не выдуман. Реальные дни добавляй такими же папками — адаптер прочитает их
автоматически (`npm run alovlab -- index`).
