# Методички AlovLab (премиум-PDF) — как делать

Так собрана эталонная методичка `higgsfield-restaurant-reel` (v2). Все новые методички
делаем по этой же системе. Не собирать PDF из непрерывного HTML — только фиксированные A4-страницы.

## Пайплайн

```bash
# 1) исходник методички в Markdown
content/guides/<тема>.md

# 2) сборщик страниц (адаптировать копию под тему) → HTML с фикс-страницами
python3 scripts/guide_pdf_v2_build.py            # шаблон-эталон

# 3) рендер: PDF + PNG каждой страницы + контактный лист
NODE_PATH=/opt/node22/lib/node_modules node scripts/guide_pdf_v2_shoot.js <html> <pdf> <pagesDir>
```

Результат кладём в `exports/higgsfield-guide/<тема>/` (или `exports/guides/<тема>/`):
`*-v2.pdf`, `pages/page-01.png…`, `preview-all-pages.png`.

## Дизайн-система (обязательно)

1. **Фиксированные A4-страницы.** Каждая страница — `div.page` размером 210×297мм, `overflow:hidden`,
   `page-break-after`. Это даёт полный контроль пагинации: без разорванных блоков, сиротских
   заголовков и авто-пустот. Контент раскладываем по страницам вручную.
2. **Свет для чтения, тьма для статуса.** Внутренние страницы — тёплая светлая бумага
   (`#FAF6EF`, текст `#1b1712`). Тёмные плашки (`#13100A`) — только под **обложку и промпты**.
   Не делать всю методичку тёмной.
3. **Поля и колонка.** Верх/низ ≥ 19мм, бока ≥ 22мм. Текстовая колонка ≤ ~150мм (60–72 знака в строке).
4. **Типографика.** Тело **11pt / интервал 1.62**; заголовок страницы 26–30pt; раздел 18–20pt;
   подзаголовок 13pt; подписи 8.5–9pt. Не уменьшать шрифт ради вместимости — добавить страницу.
5. **Один экран — одна мысль.** Лучше 16 воздушных страниц, чем 8 перегруженных. Низ страницы
   может дышать — это премиум, а не недоработка.
6. **Карточки вместо тесных таблиц.** Сцены, подготовка, длительности — карточки. Таблицу
   оставляем только там, где она реально яснее, с воздухом в ячейках (padding ≥ 10px).
7. **Промпты — рабочий инструмент.** Тёмная плашка на светлой странице, метка
   «ГОТОВЫЙ ПРОМПТ · СКОПИРОВАТЬ», крупный моно, русское пояснение под ним.
   **Один промпт — одна страница**, не рвать между страницами.
8. **Навигация.** Колонтитул сверху (бренд + раздел), футер снизу (тема + номер страницы),
   отдельная страница «Содержание». 
9. **Ритм.** Врезки «Что должно получиться» и «Проверь себя», блоки good/bad, схемы-потоки
   (`node → node`). Каждый блок с функцией, не декоративные прямоугольники.
10. **Обложка и финал.** Обложка тёмная: логотип, короткое название, конкретный результат,
    сильный кадр, воздух. Логотип — на обложке и в финале (не на каждой странице).
    Финал — контакты: Telegram t.me/AlovLab, VK, сайт alovlab.ru.

## Проверка (не пропускать)

- Отрендерить **каждую** страницу в PNG и открыть глазами (не судить по коду).
- Проверить: поля, размер текста без увеличения, отсутствие переполнения/обрезки,
  нет разорванных блоков и пустых страниц, единый стиль, читаемость на телефоне.
- Собрать `preview-all-pages.png` — но он не заменяет проверку отдельных страниц.
- Любой из критериев ниже 8/10 (читабельность, поля, типографика, структура,
  премиальность, готовность) → ещё один цикл, не выдавать слабую версию.

## Язык

Живая речь наставника, короткие фразы, термин расшифровываем при первом появлении,
английские команды/промпты — на английском с русским пояснением. Без канцелярщины и
шаблонных AI-фраз (список запретов — в `CLAUDE.md`, раздел 8).

Эталон: `scripts/guide_pdf_v2_build.py` + `content/guides/higgsfield-restaurant-reel.md`.
