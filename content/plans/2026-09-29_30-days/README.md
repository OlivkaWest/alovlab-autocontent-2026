## Как продолжить (для следующей сессии/итерации)

1. Открыть `production-manifest.json`, найти следующий день со статусом `запланирован`.
2. Взять его тему/хук/результат из `calendar.csv`.
3. Собрать пакет по образцу `days/day-01/` (reel.md, heygen-prompt.txt, carousel-ru.md,
   carousel-en.md, workbook.md, telegram.md, quality-check.md).
4. Для методички — скопировать `scripts/guide_30days_day01_build.py` под новый день (меняется
   контент страниц, CSS/структура уже готовы), отрендерить через `guide_pdf_v2_shoot.js`.
5. Для DOCX — переиспользовать конвертер `workbook.md → .docx` (скрипт использовался разово из
   scratchpad этой сессии; при необходимости пересоздать по тому же принципу: python-docx,
   разбор по `## ` заголовкам).
6. Обновить `production-manifest.json` по факту, не заранее.
7. Работать пакетами по 5–7 дней и коммитить после каждого пакета — не пытаться закрыть все 29
   дней одним проходом.
