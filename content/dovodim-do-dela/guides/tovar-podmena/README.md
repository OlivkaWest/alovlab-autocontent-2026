# Методичка «Товар не тот. Проверка ИИ-рекламы перед сдачей»

Спутник к карусели `content/dovodim-do-dela/carousels/day-06/` («Реклама красивая. Товар —
другой.») — та же CORE IDEA, что и в Reels дня 6 «Доводим до дела»
(`content/dovodim-do-dela/days/day-06.txt`).

## Источники

- Собственная карусель дня 06 — правило трёх точек (силуэт / функциональные детали / пропорции).
- Присланные пользователем файлы `ae449acc-Caption.txt` и `d749efe8-Generation_Prompts.txt` —
  расширенная 7-слайдовая версия той же темы («КРАСИВАЯ ИИ-РЕКЛАМА. ТОВАР НЕ ТОТ.»): техника
  разделения товара и фона на отдельные слои, рабочий ретушь-промпт, чек-лист с процедурой
  наложения 50%, таблица «ошибка → фикс». Промпт перенесён в методичку без переписывания
  содержания — добавлена только версия с переменными `[...]` под произвольный товар.
- Честные ограничения перенесены из Caption.txt дословно по смыслу: мугы — учебный пример, не
  клиентский кейс; приём наложения проверяет только видимый контур при одинаковом ракурсе, не
  гарантирует совпадение со всех сторон.

## Файлы

- `workbook.html` / `tovar-podmena-workbook.pdf` — сама методичка, 10 страниц A4.
- `pages/page-01..10.png` — рендер каждой страницы, визуально проверены (текст не обрезан,
  карточки-предупреждения отображаются с рамкой и фоном, нет переполнения).
- `prompts.txt` — оба промпта главы 4 отдельным копипаст-файлом.

## Структура (8 глав)

1. Зачем это нужно — откуда берётся несовпадение формы.
2. Правило трёх точек — метод + честное ограничение наложения.
3. Сборка: товар отдельно, фон отдельно — технология слоёв, уровни Быстрый/Про/Advanced.
4. Рабочий промпт — готовый + с переменными.
5. Чек-лист перед сдачей — форма/детали/впечатление + процедура наложения.
6. Если деталь поплыла — таблица ошибка → фикс (форма / надпись / сложный материал).
7. ACTION BLOCK «Сделай сейчас» + QUALITY CHECK.
8. Куда дальше — мост в курс (Земля Изображений) + Studio + «Путь в команду AlovLab».
