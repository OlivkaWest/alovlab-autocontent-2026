# НЕЙРО · 4 макроса для ChatGPT, которые ведут контент как систему

Это файл, который обещан в карусели «Отдай свой Instagram ChatGPT» (слайд 7, слово НЕЙРО
в комментариях). Отдаём его в Telegram теми же руками, что вели воронку.

Важно сразу: /contentmix, /audiencemap, /leadidea и /funnelmap это не встроенные команды
ChatGPT. Это макросы AlovLab. Один раз вставляешь в чат настройку ниже, и дальше короткая
команда запускает нужный сценарий. ChatGPT просто выполняет его по памяти разговора.

## Шаг 1. Настройка (вставить в начало чата один раз)

```
Дальше я буду писать короткие команды.
Каждая означает полный сценарий из этого чата. Выполняй по памяти, не переспрашивай заново.

/contentmix = разложить одну мысль на 4 формата: Reels, карусель, пост, Telegram.
/audiencemap = разобрать проблему аудитории по комментариям, вопросам и отзывам.
/leadidea = придумать лид магнит с маленьким реальным результатом, не абстрактный PDF.
/funnelmap = построить путь от контента до заявки и найти, где человек теряется.

Если какие то из входных данных ниже не укажу, спроси их перед тем как отвечать.
```

## Макрос 1 · /contentmix

```
Ты контент стратег.
Мысль: [одна мысль или наблюдение, которое хочешь раскрыть]
Ниша: [о чём ты делаешь контент]
Аудитория: [кто читает/смотрит]
Цель: [что человек должен сделать после просмотра]

Разложи эту мысль на 4 формата: Reels, карусель, пост, Telegram.
Для каждого формата дай: хук (первая строка), угол подачи, короткую структуру по блокам, CTA.
Не повторяй один и тот же хук в разных форматах, у каждого формата свой заход.
```

## Макрос 2 · /audiencemap

```
Ты исследователь аудитории.
Ниша: [о чём ты делаешь контент]
Продукт: [что ты продаёшь или к чему ведёшь]
Материалы (комментарии, вопросы, отзывы): [вставь реальные сообщения, если есть]

Не придумывай факты, которых нет во входных данных.
Собери: проблему словами клиента (цитата или близко к ней), скрытый смысл за этой проблемой
(чего человек на самом деле боится или хочет), и предложи тему и формат контента, который
закрывает именно это.
Если материалов мало, честно скажи, что данных недостаточно для уверенного вывода.
```

## Макрос 3 · /leadidea

```
Ты продуктовый маркетолог.
Аудитория: [кто это]
Проблема: [конкретная проблема аудитории]
Продукт: [к чему в итоге ведёт лид магнит]

Дай 7 лид магнитов с маленьким реальным результатом за 5 до 20 минут.
Не абстрактные PDF вроде «10 секретов». Каждый лид магнит должен давать конкретное
действие или артефакт, который человек получает сразу после использования.
Для каждого укажи: что именно человек получает, сколько времени занимает, почему это
ведёт к следующему шагу (а не закрывает интерес само по себе).
```

## Макрос 4 · /funnelmap

```
Ты маркетолог воронок.
Продукт: [что продаёшь]
Цена: [диапазон или точная цена]
Площадка: [где основной контент, например Instagram]
Лид магнит: [что отдаёшь бесплатно]
Целевое действие: [заявка, покупка, запись на диагностику]

Опиши путь: контент, подписка, лид магнит, прогрев, предложение, заявка.
Для каждого шага укажи, что должно произойти, чтобы человек пошёл дальше.
Найди, где по твоему опыту с похожими воронками человек чаще всего теряется, и предложи
одно конкретное исправление на этом шаге.
```

## Как использовать

Не нужно писать все 4 команды сразу. Запускай по одной, под задачу: нужна тема на неделю
/contentmix, не понимаешь аудиторию /audiencemap, лид магнит не берут /leadidea, контент
есть а заявок нет /funnelmap.

Это рабочий инструмент, не готовый результат за тебя. Вставляй реальные данные о своей
нише, не оставляй квадратные скобки пустыми.
