- **IG RU/EN** — весь месяц одинаково: сохранить пост / ответить ключевым словом в комментариях.
  Ссылок нет из-за ограничения (действует предположительно до 30.10.2026) — не обходим сокращателями

- **Telegram** — «Полный материал (методичка G0X) — пост+файл в t.me/AlovLab», статус места выдачи
  указан честно по каждому дню: для дней 1–7 — «файл создаётся в этой сессии», для остальных —
  «место выдачи не подготовлено» (методичка ещё не написана, это не выдуманная ссылка).
- **VK** — контекстный пост (+VK Клип для Reels-дней), ссылка на методичку в закрепе/первом
  комментарии, тот же честный статус.
- Генерическую заглушку «методичка/курс» больше нигде не используем — везде указан конкретный ID
  методички (G01–G10) и реальный статус файла.
