# День 5 · Подписи — «Один вопрос — два разных ответа. Не баг»

## IG RU
Один вопрос. Два разных ответа. Это не баг.
Модель не вспоминает готовый ответ — собирает заново каждый раз. Оба варианта могут быть одинаково
верными. Поэтому для важного текста прошу не один ответ, а три. Разбор — в Telegram.
**CTA:** сохрани / напиши «ВАРИАНТЫ» — ссылок нет весь месяц.

## IG EN
One question. Two different answers. Not a bug.
The model builds an answer fresh each time. Both can be equally correct. For anything important,
ask for three, not one.
**CTA:** save / comment "VARIANTS".
