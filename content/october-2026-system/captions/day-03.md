# День 3 · Подписи — «Как проверить ответ ИИ»

## IG RU
Ответ ИИ звучит уверенно. Уверенность — не доказательство.
3 проверки перед тем, как использовать ответ в работе: первоисточник, конкретное утверждение,
цифры отдельно. Переспросить ту же модель — не в счёт, это тот же источник. Разбор на примере — в Telegram.
**CTA:** сохрани / напиши «ПРОВЕРКА» — ссылок нет весь месяц.

## IG EN
A confident answer isn't a correct one.
3 checks before using an AI answer for real work: primary source, one specific claim, numbers
checked separately. Asking the same model again doesn't count. Full example in Telegram.
**CTA:** save / comment "CHECK".
