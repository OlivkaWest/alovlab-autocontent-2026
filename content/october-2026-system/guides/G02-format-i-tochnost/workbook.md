# AlovLab · Октябрь 2026 · G02 «Формат и точность ответа» (дни 4–7, капстоун недели 1)

## Глава 1 · Что нельзя вставлять в чат
Для кого: любой, кто работает с чужими данными. Результат: проверенная привычка обезличивания.

1. Пароли/доступы — даже «временный» токен.
2. Договоры без обезличивания — ФИО, суммы, реквизиты сторон.
3. Финансы клиента — выписки, доходы, платёжные данные.
4. Медданные — диагнозы, история болезни.
5. Чужие личные данные — телефон/адрес без согласия человека.

Вместо этого — обезличивай: «Клиент А» вместо имени, «N рублей» вместо суммы, сохраняй только
структуру задачи. Полный пример обезличивания — глава 5.

## Глава 2 · Почему ответы разные
Для кого: любой пользователь ChatGPT. Результат: использовать вариативность осознанно.

Модель выбирает следующее слово вероятностно, а не по жёсткой таблице — поэтому один и тот же
промпт может дать разные, но одинаково валидные ответы. Это не ошибка и не признак «плохой»
модели. Источник: OpenAI Developer Community, «Why is GPT-4 giving different answers with same
prompt & temperature=0?», https://community.openai.com/t/why-is-gpt-4-giving-different-answers-with-same-prompt-temperature-0/143513
(дата проверки 30.09.2026).

**Промпт на несколько вариантов:**
```
[твой обычный рабочий запрос]
Дай два-три разных варианта ответа, не один. Пронумеруй их.
```
Для важного текста — выбор из нескольких вариантов, а не единственная попытка.

## Глава 3 · Как управлять форматом ответа
Для кого: тот, кто переделывает ответы руками. Результат: формат задан заранее.

Без формата — сплошной текст, использовать нужно после ручной переделки. С форматом («оформи как
таблицу») — готовый результат сразу.

**Шаблон:**
```
[твой вопрос]
Оформи ответ как: [таблица / нумерованный список / шаблон с полями: ...].
```
«Покрасивее» — не формат. Формат — конкретная структура: таблица, список, шаблон.

## Глава 4 · Капстоун: сборка личного чат-помощника
Для кого: тот, кто прошёл G01 и G02. Результат: один настроенный чат под свою задачу.

Схема: Инструкции (роль+контекст) → Ограничения+формат → Проверка (3 шага из G01, глава 3) →
Помощник готов к работе. Полный рабочий пример такого помощника — глава 5.

**Шаблон сборки** (исправлено: инструкция адресована помощнику, не описывает автора от первого лица):
```
Я [роль], моя задача: [конкретная повторяющаяся задача].
[Контекст, который нужен для этой задачи].
Ограничения: [что нельзя].
Формат ответа: [структура].
Если данных не хватает — спрашивай, не додумывай.
Если задача важная — дай мне два-три разных варианта, не один.
```

## Глава 5 · Полный кейс: помощник для ответов клиентам AlovLab

Учебный пример от начала до конца на вымышленном обращении.

**Входящее сообщение (учебное, не реальный клиент):**
«Здравствуйте! Меня зовут Марина, мой номер +7 999 123-45-67. Веду инстаграм для своей студии
маникюра, около 800 подписчиков. Очень хочу разобраться в нейросетях, но боюсь, что это сложно и
дорого. С чего лучше начать?»

**Что убрать/заменить:**
- Имя «Марина» → убрать → «Клиент А»
- Номер телефона → убрать полностью — не нужен для черновика ответа
- «Студия маникюра, ~800 подписчиков» → оставить — нужный контекст, не чувствительные данные
- «Боюсь, что сложно и дорого» → оставить — это и есть суть вопроса

**Заполненная инструкция помощнику:**
```
Я готовлю черновики ответов клиентам AlovLab (курс «Нейросети и ChatGPT для каждого», Нейромонах Илья Алов).
Клиент А написал: "Очень хочу разобраться в нейросетях, но боюсь, что это сложно и дорого. С чего лучше начать? У меня студия маникюра в инстаграме, около 800 подписчиков."
Составь черновик ответа. Тон простой и спокойный, без канцелярита и без давления.
Не придумывай цену, сроки или состав курса — используй только факты, которые я укажу отдельно.
Факты о курсе: 6 видеоуроков, 6 направлений (Слова, Изображения, Видео, Звук, Аватары, Знания), три тарифа с разным уровнем поддержки, гарантия возврата 14 дней.
Формат: 3-5 предложений, отвечает и на страх "сложно", и на вопрос "с чего начать", заканчивается одним конкретным следующим шагом, без "оплатите сейчас".
Дай два разных варианта, не один.
```

**Куда вставить и как начать:** в тот же настроенный чат-помощник из главы 4 (или новый чат с этой
инструкцией). Цену и точный состав тарифов не храни в инструкции навсегда — сверяй перед каждым
использованием, тарифы могут измениться.

**Вариант ответа 1** (иллюстративный, не результат реального теста):
«Марина, это правда не так сложно, как кажется — большинство начинает с одного простого приёма и
уже через день видит результат. Специально для тех, кто в начале пути, есть модуль «Земля Слов» —
с него удобно стартовать, не тратя сразу много. Расскажите, что для вас сейчас самое узкое место —
тексты, фото для студии или видео?»

**Вариант ответа 2:**
«Марина, страх понятный, почти все с этого начинают. По деньгам всё прозрачно — три уровня
доступа, можно начать с малого и посмотреть, подходит ли формат. По содержанию курс как раз про
такие задачи, как ваши — тексты и визуал для соцсетей студии. Что вам сейчас важнее всего — фото,
тексты постов или видео-контент?»

**Критерии сравнения:** честность про «сложно» (конкретика, не общие слова); аккуратность с ценой
(ни один вариант не называет цифр, которых не было в фактах); один следующий шаг (ровно один
вопрос клиенту в конце).

**Формат результата:** черновик читает и при необходимости правит человек (Илья или менеджер) —
это не автоматическая отправка без просмотра.

**Неудачный ответ:** «Марина, у нас сейчас акция −50%! Курс стоит всего 14 990 ₽, успейте купить
до конца недели, не упустите шанс!» — цена и акция выдуманы (их не было в заданных фактах),
«успейте/не упустите» — давление без подтверждённой срочности.
**Исправление:** убрать цену и акцию полностью, убрать слова давления, оставить открытый вопрос.

**Полный цикл:** обращение → очистка данных → помощник (инструкция+факты) → 2 варианта → сравнение
по критериям → человек правит и отправляет.

## Упражнение
Пройди тот же цикл на другом обращении: «Здравствуйте, интересует автоматизация контента для
нашего бренда, можно подробнее?»
**Образец решения:** ответ честно называет направление (AI-реклама, аватары, автоматизация —
подтверждённые факты), не называет цену Studio (её нет на сайте), заканчивается одним шагом:
«Отправьте бриф — ответим в течение 24 часов».

**Проверка результата:**
- [ ] Личные данные клиента не попали в промпт.
- [ ] В ответе нет цифр/акций, которых не было в заданных фактах.
- [ ] Ответ оставляет ровно один следующий шаг.
- [ ] Сравнил минимум 2 варианта, не взял первый попавшийся.

## Частые ошибки
1. Глава 1: «обезличу потом» — данные уже отправлены к моменту, когда вспомнил.
2. Глава 2: берёшь первый ответ как единственно верный для важного текста.
3. Глава 3: просишь «красивее» вместо конкретного формата.
4. Глава 4: настраиваешь помощника «под всё сразу» — снова обобщённый инструмент.
5. Глава 5: даёшь помощнику придумывать цену/сроки вместо того, чтобы задать факты явно.
