# Трекер метрик — как заполнять

`tracker.csv` — одна строка = одна публикация на одной площадке. Строки для дня 1 (4 площадки)
добавлены как шаблон с пустыми значениями — заполняются по факту публикации и измерения, не
заранее. Новые строки добавлять по той же схеме при выходе каждой публикации (не создавать все
30×4 строк сейчас — это было бы либо пустой таблицей без ценности, либо соблазном подставить
выдуманные числа).

**Колонки:** day, date, publication_id (`OCT-01` и т.д. — совпадает с `calendar.csv`), platform,
reach, views, saves, shares, profile_visits, new_follows, unfollows, net_follow (=new_follows −
unfollows), link_clicks, leads, purchases, revenue, data_source (откуда цифра — обязательно, не
оставлять пустым при заполнении), measured_at (когда снят замер), notes.

**Правило:** пустая ячейка = не измерено, не ноль. Не путать отсутствие данных с нулевым
результатом. `data_source` обязателен при заполнении любой цифры — иначе непонятно, можно ли ей
доверять при разборе на 7/14/21/30 день.
