# 3 дизайн-концепции — сравнение и выбор

> Одинаковый образец контента (G01, глава 1 «Голосовое → сценарий») в трёх системах. Обложка + 1
> содержательная страница на концепцию — этого достаточно, чтобы сравнить читаемость, навигацию и
> удобство практики; полные 3×13 страниц не строил, чтобы не раздувать объём этого исправления.
> Файлы: `concept-b.pdf`/`pages-b/`, `concept-c.pdf`/`pages-c/`. Концепция A — уже существующая
> система (использована в G01/G02 и во всех предыдущих методичках этой сессии), образцы —
> `guides/G01-prompt-pomoshnik/pages/page-01.png` (обложка) и `page-03.png` (контент).

## Концепция A — Editorial Light (действующая)
Тёплая светлая бумага, графитовый текст, оранжевый акцент, карточки с воздухом, тёмная обложка.
Один столбец — весь текст читается сверху вниз без горизонтального скролла.

## Концепция B — Workbook Grid
Едва заметная миллиметровка на фоне, чёрно-белая графика с одним акцентным цветом, шаги в жирных
рамках, чек-боксы для самопроверки, шаблон-промпт — светлая рамка вместо тёмной плашки. Ощущение
рабочей тетради, которую заполняешь, а не читаешь.

## Концепция C — Field Manual
Двухколоночная плотная вёрстка, боковая вкладка-таб с номером главы, моноширинные ярлыки разделов,
засечная гарнитура для основного текста. Высокая плотность информации на странице.

## Сравнение

| Критерий | A · Editorial Light | B · Workbook Grid | C · Field Manual |
|---|---|---|---|
| Читаемость на телефоне | Высокая — один столбец, крупный кегль | Высокая — один столбец, ещё крупнее контраст | **Низкая — две колонки на A4 превращаются в нечитаемо-узкие столбцы при масштабировании под экран телефона** |
| Навигация (где я в главе) | Колонтитул + номер раздела | Крупный номер шага в чёрном блоке — заметнее | Боковая вертикальная вкладка — стильно, но менее считываемо на маленьком экране |
| Удобство практики (шаблоны/самопроверка) | Хорошо (карточки-чек-листы) | **Лучше всех** — чек-боксы прямо в разметке физически приглашают отметить | Средне — плотный текст скорее для чтения, чем для заполнения |
| Соответствие бренду AlovLab | Полное — уже используется во всех методичках, тёплый/премиальный тон из CLAUDE.md Приложение В | Близкое, но чуть более «утилитарно», графическая сетка спорит с «премиальная композиция, минимум шума» | Наименьшее — засечный шрифт и плотная вёрстка не пересекаются с текущей визуальной системой бренда |
| Копируемость текста в PDF | Да (реальный текст, не картинка) | Да | Да |

## Решение

**Выбрана концепция A (Editorial Light)**, с одним заимствованием из B: усилить чек-лист
самопроверки (уже физически существовал как `.callout.check`, дополнительно проверено, что чек-
строки визуально читаются как «отметь», не просто список).

**Почему не B:** реально сильнее по «практике», но пока не выигрывает настолько, чтобы оправдать
полную переверстку всех уже готовых страниц G01/G02 и последующих методичек — цена смены системы
сейчас выше прироста качества, при этом сохраняется свобода вернуться к элементам B (чек-боксы,
рамочные степ-блоки) в будущих месяцах, если понадобится.

**Почему не C:** проигрывает по ключевому и явно заданному критерию — читаемости на телефоне
(двухколоночная вёрстка A4 не масштабируется на узкий экран без горизontального скролла или
нечитаемо мелкого текста). Дисквалифицирующий фактор, не второстепенный.

**Что реально меняется в самой системе A по итогам этого сравнения** (применено в G01/G02, см. их
файлы): убран декоративный чип «СКОПИРОВАТЬ» у тёмных промпт-плашек (в PDF это неработающая
кнопка, вводит в заблуждение) — вместо этого все промпты продублированы в отдельный `prompts.txt`
на каждую методичку; оглавление и внутренние ссылки на страницы теперь реальные кликабельные
PDF-якоря, не просто текст с номером.
