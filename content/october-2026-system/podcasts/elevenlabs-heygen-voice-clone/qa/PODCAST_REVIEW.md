# Самопроверка по 10 критериям (ALOVLAB-PODCAST-ACADEMY.md §12)

- **Хук** — первые секунды: конкретная ситуация (двадцать роликов, нет времени на озвучку), без приветствия и без «сегодня поговорим о».
- **Удержание** — обещание в хуке (запись → клон → видео с аватаром) закрывается явно в конце тем же порядком действий.
- **Практическая польза** — слушатель получает конкретный первый шаг (записать одну минуту речи) и способ оценить результат (4 вопроса на слух).
- **Экспертность** — не очевидные приёмы (сравнение нескольких генераций одного текста, раздельная проверка сложных слов, когда перезаписывать вместо настройки ползунков) вместо банальностей.
- **Понятность новичку** — API объяснён через аналогию «ты сам жмёшь кнопки» / «программа жмёт кнопки вместо тебя», термины введены перед использованием.
- **Естественность речи** — без тире, числа словами, без запрещённых оборотов (найден и убран один случай «важно понимать»), разговорные связки («вот тут начинается самое интересное», «и здесь важное правило») без повтора одной и той же фразы.
- **Логика объяснения** — порядок: что это → как работает → как подготовиться → как сделать → как улучшить → типичные ошибки → итоговый маршрут и задание.
- **Качество примеров** — один развёрнутый пример (блогер, пять сценариев за неделю), подан как условный, без выдуманных личных результатов.
- **Актуальность фактов** — расхождения источников по длине образца голоса не скрыты, явно сказано «по разным источникам»; цены и точные интерфейсные детали не называются как факт.
- **Готовность к ElevenLabs** — `PODCAST_ELEVENLABS_READY.txt` проверен скриптом на отсутствие markdown/скобок-заполнителей/URL; тире встречается только внутри законных составных слов (например «USB-микрофон»), не как разметка пауз.

**Статус:** 1520 слов, расчётная длительность 10.1-11.7 минуты (130-150 слов/мин) — это расчёт, не измерение: тестовая генерация в ElevenLabs в этой сессии не проводилась (нет доступа к аккаунту/API из песочницы). Перед публикацией — сгенерировать реальное аудио и сверить фактическую длительность.

**Открытый пункт:** CTA ссылается на методичку G07, которая на момент записи этого подкаста покрывает только подготовку к записи голоса (батч 1 из ~19 глав) — CTA в тексте скорректирован, чтобы не обещать больше, чем реально готово.
