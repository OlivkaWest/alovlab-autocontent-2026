# Reels на 19.10.2026 — «Этот подкаст ведут два человека. Ни один не существует.»

Ведущий формат дня 19 по календарю (`calendar.csv`, OCT-19). CORE IDEA: подкаст с двумя ведущими
можно собрать без студии и без второго живого человека — один сценарий-диалог и два контрастных
синтезированных голоса. Параллельный формат того же дня — карусель
`content/october-2026-system/carousels-extra/day-19/` (собрана по запросу пользователя).

- `ru/00_START.txt` — тема, честность по источнику и по примеру, CTA, статус методички.
- `ru/01_HEYGEN_AGENT_PROMPT.txt` — готовый промпт для HeyGen-агента, одним сообщением.
- `ru/02_SCENES.txt` — подробная раскладка сцен по секундам.
- `ru/03_VOICE_AND_CAPTIONS.txt` — чистовой войсовер и текстовые вставки.
- `ru/04_SOCIAL_CAPTIONS.txt` — короткие подписи (хук в одно предложение) для IG/TG/VK/YouTube + хэштеги.
- `ru/05_CHECK.txt` — самопроверка перед сборкой.
- `cover/` — обложки RU/EN, 1080x1920.

**Честно:** методичка G07 реестра («Видео и звук для клиента») ещё не написана — CTA не обещает
файл, только личный разбор в комментариях. Тема (AI-подкаст с двумя голосами) — реальная
существующая категория, но сценарий не называет конкретную платформу и не использует непроверенные
2026-детали (см. `00_START.txt`). Сцены без живого скриншота собраны нативной текстовой графикой
HeyGen, не имитацией интерфейса — та же честность, что в дне 16 и в klod-montazh.
