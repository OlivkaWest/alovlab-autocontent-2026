# День 2 (02.10.2026) — дополнительный Reels, помимо карусели

Ведущий формат дня 2 в календаре — **карусель** (`carousels/ru/day-02.md` / `carousels/en/day-02.md`),
она остаётся в календаре без изменений. Этот пакет — **дополнительный рилс на ту же дату**, та же
CORE IDEA («промпт без роли — как письмо без адресата», роль+контекст+ограничения+формат на примере
делового предложения фрилансера кофейне), собран по запросу пользователя от 02.10.2026, отдельно от
записи `calendar.csv` (она не редактировалась).

Собран по `content/rules/ALOVLAB-HEYGEN-REELS-STANDARD-v2.md` (регламент v2.0, с правкой 02.10.2026).

## Структура

- `ru/`, `en/` — по 6 файлов (`00_START` … `05_CHECK`), готовые к сборке в HeyGen Agent.
- `guide/` — методичка, которую отдаём зрителю (переиспользована, не написана заново: G01, глава 2).
- `cover/` — статус обложки. **Не готова как файл** — см. `cover/STATUS.md`, честная причина ниже.

## Главное ограничение этого пакета (сказано прямо, не спрятано)

Higgsfield сгенерировал фон для обложки (реальная генерация, job `35a439d8-b2e4-4bff-9bbb-c4010d9ba540`,
результат по ссылке в `cover/STATUS.md`), но скачать файл в эту сессию и домонтировать логотип+заголовок
не удалось: исходящий трафик на CDN Higgsfield (`*.cloudfront.net`, `upload.higgsfield.ai`) заблокирован
политикой сети этой среды (подтверждено статусом agent-proxy, не догадка). Это не повод сводить весь
пакет к тексту — сценарий, речь, субтитры, методичка и подписи ниже полностью готовы. Обложку нужно
либо доделать вручную по прикреплённому фоновому изображению и спецификации в `cover/STATUS.md`, либо
перегенерировать в сессии без этого сетевого ограничения.
