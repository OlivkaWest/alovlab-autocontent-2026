# Обложка дня 2 (доп. рилс) — ГОТОВО

RU и EN обложки собраны и лежат в этой папке: `cover-ru.png`, `cover-en.png` (1080×1920).

## Как собраны (честно, по шагам)
1. Фон сгенерирован через Higgsfield (модель `gpt_image_2_5`, 9:16): конверт без адреса на тёмном
   деревянном столе — та же метафора, что и на обложке карусели дня 2 («промпт без роли — как письмо
   без адресата»). Job ID `35a439d8-b2e4-4bff-9bbb-c4010d9ba540`.
2. Скачать этот конкретный файл напрямую через `curl`/Higgsfield CDN в этой сессии не удалось —
   исходящий трафик на `*.cloudfront.net` и `upload.higgsfield.ai` блокировала сетевая политика среды
   (подтверждено статусом agent-proxy, `connect_rejected` / 403). Файл стал доступен локально позже,
   когда клиент сам прислал превью этой генерации обратно в сессию как изображение — с этого момента
   реальные байты фонового кадра оказались на диске и их можно было обрабатывать.
3. Заголовок (2–5 слов) и логотип `assets/img/logo-mark.png` наложены локально через Pillow —
   не генератором изображений, чтобы не рисковать искажённым текстом или логотипом. Шрифт — уже
   используемый в проекте Manrope (`assets/fonts/manrope-*.woff2`, конвертирован в TTF через fontTools
   для совместимости с Pillow); для кириллицы — субсет `manrope-cyrillic-800/700`, для латиницы
   (заголовок EN и слово «AlovLab» на обеих обложках) — субсет `manrope-latin-800/700`, так как в
   кириллическом субсете нет строчных латинских букв и части пунктуации.
4. Обе обложки визуально проверены (текст не обрезан, логотип не на конверте, читаемо на телефоне).

## Заголовки
- **RU:** кикер «СВЯЗКА ДНЯ ПРОМПТ КАРКАС», заголовок «ПРОМПТ БЕЗ / АДРЕСАТА» (вторая строка —
  акцентный оранжевый).
- **EN:** кикер «TODAY'S TECHNIQUE», заголовок «A LETTER, / NO NAME» (вторая строка — акцентная).

Портрет Ильи на этой обложке не использован — конверт сам по себе прямо объясняет тему выпуска, как и
просил пользователь; кроме того, в рамках этой сессии не было возможности загрузить референсные фото
в Higgsfield для identity-точной генерации портрета (тот же сетевой блок, см. п.2) — честно
зафиксировано, не подменено синтетическим лицом.
