# День 6 (06.10.2026) — Reels, по запросу пользователя «рилс за 06.10»

Ведущий формат дня 6 в календаре (`calendar.csv`, OCT-06) — **уже Reels**, черновой сценарий существует
(`reels/ru/day-06.md`, `reels/en/day-06.md`). Этот пакет доводит тот же сценарий до полного production
package по `content/rules/ALOVLAB-HEYGEN-REELS-STANDARD-v2.md` (готов к прямой сборке в HeyGen Agent),
тот же принцип, что у `reels-extra/day-02` для дня 2. Запись календаря не менялась.

ТЕМА: «Не проси «покрасивее». Проси формат.» — один и тот же запрос к нейронке без указания формата
(стена текста, читать можно, использовать нельзя без ручной переделки) и с одной добавленной строкой
«оформи как таблицу» (готовый к использованию результат сразу).

## Структура

- `ru/`, `en/` — по 6 файлов (`00_START` … `05_CHECK`), готовые к сборке в HeyGen Agent.
- `guide/` — методички, которые отдаём зрителю: `workbook.pdf` (20 страниц, углублённая, по
  отдельному запросу «методичку обьемную... с проптами и скриптами» — 3 формата, 5 скриптов,
  advanced-связка) и `G02-format-i-tochnost-workbook.pdf` (короткий реюз, ровно по примеру рилса).
  Детали обоих — `guide/README.md`.
- `cover/` — готовые обложки `cover-ru.png` / `cover-en.png` (1080x1920). Как собраны — `cover/STATUS.md`.

запятая, новое предложение.
