# Методичка для этого рилса — два файла, разного объёма

## `workbook.pdf` (20 страниц) — углублённая версия, основной файл для выдачи зрителю

По явному запросу пользователя («методичку обьемную... с проптами и скриптами») собрана отдельная,
более глубокая методичка «Формат ответа: промпты и скрипты», которая расширяет один приём из рилса
(добавить «оформи как таблицу») в систему: 3 полных рабочих промпта на разные типы формата
(таблица, список, шаблон с полями), библиотека из 5 готовых скриптов-концовок под частые ситуации
(ответ клиенту, контент-план, сравнение вариантов, статус задачи, короткая версия для сторис),
advanced-связка формата с ролью и контекстом (мост к методичке G01). Собрана скриптом
`scripts/guide_day06_format_build.py`, той же системой A4-страниц, что и остальные методички проекта.
`prompts.txt` рядом — все 3 промпта, advanced-промпт и все 5 скриптов текстом, копипаст-готовые.

Это файл, который реально отдаётся по CTA «напиши ФОРМАТ в комментариях» (см. `../ru/04_SOCIAL_CAPTIONS.txt`).

## `G02-format-i-tochnost-workbook.pdf` (20 страниц, 14 содержательных) — лёгкий реюз, привязан к записи календаря

Точная копия уже существующей методички `content/october-2026-system/guides/G02-format-i-tochnost/workbook.pdf`.
Глава 3 (страницы 5-6): «Как управлять форматом ответа» + «Шаблон формата» — тот самый один приём на
одном примере, который показывает сам рилс. Совпадает с записью календаря дня 6 (`calendar.csv`,
`guide_id: G02`). Повторное использование подходящей готовой методички допустимо по
`content/rules/ALOVLAB-HEYGEN-REELS-STANDARD-v2.md` §8.

Оставлен в пакете как более короткая альтернатива, если кому-то нужна только версия ровно по рилсу,
без расширения в систему.
