# Reels · «Монтаж теперь делает Клод»

Отдельный Reels вне календаря (по прямому запросу: «собери рилс о том что теперь весь монтаж делает
Клод»). CORE IDEA: финальную сборку видео (нарезка, синхрон голоса, титры, экспорт) теперь делает
AI-агент по командам Ильи — он ставит задачу, агент выполняет, Илья проверяет результат. Прямой
сиквел к уже доказанному топ-ролику месяца «Claude монтирует видео. Сам» (CLAUDE.md §2).

- `ru/00_START.txt` — тема, оценка 0-10 по 10 критериям, CORE IDEA, хук, GUIDE/COURSE/B2B connection.
- `ru/01_HEYGEN_AGENT_PROMPT.txt` — готовый промпт для HeyGen-агента, одним сообщением.
- `ru/02_SCENES.txt` — подробная раскладка сцен по секундам.
- `ru/03_VOICE_AND_CAPTIONS.txt` — чистовой войсовер и текстовые вставки.
- `ru/04_SOCIAL_CAPTIONS.txt` — короткие подписи (хук в одно предложение) для IG/TG/VK/YouTube + хэштеги.
- `ru/05_CHECK.txt` — самопроверка перед сборкой.
- `cover/` — обложки RU/EN, 1080x1920.

**Честно:** отдельной методички-туториала под эту тему нет (см. открытый пункт в `00_START.txt` и
`05_CHECK.txt`) — тема про процесс работы с Claude Code, а не про инструмент с интерфейсом вроде
ElevenLabs/HeyGen, и полноценный учебник по ALOVLAB-ACADEMY-STANDARD под неё — отдельная задача.
Сцены без реального интерфейса (3-4) собраны нативной текстовой графикой HeyGen, не имитацией
скриншота — та же честность, что в дне 16.
