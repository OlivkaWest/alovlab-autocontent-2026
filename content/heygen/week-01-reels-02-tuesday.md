## 3. Режиссёрские указания для Video Agent

- Формат 9:16, длительность 28–31 сек. Аватар НЕЙРОМОНАХ, голос доктор Нейро.
- Тон: спокойный наставник с внутренней силой. Без крика, без наигранной эмоции.
- Паузы: держать после «Это и есть твоя ошибка» и после «Это конвейер».
- Аватар в кадре: 0–8 сек (удар + конфликт + мостик), 24–31 сек (вывод + CTA). Середина 8–24 — скринкаст, голос поверх.
- Субтитры: снизу, крупно, жирным. На экране — только выделенные слова из колонки «Текст на экране», не весь текст.
- Акцент — оранжевый, на одном слове-ударе за кадр.
- Ритм: новый импульс каждые 3–5 сек (смена плана / скринкаст / титр / таблица).

## 4. Дополнительные кадры (B-roll — подготовить отдельно)

1. Пустой документ с мигающим курсором (2–6 сек, «о чём снимать»).
2. Скринкаст-связка: Claude выдаёт список углов → сценарий по секундам → кадр по референсу (8–19 сек). Показать реальную строку промпта.
3. Готовая таблица контент-плана на неделю, 5 строк (19–24 сек).
4. Короткая перебивка: пальцы листают готовые посты в галерее (по вкусу).

> Ты придумываешь пост каждый день. Это и есть твоя ошибка.

> Контент встаёт не на съёмке. Он встаёт на вопросе «о чём снимать». И пока ты решаешь его каждый день заново — ты стоишь на месте.

>
> Это и есть суть: конвейер, а не генерации.
>
> Связку с промптами выложил в Telegram — забирай в профиле.
