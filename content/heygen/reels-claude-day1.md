## 3. Режиссёрские указания

- Формат 9:16, 33–34 сек. Аватар НЕЙРОМОНАХ, голос доктор Нейро.
- Тон: спокойный, чуть удивлённо-довольный на «результат открывается сам». Без хайпа и восклицаний.
- Паузы: держать после «Кода — ноль» и после «Я только подтверждаю».
- **avatar_scene:** 0–3, 8–14, 31–34 — лицо чистое, никакой UI/текст не перекрывает лицо, глаза, рот.
- **non_avatar_scene (Seedance):** 3–8, 14–27, 27–31 — всё оживает ВНУТРИ экрана/терминала. Не статик, не скриншот, не overlay, не slideshow, не зум.
- Ключевой приём: зритель видит **и метод (пишу словами → план → шаги), и результат (пусто → готово)** — не абстракция.
- Тёплый свет нарастает к финалу; на скрин-сценах самый яркий источник — только экран.
- **Честность:** показываем реальный процесс Claude Code (план → шаг → подтверждение → результат). Никаких выдуманных «за 3 секунды» и фейковых цифр; «десять минут» — образно про быстрый первый результат, не замеряем.
