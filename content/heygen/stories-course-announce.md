## Общие правила

- Аватар: **НЕЙРОМОНАХ**. Голос: **«доктор Нейро»**, русский.
- Формат: **1080×1920 (9:16)**. Длительность **27–32 сек**, 5 сцен по 5–7 сек.
- Аватар только в **сценах 1 и 5**. Сцены 2–4 — визуальный B-roll / motion graphics + закадровый голос.
- Стиль AlovLab: почти чёрный фон, тёплый оранжевый акцент, белая типографика. Premium education, clean, cinematic — без дешёвого инфобизнес-визуала.
- Логотип: настоящая оранжевая буква **A** AlovLab.
- На экране максимум **одна главная мысль за сцену**.
- Никаких пустых карточек, абстрактных плашек, бессмысленных иконок. Каждый визуальный элемент показывает реальный смысл сцены.

## СЦЕНА 1 · 0–5 сек
**Озвучка:** «Ты уже видел, как нейросети делают работу за меня. Теперь научись сам.»
**Визуал:** крупный план НЕЙРОМОНАХА, взгляд в камеру, тёмный премиальный фон. За спиной очень мягко — короткие «дорогие» вспышки реальной AI-работы: текст · изображение · видео · аудиоволна · AI-аватар · исследование. Не яркий коллаж.
**Титр:** `6 ЗЕМЕЛЬ ИИ` (6 — оранжевым). Мелко: `от первого запроса → до готового результата`. Пауза после «Теперь научись сам.»

## СЦЕНА 2 · 5–11 сек
**Озвучка:** «Шесть Земель: слова, картинки, видео, звук, аватары, знания. От нуля до результата.»
**Визуал:** НЕ шесть пустых карточек с иконками — реальная сетка из 6 мини-сцен:
1. **СЛОВА** — реальный интерфейс AI-чата: запрос → структурированный текст.
2. **ИЗОБРАЖЕНИЯ** — до/после: обычный референс → сильный фотореалистичный AI-визуал.
3. **ВИДЕО** — статичный кадр → короткий cinematic movement.
4. **ЗВУК** — реальная waveform + голосовая дорожка.
5. **АВАТАРЫ** — человек/фото → говорящий digital avatar.
6. **ЗНАНИЯ** — несколько источников → структурированный research/документ.
Подсветка движется по каждому блоку синхронно с озвучкой.
**Титры:** `СЛОВА → ИЗОБРАЖЕНИЯ → ВИДЕО → ЗВУК → АВАТАРЫ → ЗНАНИЯ`. В конце: `6 навыков → одна система`.
**Анимация:** каждая из 6 карточек **проявляется и загорается по очереди**, синхронно со словом озвучки (слова → карточка 1, картинки → 2, видео → 3, звук → 4, аватары → 5, знания → 6). Появление — лёгкий подъём снизу + fade + оранжевое свечение рамки на активной карточке (0,3–0,4 сек). Внутри активной карточки играет микро-переход «до → после»: стрелка заполняется, второй кадр/результат проявляется. К концу сцены все 6 остаются на экране и мягко «собираются» к подписи `6 навыков → одна система`.

## СЦЕНА 3 · 11–17 сек
**Озвучка:** «Простыми словами. С нуля. Даже если ни разу не открывал нейросеть.»
**Визуал:** путь новичка. Слева — чистый ноутбук с пустым AI-чатом, метка `0 опыта`. Стрелка. По центру — первый простой запрос. Справа — готовый результат (текст · картинка · небольшой видео-фрагмент), метка `первый результат`.
**Главный титр:** `С НУЛЯ. БЕЗ ТЕХНИЧЕСКОГО ЯЗЫКА.` Мелко: `открыл → повторил → получил результат`. Смысл понятен за 1 секунду, без сложных UI-схем.
**Анимация:** три карточки шагов появляются **последовательно сверху вниз** (0 опыта → первый запрос → первый результат), синхронно с «открыл → повторил → получил результат». Каждая всплывает снизу + fade (0,3–0,4 сек), между карточками **дорисовывается стрелка ↓**. На карточке «первый запрос» печатается текст запроса; на «первый результат» кадры (текст/картинка/видео) проявляются друг за другом, рамка загорается оранжевым. Финальная карточка держит акцент дольше.

## Анимация карточек (общие правила)

- **Каждая карточка/ячейка анимируется** — не появляется всё сразу. Порядок появления всегда синхронен с озвучкой (слово → своя карточка).
- Тип движения: лёгкий подъём снизу (8–14 px) + fade-in, **ease-out, 0,3–0,5 сек** на карточку, между соседними — задержка ~0,15–0,25 сек (каскад).
- Активная/текущая карточка — тонкое оранжевое свечение рамки; предыдущие остаются на экране (не исчезают), просто гаснет акцент.
- Внутренние элементы (чипы тарифа, кадры результата, стрелки «до→после», стрелки ↓) проявляются вслед за своей карточкой, а не одновременно.
- Микро-движение живёт постоянно: очень медленный параллакс/дыхание фоновых «искр», лёгкий drift — кадр не статичный «стоп».
- **Нельзя:** резкие мигания, отскоки (bounce), кручение, вылет за экран, дёрганье, более 1 акцента в кадре одновременно. Движение поддерживает смысл, а не украшает.
- B-roll-кадры (сцены 2–4) отданы как статичные PNG 1080×1920 — анимацию карточек накладывать поверх них в HeyGen/редакторе по этому таймингу.
