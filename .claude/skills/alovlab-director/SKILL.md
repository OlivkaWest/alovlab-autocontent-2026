# alovlab-director

Отвечает не за красивый prompt, а за весь ролик. Правило: **одна сцена доказывает
одну мысль.**

## Вход
сценарий · контент дня · персонаж · доступные материалы · генераторы · длительность · площадка.

## Выход (director_plan_vN.json)
визуальная концепция · главный образ · визуальный конфликт · ритм · список сцен ·
крупности · движения камеры · свет · звук · переходы · роль аватара · роль B-roll · финальный кадр.

## Движение и переходы
Спокойное движение: slow push-in, лёгкий pan, аккуратный zoom на ключевую фразу,
последовательное появление блоков. Переходы: склейка, короткий dissolve, match cut.

Запрещено: вращение карточек, летящий текст, глитчи, кубы, перелистывание, вспышки
между каждой сценой, кислотные эффекты, дешёвые zoom-переходы.

## Экран
Один экран — одна мысль. Не показывай одновременно полный текст карточки + длинные
субтитры + заголовок + интерфейс + логотип. Карточка должна оставаться читаемой.
