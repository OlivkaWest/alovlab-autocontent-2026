# alovlab-audio-edit

Монтаж аудио локально, безопасно (массив аргументов FFmpeg, без shell-строки).
Реализация — `automation/src/video/ffmpeg.ts` (`buildAudioConcatArgs`, `synthSilentMp3`).

## Сборка
- склейка сегментов ElevenLabs в полную дорожку;
- интро в начале, аутро в конце, отбивки между главами;
- фоновая музыка **тише голоса**, не под весь выпуск, если утомляет;
- паузы по смыслу, fade-in/fade-out, нормализация громкости.

## Музыка
Приоритет: трек из контент-плана → трек дня → общая библиотека → нейтральный фон.
Нет подходящей — собираем без музыки, это не ломает пайплайн.

## Проверка
файл открывается · нет тишины в начале · нет обрезанных слов · громкость стабильна ·
голос громче музыки · длительность по сценарию.

## Только аудио
Меняется музыка/паузы/громкость — **не** перезапускай ElevenLabs, только пересборка.
