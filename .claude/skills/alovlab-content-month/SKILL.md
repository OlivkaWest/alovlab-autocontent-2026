# AlovLab — 30-дневный план мини-уроков (управление)

Работает с планом(ами) в `content/plans/YYYY-MM-DD_30-days/`. Если план не создан — не выдумывать
структуру заново, а собрать по системе, зафиксированной в `content/plans/2026-09-29_30-days/`
(эталон): `README.md` (индекс) + `strategy.md` + `calendar.md`/`.csv`/`.xlsx` + `sources.json` +
`production-manifest.json` + `days/day-NN/{reel.md, heygen-prompt.txt, carousel-ru.md,
carousel-en.md, workbook.md, workbook.docx, workbook.pdf, telegram.md, quality-check.md}`.

## Команды

**«Покажи контент-план на месяц»** → прочитать `calendar.md` актуального плана, вывести компактную
таблицу, назвать реальный статус (сколько дней написано/экспортировано/запланировано) из
`production-manifest.json` — не выдавать календарь тем за готовые уроки.

**«Дай полный пакет на дату»** → найти день в `calendar.csv`, если файлы уже существуют — открыть
и показать; если только запланирован — собрать по образцу `days/day-01/` этого же плана (эталонная
структура методички — все разделы А–О из `workbook.md` дня 1, PDF-сборщик — по образцу
`scripts/guide_30days_day01_build.py`, DOCX — `scripts/md_to_docx_workbook.py <md> <docx> "<тема>"`).
Обновить `production-manifest.json` по факту после сборки.

**«Обнови тему перед публикацией»** → для дней с `update_required: true` в `production-manifest.json`:
проверить пункты из `sources.json` (что именно нужно перепроверить), при необходимости заменить на
резервную тему блока (`sources.json` → `reserve_topics_by_block`), синхронно переписать Reels,
карусель, методичку, описание и CTA — не только заголовок.

**«Проверь готовность методичек»** → пройтись по `production-manifest.json`, для каждого дня со
статусом отличным от «запланирован» — свериться, что все файлы реально существуют на диске (путь
в манифесте не гарантирует существование файла, только заявленный статус — не путать одно с другим).

## Связь с alovlab-reels-today

Разные задачи: `alovlab-reels-today` ищет разовую свежую тему на конкретный день вне месячного
плана (реальные новости/тренды). `alovlab-content-month` работает со структурированным 30-дневным
планом мини-уроков. Если пользователь просит тему на сегодня и сегодня совпадает с днём из активного
30-дневного плана — сначала предложить пакет из плана, `alovlab-reels-today` — для дней/тем вне плана.

## Честность (обязательно)

- Статус «написан» ≠ «опубликован». Никогда не менять статус на «опубликован» без явного
  подтверждения пользователя, что публикация реально произошла.
- Не собирать 30 дней одним проходом ради скорости — работать пакетами по 5–7 дней, сохранять
  каждый пакет в файлы, обновлять манифест по факту, не заранее.
- Не заменять тему без пометки `update_required` без явной причины — синхронно менять все файлы дня.
- Голос, запреты, цены курса — из `CLAUDE.md` (корень репозитория), не дублировать здесь.
