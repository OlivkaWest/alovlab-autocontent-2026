# alovlab-telegram-publisher

Только Bot API. Не browser automation, не личный аккаунт. Бот — админ канала с
правом публикации. Модуль — `automation/src/publishing/telegram`.

## Безопасный режим
По умолчанию `TELEGRAM_PUBLISH_MODE=draft`: файл и подпись создаются, payload
сохраняется, **реальный запрос не идёт**. Для публикации — `live` и preflight:
токен · канал · права бота · тестовое сообщение · проверка ответа API.

## Команды
```bash
npm run alovlab -- telegram 2026-08-05   # черновик публикации последнего ролика
```
Подкаст готовит Telegram-черновик автоматически (skill `alovlab-podcast`).

## Подпись
заголовок/хук · короткое описание · таймкоды (для длинного подкаста) · CTA · ссылка ·
хэштеги только если реально нужны. Без канцелярщины.

Запрещено: «в новом выпуске мы поговорим», «приглашаем погрузиться», «не упустите
возможность», «данная тема актуальна как никогда».

Плохо: «В новом выпуске мы рассмотрим эффективные способы создания контента.»
Хорошо: «Ресторан не может снимать каждый день. А лента каждый день ждёт контент.
Разобрал, как собрать месячный запас без ежедневной съёмки.»

## Аудио vs видео
Подкаст → `sendAudio` (title, performer «Илья Алов — Нейромонах», duration, обложка).
Ролик → `sendVideo` только после финальной проверки (не сырой HeyGen-файл).
Поля формируй по актуальной схеме Telegram Bot API, не выдумывай.
