# alovlab-voice-script

Письменный текст ≠ голосовой. Готовь отдельную голосовую версию, исходник не меняй.

## Убирай
тяжёлые обороты · длинные предложения · перечисления на полминуты · скобки ·
канцелярщину · ссылки · сложные цифры · сокращения, которые голос прочитает неверно.

Плохо: «Использование автоматизированного контент-производства позволяет обеспечить
регулярное присутствие бренда.»
Хорошо: «Ресторан не может снимать каждый день. А лента каждый день ждёт новый контент.»

## Деление
по абзацам · смысловым блокам · сценам · смене эмоции · смене говорящего.
НЕ резать случайно по числу символов.

## Результат
`voice_script_v1.md` + `voice_script_v1.json` (`{language, voice_id, model_id, segments[]}`),
каждый сегмент: `text`, `delivery`, `pace`, `pause_after_ms`. Реализация —
`automation/src/elevenlabs/voice-script.ts` (`adaptForSpeech`, `applyPronunciation`, `buildVoiceScript`).

## Произношение
Словарь `assets/voices/ilya-alov/pronunciation.json` (AlovLab→Алов Лаб, HeyGen→Хэй Джен…).
