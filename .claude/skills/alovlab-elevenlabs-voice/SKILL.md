# alovlab-elevenlabs-voice

Главный голос проекта — постоянный `ELEVENLABS_VOICE_ID` (клон «доктор Нейро»).
**Не подменять другим голосом, не клонировать заново, не брать случайный из библиотеки.**

## Перед генерацией
1. Проверь голос: существует ли `voice_id`, доступен ли, говорит ли по-русски.
   Нет → «Голос ElevenLabs не найден. Проверь ELEVENLABS_VOICE_ID.»
2. Адаптируй текст под речь (skill `alovlab-voice-script`): убери ссылки, скобки,
   канцелярщину; примен~ словарь произношения `assets/voices/ilya-alov/pronunciation.json`.
3. Голос и настройки — из `assets/voices/ilya-alov/` (Voice Bible + settings.json).

## Команда CLI
```bash
npm run alovlab -- voiceover 2026-08-05   # озвучка сценария дня → reels/audio/full_reels.mp3
```

## Проверка качества (перед монтажом)
нужный voice_id · узнаваем · русский без акцента · нет щелчков · нет обрезанных слов ·
нет длинной тишины · темп по сценарию · паузы по смыслу · имена сервисов верно.
Не прошло → `voice_review_failed`, в финал не идёт.

## Перегенерация одной реплики
Меняешь одно слово/фразу/произношение — **не** гони всё заново. Перегенерируй
сегмент, пересобери дорожку (и видео, если сегмент в ролике), новая версия.

## Режимы с HeyGen
- Режим A: голос от HeyGen (если качество/синхрон устраивают).
- Режим B (по умолчанию для нейромонаха): голос ElevenLabs → мастер-дорожка монтажа
  поверх B-roll. Полный lip-sync аватара к ElevenLabs-аудио требует загрузки аудио
  в HeyGen как asset — сверь актуальный HeyGen API, не выдумывай endpoint.
