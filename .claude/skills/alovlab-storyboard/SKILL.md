# alovlab-storyboard

Разбивает сценарий на сцены и назначает каждой генератор.

## На каждую сцену
номер · длительность · тип кадра (avatar/broll) · действие · текст на экране ·
звук · переход · движение камеры · генератор · промпт · fallback.

## Маршрутизация генератора (автовыбор)
- **heygen** — в кадре говорит Нейромонах (хук, реплики, финал, CTA). Fallback: нет
  (аватар не подменяем чужим персонажем).
- **higgsfield** — есть готовый кадр, надо оживить (image-to-video). Fallback: grok.
- **grok** — готового кадра нет, нужна новая сцена (text-to-video). Fallback: higgsfield.
- **ffmpeg** — хватает карточки/push-in, генерация не нужна (кредиты не тратим).
- **existing_asset** — для сцены уже есть готовое видео дня.

Не генерируй видео ради генерации. Простой push-in по карточке → FFmpeg.

## Результат
`reels/storyboard_vN.json` + `reels/generation_plan_vN.json` (маршруты, промпты, модели).
Модель Higgsfield выбирается ПОСЛЕ проверки доступных моделей через MCP, не наугад.
