# AlovLab — свежие темы для Reels (повторяемый режим)

Команда: `/alovlab-reels-today`. Срабатывает и на естественные формулировки из description выше.

## Что делает при каждом запуске

1. **Заново определяет текущую дату** — не берёт дату из прошлого запуска.
2. **Проверяет историю** — читает `content/reels/history.jsonl`, чтобы не повторять уже
   предложенные темы без новых оснований (новое событие/цифра — можно, то же самое — нет).
3. **Ищет реальные источники** через WebSearch/WebFetch: свежие (24ч–7дн) новости и релизы,
   плюс эвергрин-факты как фон. Честно категоризирует находки:
   - **A** — подтверждённый интерес (несколько независимых публикаций с видимыми метриками);
   - **B** — ранний сигнал (сильный пример/новость, интерес аудитории не подтверждён);
   - **C** — редакционная гипотеза (полезный факт, просмотры не проверены).
   Категорию C никогда не выдавать за подтверждённый тренд.
4. **Честно фиксирует ограничение инструментов**: в этой среде нет прямого доступа к статистике
   Instagram/TikTok/YouTube (нет API/браузера с логином) — просмотры конкретных роликов почти
   всегда недоступны, это не повод пропускать проверку, а факт, который нужно проговорить.
5. **Отбирает до 10 тем** по критериям: свежесть, соответствие аудитории AlovLab, возможность
   показать результат, пригодность для аватара в HeyGen, отличие от уже опубликованного
   (сверка с `content/strategy/CONTENT-PLAN.md` и `content/reels/history.jsonl`).
6. **Готовит 3 полных production-пакета** для лучших тем — структура ниже.
7. **Сохраняет результат** в `content/reels/YYYY-MM-DD/{brief.md,sources.json,scripts.md}`
   и дописывает строку в `content/reels/history.jsonl`.

## Структура каждого production-пакета

Хук (3 варианта, один выбран с обоснованием) → чистая озвучка одним блоком (без тире,
живая русская речь, без стоп-листа CLAUDE.md §8) → таблица сцен (время/тип/визуал/речь/звук)
→ Seedance-промпты для не-аватарных сцен (Приложение Г CLAUDE.md — никаких статичных оверлеев,
скриншотов, слайд-шоу) → единый master prompt для HeyGen → обложка (заголовок 2–5 слов +
визуальная идея, без генерации изображения на этом этапе) → короткое описание (300–400 знаков,
один CTA) → одно целевое действие.

CTA по умолчанию — Telegram (`content/rules/TELEGRAM-FUNNEL-CTA.md`), если нет отдельно
подтверждённой пользователем активной акции с ценой/дедлайном для конкретного ролика.

## Голос и запреты

Полностью наследуются от `CLAUDE.md` (корень репозитория) и `.claude/skills/alovlab-content/SKILL.md`
— не дублировать их здесь. При конфликте приоритет у `CLAUDE.md`.

Дополнительно для этого скилла: не приписывать Илье личный опыт/кейсы, которых нет в материалах
(«я протестировал», «мои ученики заработали») — только формулировки, которые не требуют
непроверяемого личного факта.

## Внешние скиллы

Проверять по запросу через прямую ссылку на SKILL.md, фиксировать автора/лицензию/commit SHA
в `docs/reels-skills-manifest.md`. Не устанавливать automatически без явного запроса пользователя —
это автозагружаемый код, риск оправдан только точечным запросом, не количеством.
