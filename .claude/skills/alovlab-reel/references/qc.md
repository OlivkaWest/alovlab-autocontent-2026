# QUALITY CONTROL — финальная критика до рендера (роль QC)

Прогоняй готовый ролик по метрикам. **Любая метрика < 9/10 → не отдавай, сначала переделай
слабое место**, потом пересчитай.

## Метрики (1–10)
- **HOOK** — удар первых 2 секунд: рождает внутреннее «чего?», незакрытый вопрос, разворот.
- **RETENTION** — есть ли причина смотреть следующий кадр; каждый кадр обещает следующий.
- **VOICE** — живой ли текст; ни одной запрещённой формулировки; говорит с одним зрителем.
- **VISUAL PROOF** — доказывает ли визуал слова; каждая реплика имеет кадр-доказательство.
- **PREMIUM LOOK** — уровень блогера-миллионника / дорогого продакшена, не презентация из карточек.
- **CLARITY** — понятно ли без звука по одному визуалу.
- **CTA** — понятно ли, что получит человек, и куда идти (Telegram/бриф).

## Три обязательных теста
1. Убери звук → история читается по визуалу.
2. Убери визуал → текст звучит как живая речь.
3. Сложи → маленький рекламный фильм, а не обучающее слайд-шоу.

## Честность-чек (§0 — блокирующий)
- Нет выдуманных цифр/цен/сумм/«N мест»; результат формой или реальной цифрой из практики.
- ИИ показан реальным актуальным интерфейсом; места «настоящий экран» помечены REAL SCREEN RECORDING.
- Логотип — настоящий знак; кадры — концепт-дизайн, не «результат клиента».
Любой провал честности → стоп, переписать, даже если остальные метрики 10/10.

## Типичные провалы и правки (быстрый список)
- Хук-заголовок вместо фразы человека → переписать разговорно, вынести конфликт в первое слово.
- Реплика без кадра-доказательства → придумать действие/объект или вырезать секунду.
- Пустая UI-карточка / generic AI visual как основной визуал → заменить действием/реальным экраном.
- Один приём кадра >2 раз → заменить технику (human/macro/screen/object/architecture/documentary/product/environment).
- Текст «плывёт» в Seedance-UI → вынести читаемый текст в нативные карточки HeyGen.
- CTA размазан («лайк, подписка, коммент, тг») → одна строка, один шаг.

## Итог
Выведи оценку по каждой метрике + вердикт по трём тестам + честность-чек. Только когда всё ≥ 9
и честность пройдена — «к отдаче готов».
