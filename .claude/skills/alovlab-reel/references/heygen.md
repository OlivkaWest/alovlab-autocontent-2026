# HEYGEN — сборка сцен и синхронизация (роль HEYGEN)

Как превратить сценарий в бриф для **HeyGen Video Agent** (Seedance встроен в агент).

## Базовые настройки диалога
Авто · Вертикальная · **Seedance Вкл**. Аватар: **НЕЙРОМОНАХ**. Голос: **доктор Нейро** (рус).
Формат 9:16, 30–32 сек. В озвучке «Клод» / формула словами («два-один-один-один»); на титре
«Claude» / «2:1:1:1».

## Три слоя «живого» кадра
1. **Аватар** — говорящая голова только в хуке / развороте / CTA.
2. **Нативная анимация HeyGen** — каждый титр/фигуру/glow-плашку клади отдельным элементом,
   вешай Entrance (Fade/Slide/Pop) с ручным Start time по слову-триггеру. Это и есть подсветка.
3. **B-roll Seedance** — генерит сам агент по промптам из роли SEEDANCE. Текст/UI в кадре
   Seedance «плавит» → используй нативные карточки HeyGen для любого читаемого текста, а
   Seedance — для физики (свет, вода, движение, объекты).

## Подсветка по словам
Соберни голос первым, включи waveform, ставь Start time каждого элемента по слову-триггеру.
Активный элемент — orange-контур + яркость 1 + scale ~1.03; неактивный — тускло (0.4);
пройденный — читаемый без glow. Один акцент за бит. После перечисления — pull-out + общий слабый glow.

## Реальный интерфейс
Где сценарий говорит «Клод собирает …», «показываю в Claude» — это **REAL SCREEN RECORDING
REQUIRED**: запись настоящего актуального интерфейса Anthropic, 9:16-кроп, 6–10 сек. Seedance
и «фейковый UI» это НЕ заменяют. Подсветку зон/строк накладывай поверх реальной записи в HeyGen.

## Субтитры
Крупные, жирные, снизу; активное слово — orange; одно акцент-слово на бит (список — из колонки
«текст на экране» сценария).

## Переходы
whip / джамп / резкий cut между сценами (не диссолв, кроме осознанных случаев по еде/атмосфере).

## Media assets, которые обычно грузим
- Аватар Нейромонах; голос доктор Нейро.
- `Лого1.jpg` (знак A) — только финал.
- REAL SCREEN RECORDING (там, где показываем Claude).
- B-roll клипы (генерит агент через Seedance) или готовые.
- Нативные карточки для любого читаемого текста в кадре.
- Бренд: orange `#E8672A/#FF8A3D`, жирные субтитры.

## Инструкция агенту — структура
Глобально (формат, тон, аватар только хук/разворот/CTA, подсветка, переходы, «Клод»/титр) →
посценно (реплика + что генерит Seedance / что реальный экран / что нативные карточки + что
подсвечивается на каком слове + субтитр) → вставить чистую озвучку → тайминги подсветки по waveform.
