# alovlab-reel — оркестратор производства по дате

Всё производство идёт через CLI в `automation/` (без веб-приложения). Аватар —
только Нейромонах (HeyGen). B-roll — Higgsfield (MCP) / Grok (xAI) / FFmpeg.
Монтаж — FFmpeg. Секреты только в `automation/.env`.

## Распознавание даты
«5 августа» → `2026-08-05` (год берётся из текущей даты проекта). Никогда не
выбирай случайный день. Если контента на дату нет — скажи прямо:
«На <дата> материал в контент-плане не найден.»

## Команды CLI (запускай из папки automation)
```bash
npm run alovlab -- doctor              # статус HeyGen/Grok/Higgsfield/FFmpeg
npm run alovlab -- content 2026-08-05  # показать материал дня
npm run alovlab -- script  2026-08-05  # только сценарий + сцен-план (без HeyGen)
npm run alovlab -- scenes  2026-08-05  # показать сцен-план
npm run alovlab -- route   2026-08-05  # маршрутизация сцен по генераторам
npm run alovlab -- reel    2026-08-05  # ПОЛНЫЙ цикл → готовый MP4
npm run alovlab -- assemble 2026-08-05 # пересобрать монтаж (без HeyGen)
npm run alovlab -- regen-scene 2026-08-05 2   # перегенерировать одну сцену
npm run alovlab -- status  2026-08-05  # статус дня
```

## Полный цикл «Сделай ролик на <дата>»
1. `content <дата>` — найти материал дня. Нет → остановиться и сказать прямо.
2. Сценарий (skill `alovlab-reels-script`): хук, одна мысль, 5 сцен, живая речь.
3. Проверка стиля: ни канцелярщины, ни шаблонных AI-фраз, ни приветствий.
4. Режиссура (`alovlab-director`) + раскадровка (`alovlab-storyboard`).
5. Маршрутизация сцен (`route`): heygen / higgsfield / grok / ffmpeg.
6. Character Lock (`alovlab-character-lock`) для всех сцен с Нейромонахом.
7. Генерация: HeyGen (аватар) + Higgsfield/Grok (B-roll) или mock.
8. Монтаж FFmpeg: 9:16, голос поверх B-roll, субтитры, логотип в финале.
9. Проверка финала (ffprobe): 1080×1920, видео+аудио, длительность.
10. Video Review (`alovlab-video-review`). Отчёт с путём к MP4.

## Правила
- Не говори «ролик готов», если собран только сценарий или файл не прошёл проверку.
- Не говори «HeyGen подключён», если реальный запрос не прошёл (в mock так и пиши).
- Меняется только монтаж → НЕ перезапускай HeyGen (`assemble`).
- Версионируй: `reels_script_vN.json`, `final_reels_vN.mp4`. Удачное не перезаписывай.

## Mock
`HEYGEN_MOCK_MODE=true` / `XAI_VIDEO_MOCK_MODE=true` — весь путь без ключей и трат.
Не выдавай mock за реальную интеграцию.
