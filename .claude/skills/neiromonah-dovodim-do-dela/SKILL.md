# Нейромонах. Доводим до дела — ежедневный Reels-сериал

Полное правило — `content/rules/NEIROMONAH-DOVODIM-DO-DELA.md`. Действующий план —
`content/dovodim-do-dela/plan/AlovLab_Reels_30_days.xlsx` (+ `plan-30-dney.csv`,
`production-notes.md`). **С 22.10.2026 заменяет `content/october-2026-system/calendar/calendar.csv`**
как активный ежедневный план — старая система остаётся архивом, не продолжается.

## Команда

**«Рилс дня»** (+ опционально номер дня или дата) — выдать готовый сценарий-блок для копирования в
HeyGen Video Agent без доработки, по формату §8 правила. Больше никаких других команд этот скилл не
вводит — это не `/reel`/`/reel-duo` (те принадлежат `alovlab-heygen-director` и действуют для
остального контента AlovLab, не для этого сериала, если явно не попросят).

## Как работать

1. Разрешить день по приоритету §1 правила (номер → дата → текущая московская дата). Если дата вне
   периода 22.10-20.11.2026 или команда дана без дня/даты и текущая дата неизвестна — задать один
   короткий вопрос, не выбирать день наугад.
2. Взять строку плана из `plan-30-dney.csv` (поля: День/Дата/Формат/Тема/Первая реплика/Первый
   кадр/Сюжет и действия/Что получает зритель/Одно действие/Что подготовить·проверить/Секунд/Пакет
   съёмки/Этап/Статус).
3. Проверить, что реально приложено к текущему запросу (§6 правила) — не считать файл доступным
   только по упоминанию в прошлом сообщении. При отсутствии исходников — статус «Нужны исходники»,
   обозначения «ИСХОДНИК 1/2», без имитации интерфейсов и результатов.
4. Написать сценарий по формату §8: заголовочная строка + 5 блоков (ЗАДАЧА / МАТЕРИАЛЫ / СЦЕНАРИЙ
   ПО СЦЕНАМ / ЧИСТЫЙ ТЕКСТ ОЗВУЧКИ / УКАЗАНИЯ ДЛЯ СБОРКИ). Без тире в озвучке
   (`GLOBAL-REELS-VOICE-RULE.md` §8), без фраз из единого списка §3-4 той же памятки (включая
   дополнения 21.10.2026).
5. Прогнать по чек-листу §9 правила молча, исправить слабые места до ответа.
6. Сохранить готовый блок в `content/dovodim-do-dela/days/day-NN.txt` (NN с ведущим нулём).
7. После блока — ничего не добавлять: ни анализ, ни предложение написать сценарий (он уже написан).

## Разделение зон ответственности

- Остальной контент AlovLab (не этот сериал) — `.claude/skills/alovlab-heygen-director/SKILL.md`
  (`/reel`, `/reel-duo`) и `.claude/skills/alovlab-content-month/SKILL.md` по старой системе — для
  архива, не для новых дней с 22.10.2026.
- Открытый поиск темы «на сегодня» — не используется в этом сериале: тема всегда берётся из
  `plan-30-dney.csv`, не из открытого веб-исследования, если пользователь явно не заменил тему.
