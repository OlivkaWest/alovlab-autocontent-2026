# alovlab-ffmpeg-edit

Монтаж локально, безопасно (массив аргументов, без shell-строки). Реализация —
`automation/src/video/ffmpeg.ts` и `pipeline/make-reel.ts`.

## Единый формат
1080×1920 · 9:16 · MP4 · H.264 · AAC · 30 fps. Горизонталь не растягивать —
pad/scale без обрезки лиц и текста.

## Сборка
- Каждая сцена → 9:16 video-only сегмент (аватар-сегмент или push-in по карточке).
- Голос Нейромонаха (мастер-клип) — поверх B-roll, музыка тише голоса.
- Субтитры из файла (`subtitles.srt`/`.ass`) — без инъекций в команду.
- Логотип только в финале (1–2с, без вращения/свечения).

## Безопасность
Пользовательский текст НЕ вставляется в строку FFmpeg. `assertSafeArg` отсекает
управляющие символы. Запуск — `execFile` с массивом, `shell:false`.

## Проверка финала (ffprobe)
существует · размер>0 · открывается · 1080×1920 · есть видео+аудио · длительность.
Не прошло — не называй готовым, исправь и пересобери (`assemble <дата>`).

## Только монтаж
Изменение субтитров/музыки/логотипа НЕ перезапускает HeyGen. Команда `assemble`.
