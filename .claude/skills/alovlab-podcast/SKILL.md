# AlovLab Podcast Academy — аудиоподкасты для ElevenLabs

Полное правило — `content/rules/ALOVLAB-PODCAST-ACADEMY.md`. Этот скилл — точка входа по команде.

## Команды

- **`/alovlab-podcast [тема]`** — полный цикл: исследовать тему (официальная документация + уже
  существующие материалы проекта по теме, если есть), собрать структуру 11-12-минутного выпуска,
  написать готовый текст для озвучки, собрать 4 итоговых файла (см. правило §8) в новую папку
  `content/october-2026-system/podcasts/<topic-slug>/`.
- **`/alovlab-podcast-from-reel [путь к reels-пакету]`** — то же самое, но содержательная основа —
  уже готовый сценарий Reels (`01_HEYGEN_AGENT_PROMPT.txt` и `03_VOICE_AND_CAPTIONS.txt` этого
  пакета), переработанная под разговорный аудиоформат, не пересказ один в один.
- **`/alovlab-podcast-from-guide [путь к методичке]`** — то же самое, основа — готовая методичка
  (`guide_*.py` / `workbook.html` папки гайда).
- **`/alovlab-podcast-review [путь к PODCAST_ELEVENLABS_READY.txt]`** — проверка без переписывания
  с нуля: посчитать слова, оценить расчётную длительность, проверить отсутствие markdown/тире/
  скобок-заполнителей/английских служебных команд в тексте озвучки, пройтись по 10 критериям
  правила §12, список конкретных правок (не общая оценка).

## Как работать

1. Прочитать правило целиком (`ALOVLAB-ACADEMY-STANDARD.md` тоже, если тема пересекается с
   методичкой) перед первым запуском в сессии.
2. Не запрашивать повторно материалы, которые уже есть в репозитории по этой теме — искать их
   сначала (Glob/Grep по `content/october-2026-system/`), и только потом исследовать недостающее
   через WebSearch (прямой доступ к elevenlabs.io/heygen.com из песочницы обычно заблокирован сетью
   — WebSearch даёт вторичное подтверждение, это нормально и достаточно, если честно помечено).
3. Собрать текст по архитектуре правила §5, сразу с поправками §3 (без тире, числа словами, без
   запрещённых оборотов).
4. Перед сдачей — самопроверка: `python3 -c "print(len(open('PODCAST_ELEVENLABS_READY.txt').read().split()))"`
   для числа слов; глазами пройтись, что в файле нет ничего, кроме слов для диктора.
5. Четыре файла из правила §8 — не три и не пять, именно эти роли.
