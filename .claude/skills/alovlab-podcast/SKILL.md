# alovlab-podcast

Подкаст не звучит как статья, которую читает робот. Сначала перепиши под речь.

## Команды
```bash
npm run alovlab -- podcast 2026-08-05           # короткий (по умолчанию)
npm run alovlab -- podcast 2026-08-05 audiopost # 1–3 мин
npm run alovlab -- podcast 2026-08-05 full      # 15–30 мин
```

## Форматы
- **Аудиопост (1–3 мин):** сильная первая фраза → одна мысль → пример → вывод → CTA.
- **Короткий (5–10 мин):** хук → проблема → контекст → 3 блока → пример → вывод → CTA.
- **Полный (15–30 мин):** открытие → конфликт → главы → практика → вывод → действие.
- **Диалог (2 голоса):** основной — Илья, второй — утверждённый `ELEVENLABS_PODCAST_GUEST_VOICE_ID`.
  Реальный диалог, не механическое чередование. Второй голос не выбирать случайно.

## Качество первой минуты
Держит внимание. Можно (не механически): «Смотри, где здесь проблема», «Вот что
обычно происходит», «И здесь начинается самое интересное», «Но есть один нюанс».

## Studio API
ElevenLabs Studio podcast endpoint — не считать гарантированно доступным. Есть доступ →
проект/статус/скачивание. Нет → обычный TTS/Text-to-Dialogue + склейка FFmpeg (интро,
музыка, паузы). Отсутствие Studio API не ломает подкаст.
