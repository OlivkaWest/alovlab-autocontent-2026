# AlovLab HeyGen Director — живая речь, два аватара, master-промпт для Video Agent

Полные правила: `content/rules/ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` (с 27.10.2026, формат
вывода для `/reel` и `/reel-duo` — один master-промпт для HeyGen Video Agent, не пакет файлов) +
`content/rules/ALOVLAB-REELS-DIRECTOR-STANDARD.md` (живая разговорная речь, режим двух аватаров,
конфликт-диалог, разговорный аудит — содержание не изменилось, изменился только формат выдачи) +
`content/rules/GLOBAL-REELS-VOICE-RULE.md` (голос, запрет тире, запрещённые фразы) +
`content/rules/ALOVLAB-HEYGEN-REELS-STANDARD-v2.md` (§7 — аватар/голос Claude не выбирает никогда;
эта норма не меняется ни одним из более новых документов). Этот скилл — точка входа по командам, не
замена ни одного из документов.

  `.claude/skills/alovlab-content-month/SKILL.md` (план архивен с 22.10.2026, новые дни по нему не

## Команды

- **`/reel [тема]`** — режим A (один аватар). Хук → проблема → поворот → демонстрация → payoff →
  CTA (`ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §6). Результат — Часть 1-5 по §18 стандарта: краткая
  концепция, полный master-промпт (главный результат, одним куском), материалы для загрузки,
  проверка Video Plan, готовая команда для корректировки.
- **`/reel-duo [тема]`** — режим B (два аватара, диалог-конфликт). **Перед запуском проверь, утверждён
  ли паспорт второго аватара** (реальный аватар + голос, уже настроенные в HeyGen —
  `ALOVLAB-REELS-DIRECTOR-STANDARD.md` §3). Если паспорта нет: выдать всё, кроме раздела AVATAR
  master-промпта для второго персонажа (диалог, режиссёрская раскадровка, B-roll, субтитры,
  подсветка — всё остальное готово), и явно попросить назначить второй аватар+голос в HeyGen — не
  придумывать внешность/имя/Voice ID, не предлагать подбор в Higgsfield от своего имени. Технический
  маршрут для многоаватарности — `ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §5 (Avatar Shots powered
  by Seedance 2.0, до 3 аватаров — или сцена-за-сценой, если Avatar Shots не подтверждается в живом
  интерфейсе на момент сборки).
- **`/dialogue-review [путь к сценарию]`** — прогнать текст через аудит §14
  `ALOVLAB-REELS-DIRECTOR-STANDARD.md` (10 вопросов), вернуть список конкретных правок построчно, не
  общую оценку «хорошо/плохо».
- **`/seedance-broll [путь к сценарию]`** — промпты для Seedance-сцен по полному набору полей
  `ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md` §8: SUBJECT · ACTION · ENVIRONMENT · CAMERA ANGLE ·
  CAMERA MOVEMENT · LIGHTING · ATMOSPHERE · VISUAL STYLE · DURATION · CONTINUITY · NEGATIVE
  CONSTRAINTS. Операторский язык — конкретный («slow dolly-in», не «cinematic» вообще). Не выдумывать
  неподтверждённые возможности текущей версии Seedance — сверять с живым интерфейсом HeyGen.
- **`/heygen-director`** — собрать уже одобренный сценарий/диалог в единый master-промпт по шаблону
  `templates/heygen-video-agent-master.md` + сцены по `templates/heygen-scene.md`. Заменяет прежнюю
  узкую роль `/heygen-script` (та собирала только файл `01_HEYGEN_AGENT_PROMPT.txt` старого пакета).
- **`/heygen-review [Video Plan]`** — разобрать присланный Video Plan по чек-листу
  `templates/heygen-video-plan-review.md` (12 пунктов), сформировать корректирующее сообщение при
  расхождении. Не подтверждать запуск платной генерации заведомо неверного плана.
- **`/heygen-fix [замечание]`** — собрать запрос на локальную правку готового ролика по
  `templates/heygen-local-fix.md` — точная команда на правку конкретной сцены, не пересборка всего
  ролика; если точнее исправить в AI Studio — сказать прямо.
- **`/reel-from-plan`** — честно: отдельного действующего контент-плана для этой команды сейчас нет
  (`calendar.csv` архивен с 22.10.2026, `CONTENT-PLAN.md` не ведётся с сентября,
  `content/dovodim-do-dela/` зарезервирован за «Рилс дня»). Вместо выдумывания плана — предложить
  кандидатов по приоритету кластеров CLAUDE.md §0-Ц (Claude, Claude Code, Skills, Agents,
  Multi-Agent, заработок) и явно назвать это предложением, не утверждённым планом.

## Как работать

1. Перед первым запуском в сессии (или если давно не перечитывались — правила меняются, не
   полагаться на память прошлой сессии) прочитать целиком: `ALOVLAB-HEYGEN-VIDEO-AGENT-DIRECTOR.md`,
   `ALOVLAB-REELS-DIRECTOR-STANDARD.md`, `GLOBAL-REELS-VOICE-RULE.md`.
2. Для `/reel-duo` — сначала проверить паспорт второго аватара, не писать реплики под выдуманную
   внешность.
3. Писать диалог/сценарий целиком, потом резать по персонажам/сценам — не реплику за репликой с нуля.
4. Прогнать через аудит §14 `ALOVLAB-REELS-DIRECTOR-STANDARD.md` перед выдачей — вслух, «я бы так
   реально сказал?».
5. Проверить запрет на тире (`GLOBAL-REELS-VOICE-RULE.md` §8) и полный список запрещённых фраз
   (там же §3-4, со всеми дополнениями) по тексту EXACT SPOKEN SCRIPT, для всех персонажей.
6. Собрать единый master-промпт по `templates/heygen-video-agent-master.md`, сцены — по
   `templates/heygen-scene.md`. Выдать все 5 частей формата §18 — не подменять готовый промпт кратким
   описанием и не разбивать на отдельные задания.
