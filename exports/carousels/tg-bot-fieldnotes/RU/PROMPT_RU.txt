Собери проект Telegram-бота на Python для приёма заявок на консультацию.

Сценарий: /start → выбор одной из трёх тем → имя → контакт → подтверждение → приватное сообщение с заявкой администратору. На каждом шаге работает /cancel. Обработай пустой ввод, неожиданный тип сообщения, повторный /start и сбой отправки администратору.

Токен и ID администратора считывай из переменных окружения. Не записывай токен в код, логи или Git. Выдай bot.py, requirements.txt, .env.example без секретов, .gitignore и README с командами запуска для Windows и macOS/Linux. Для локального прототипа используй long polling, не включай одновременно webhook.

Покажи четыре ручных теста: /start, пустой ответ, /cancel, получение заявки администратором. Не заявляй об успешной интеграционной проверке без реального токена. Отдельно опиши публикацию на хостинге: переменные окружения, перезапуск процесса, мониторинг ошибок. Сначала покажи план файлов и сценарий, потом код.
