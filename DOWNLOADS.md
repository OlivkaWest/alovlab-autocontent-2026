# Скачать материалы (прямые ссылки)

> Файловые карточки в чате не качаются — качаем отсюда, через GitHub (он работает всегда).
> Два типа ссылок: **Открыть** (страница с кнопкой Download) и **Скачать сразу** (raw, файл падает в загрузки).
> Ветка: `claude/vercel-labs-skills-setup-c9cz6s`. Список обновляется под каждый новый материал.

## Как качать
- С телефона/веба: жми **Открыть** → на странице GitHub кнопка **Download** (или ⋯ → Download).
- Быстро: жми **Скачать сразу** — PDF падает в загрузки, картинка открывается (долгий тап → Сохранить).
