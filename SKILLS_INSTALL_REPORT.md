## 2. Итоговые цифры

1. **Найдено точно** (подтверждён существующий проект/источник под тем же или очень близким именем):
   **15 из 30** (№1, 6, 8, 10, 11, 13, 14, 17, 18, 20, 24 частично, 25, 28, 29, 30 — из них 20/24
   найдены как реальные сервисы, не скиллы).
2. **Установлено:** **18 скиллов** из **9 источников** (video-use, 6× hyperframes, 5× remotion,
   video-shotcraft, clipify, shorts, find-broll, video-perception, higgsfield, 3× claude-code-video-toolkit).
   Это закрывает позиции №1, 6, 8, 10, 11, 12, 13, 14, 15 (аналог), 17, 25, 28 — **12 из 30** позиций
   списка получили установленный рабочий скилл (считая дубли №12/13 и аналог №15 как закрытые).
3. **Реально проверено** (не просто «папка существует»): ffmpeg-пайплайн целиком — чтение параметров,
   обрезка, склейка, субтитры (визуально подтверждено на кадре), звук (фейд+нормализация), финальный
   9:16-экспорт — всё на синтетических тестовых клипах, не на ваших оригиналах. Каждый установленный
   SKILL.md прочитан и сверен на конфликт с голосом/правилами CLAUDE.md (конфликтов не найдено — это
   технические скиллы, не контент-генераторы). Полный рендер через Remotion/HyperFrames/Whisper-
   транскрипцию **не** запускал — для этого нужны тяжёлые зависимости (`faster-whisper`/`torch`) или
   первый прогон, который должен увидеть и подтвердить сам пользователь.
4. **Что уже доступно для монтажа прямо сейчас:**
   - Полный ffmpeg-пайплайн (резка, склейка, титры, звук, экспорт) — проверено, работает.
   - `video-use`, `clipify`, `shorts`, `find-broll`, `video-perception` — установлены, структурно
     готовы; транскрипция/распознавание заблокированы отсутствием Whisper-зависимостей или
     ElevenLabs-ключа (см. ниже).
   - `hyperframes` + 5 под-скиллов, `remotion-*` × 5, `video-shotcraft`, `video_toolkit`+`ffmpeg`+`moviepy` —
     установлены, для первого реального рендера нужен твой личный прогон (скачивание Chromium/npm-пакетов).
   - `higgsfield` — рабочий справочник промптов прямо сейчас, без доустановки.
5. **Что требует твоего участия:**
   - `pip install faster-whisper` (или `openai-whisper`) в `/opt/video-skills-venv` — для Clipify/Shorts/
     find-broll/video-perception. Тяжёлая загрузка (torch), не делал без отдельного запроса.
   - `ELEVENLABS_API_KEY` в `.env` рядом с `video-use` — для его встроенной транскрипции.
   - Первый реальный запуск рендера (`hyperframes render`, `remotion render`, `video-shotcraft`) — сам
     процесс качает Chromium/npm-пакеты при первом вызове, это не «платная генерация ради проверки»,
     а обычная установка зависимостей, которую лучше увидеть лично перед тем, как полагаться на неё.

Среда проверена, 9 источников установлено и закоммичено (18 скиллов), ffmpeg-ядро протестировано.
Монтаж твоего реального ролика не начинал — как и было указано.
