## 3. Стиль и правила (договорённости)
- **Два визуальных языка карусели:**
  1. «Флет-премиум» (тёмные карточки, chips, до/после) — образовательные/бизнес.
  2. 🌟 **«Showcase»** (стеклянный орб + свечение + градиент-заголовок) — **новый предпочитаемый** («дизайн такой давай делать будем»).
- Бренд: тёмный фон, оранжевые акценты, шрифт Manrope, настоящий логотип `assets/img/logo-mark.png`, «AlovLab» слитно.
- **Язык — русский**, единственная латиница — подпись **AlovLab**.
- Карусель: 4:5, под **Instagram и Telegram**, публикуется одним постом. Футер на слайдах НЕ пишем. Правила — `CLAUDE.md` Приложение Б.
- Методички: фикс-A4, светлая основа + тёмные плашки под промпты. `CLAUDE.md` Приложение В.
- Подписи к постам — короткие: хук в первой строке, до CTA без воды.
- **Примеры — всегда в нише AlovLab (ИИ/контент)**, НЕ фитнес/питание.
- **В КАЖДОЙ карусели обязательно: примеры пользы (для какого бизнеса) + готовые промпты.** Где уместно — рисунок темы + метки «Нейросеть»/«Бизнес». Эталон `carousel_showcase_prompts.py`.
- **Showcase — основной стиль** (`carousel_showcase_render.py`). Флет — для образовательных на примерах.
- **Честность (жёстко):** без выдуманных цифр/цен/акций/«N мест»/таймеров. Реальные факты курса — в закреп-оффере.
- **Приём изображений от пользователя:** вложения из чата НЕ читаются как файлы. Как только пользователь кидает картинку — сразу присылать ссылку на загрузку в репо:
  `https://github.com/OlivkaWest/alovlab-autocontent-2026/upload/claude/vercel-labs-skills-setup-c9cz6s/content/carousel-assets/commercial`
  (commit в ветку `claude/vercel-labs-skills-setup-c9cz6s` → пишет «готово» → `git pull` → раскладываю). Альтернатива — Google Drive (коннектор подключён).

## 4. Стратегия (важно помнить)
- По статистике аккаунта: **Reels 84,6% просмотров, публикации (карусели) 0,2%.** Карусели ≠ охват.
- Роль карусели: греть подписчиков, сохранения, контент для Telegram. **Охват качаем Reels** (демо «ИИ делает на глазах → метод»).
- Воронка: Reels → профиль → Telegram (закреп-оффер) → заявка (курс B2C / бриф студии B2B).
- Закреп-хаб в Telegram: один честный оффер, контент только ссылается на него.
