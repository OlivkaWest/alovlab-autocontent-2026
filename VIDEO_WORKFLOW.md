# Рабочий процесс видеопродакшна AlovLab

> Установлено 19.10.2026 по запросу «найти и установить скиллы для видеопродакшна». Полная таблица
> проверки всех 30 позиций — `SKILLS_INSTALL_REPORT.md`. Запись установки — `docs/reels-skills-manifest.md`.

## Главное правило: не включай всё сразу

На каждом конкретном задании подключай только скиллы нужного этапа — не все 18 сразу. Ниже для
каждого этапа явно указано, что брать. Если Claude Code сам подключает скилл не вовремя — поправь:
назови этап явно («сейчас только монтаж, без цвета»).

## Твои жёсткие требования (действуют на любом этапе)

- **Оригиналы не трогаем.** Исходники лежат в `footage/`, работа идёт в `work/`, готовое — в
  `exports/` (та же структура, что в методичке «Монтаж с AI-агентом»,
  `content/october-2026-system/guides/klod-montazh/`). Ни один скилл не должен писать в `footage/`.
- **Монтаж поэтапно.** Не пытаться сделать цвет+звук+титры одним проходом — лендинг ошибок резко
  растёт, когда правишь всё одновременно.
- **Единый визуальный стиль.** Экспозиция и баланс белого каждого кадра выравниваются перед
  монтажом, не после — проверяй на этапе «Цвет» (ниже), не оставляй на финал.
- **Переходы мотивированы.** Склейка — по движению в кадре, по композиции или по звуковому акценту,
  не случайный микс эффектов «потому что красиво».
- **Без случайных эффектов и повторов кадров.** Контроль качества (этап 10) ловит это целенаправленно,
  не полагайся на «на глаз во время монтажа».
- **Речь, музыка и изображение синхронизированы.** Проверяется дважды: на этапе «Звук» (технически,
  по форме волны) и на этапе «Контроль качества» (на слух и на просмотр целиком).
- **Экспорт проверяется весь, целиком**, не выборочно по кадрам — см. этап 11.

## Пайплайн по этапам

### 1. Приём исходников
Клипы → `footage/`, без изменений. Аудиодорожки → `voiceover/`.
- **Инструмент:** `ffprobe` (уже установлен) — прочитать параметры каждого файла (кодек, разрешение,
  длительность, частота кадров) перед тем, как что-либо планировать.
- **Скиллы:** не нужны на этом этапе.

### 2. Анализ материала
Понять, что реально отснято, есть ли транскрипт, где содержательные моменты.
- **`video-perception`** — извлечение кадров + транскрипция (ffmpeg + Whisper/Gemini/OpenAI).
- **Анthropic `watch`** (уже был доступен в сессии) — если материал сначала нужно скачать по ссылке.
- **Ограничение:** путь полностью локального Whisper в `video-perception` не протестирован в этой
  среде — не установлены `openai-whisper`/`faster-whisper` (см. SKILLS_INSTALL_REPORT.md).

### 3. Отбор лучших моментов
Из длинного материала — короткие яркие куски.
- **`clipify`** — находит яркие диалоговые/акционные моменты, режет как отдельные клипы.
- **`shorts`** — интерактивный отбор сегментов (Claude оценивает кандидатов, ты выбираешь).
- **Ограничение:** оба используют `faster-whisper`/Whisper для транскрипции — не установлен в этой
  среде, нужно `pip install faster-whisper` (или `openai-whisper`) в `/opt/video-skills-venv` перед
  реальным использованием.

### 4. Сценарий
Что говорим, в каком порядке, какой хук, какой CTA — это текстовая работа, не скилл. Опирайся на
принципы из методичек этой же сессии: «Монтаж с AI-агентом» (структура репозитория, CLAUDE.md) и
«Два аватара. Один разговор» (глава 3 — как писать диалог, который реально звучит как разговор, не
как два монолога подряд).

### 5. Черновой монтаж
Собрать куски в последовательность, без полировки.
- **`video-use`** — разговорный монтаж: режет по таймкодам, транскрибирует, сохраняет прогресс в
  `project.md`. Нужен `ELEVENLABS_API_KEY` для своей транскрипции — не настроен, см. отчёт.
- **`hyperframes` + `hyperframes-core`** — если собираешь композицию в формате HyperFrames (HTML-based
  видео), а не просто режешь готовые клипы.
- **Прямой `ffmpeg`** всегда доступен как запасной путь — методичка klod-montazh показывает, как
  попросить агента резать/склеивать им напрямую, без отдельного скилла.

### 6. Согласование
Человек смотрит черновой монтаж и говорит, что менять. Без скилла — это твоя пауза в процессе.

### 7. Цвет
Выравнивание экспозиции и баланса белого по всем кадрам одного ролика.
- **`video-use`** упоминает цветокоррекцию в своём описании (часть разговорного монтажа).
- **Прямой `ffmpeg`** (`eq`, `curves`, `colorbalance` фильтры) — рабочий запасной путь, не
  протестирован в этой сессии на реальном материале (только на синтетических цветных полосах,
  см. SKILLS_INSTALL_REPORT.md).

### 8. Звук
Фейды, дакинг музыки под речь, громкость, эффекты, синхронизация.
- **`hyperframes-audio`** — fade-in/out, кроссфейд, дакинг голоса под музыку, EQ/компрессор/лимитер,
  автоматизация громкости. Для композиций в формате HyperFrames.
- **Прямой `ffmpeg`** (`afade`, `loudnorm`) — протестировано в этой сессии на синтетическом клипе,
  работает.

### 9. Титры / субтитры
- **`embedded-captions`** — вшивает субтитры в готовое видео одного говорящего, 35+ стилей, разбор
  по смысловой разметке, не по движку. Полностью локально (транскрипция + поиск объекта в кадре).
- **`remotion-captions`** — если видео собирается в Remotion с нуля, а не поверх готового клипа.
- **Прямой `ffmpeg` `drawtext`** — протестировано в этой сессии, работает (см. отчёт).

### 10. Контроль качества
Проверка на случайные эффекты, повторы кадров, рассинхрон речи и картинки, обрезанные слова.
- **`hyperframes-cli`** — команды `lint`, `check`, `snapshot`, `compare` для композиций HyperFrames.
- Ручная проверка: прослушать целиком в наушниках, посмотреть целиком на экране телефона (не только
  превью на компьютере) — ни один скилл не заменяет этот шаг.

### 11. Экспорт
- **`hyperframes-cli render`** / **`remotion-render`** — финальный рендер для своих форматов.
- **Прямой `ffmpeg`** — финальный MP4, протестировано в этой сессии (9:16 кроп + аудио + титры в
  одном файле, см. отчёт).
- **Обязательно:** прогнать `ffprobe` по готовому файлу перед сдачей — длительность, отсутствие
  ошибок декодирования, корректное разрешение.

## Альтернативный оркестратор: video_toolkit

`video_toolkit` (из `claude-code-video-toolkit`) — ещё один вариант «от сценария до готового MP4»,
параллельный HyperFrames: сценарий → озвучка → музыка → визуал → рендер. `moviepy` рядом —
Python-композиция поверх готовых клипов, рабочий путь, если не хочется поднимать Remotion. `ffmpeg`
(из того же набора) — справочник паттернов конкретно под этот тулкит. Не включай одновременно с
полным набором HyperFrames на одном задании — выбери один оркестратор под конкретный ролик.

## Отдельно: промпты и сборка под продукт
- **`video-shotcraft`** — если задача не «смонтировать отснятое», а «собрать кинематографичный
  промо-ролик из скриншотов веб-страницы/продукта» — отдельный, самодостаточный путь со своими
  карточками-рецептами движения камеры, не часть пайплайна выше.
- **`find-broll`** — когда готовому монологу не хватает визуального перебивочного материала (b-roll)
  под конкретные слова транскрипта.
- **`higgsfield`** — не видео-скилл в смысле монтажа, а помощник по промптам для уже подключённого
  Higgsfield (MCP). Используй, когда пишешь промпт для генерации, а не когда монтируешь готовое.

## Что нужно доустановить перед полноценной работой (честно, не скрыто)
- `pip install faster-whisper` (или `openai-whisper`) в `/opt/video-skills-venv` — нужно `clipify`,
  `shorts`, `find-broll`, локальному пути `video-perception`. Не установлено в этой сессии — тяжёлая
  загрузка (torch), не делал без отдельного запроса.
- `ELEVENLABS_API_KEY` — нужен `video-use` для транскрипции. Получить на elevenlabs.io, положить в
  `.env` рядом со скиллом, не в git.
- Remotion-рендер (`remotion-render`, `hyperframes-cli render`, `video-shotcraft`) при первом запуске
  сам скачивает headless Chromium через `npx` — не запускал в этой сессии (не тестовая генерация, а
  фактический первый прогон, который сам пользователь должен увидеть и подтвердить).
