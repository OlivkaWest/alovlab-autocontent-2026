# День 21 · Промпты «Один проект — десять единиц»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[СЪЁМКА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
`[СЪЁМКА]` — описание одного отснятого материала в 5–7 строк: о чём, главный приём, сильная фраза, показанный результат, какие вопросы вызовет.

---

## 1. Основной промпт — собрать карту нарезки
```
Ты — контент-продюсер. Помоги выжать одну съёмку досуха.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Одна съёмка: [СЪЁМКА].

Разложи этот единственный материал на 10 единиц контента. Ничего нового не снимаем — только нарезаем то, что уже есть.
Используй шесть типов нарезки: 1) вырезать как есть, 2) переупаковать в другой формат, 3) повернуть под другую боль, 4) сжать в одну фразу, 5) развернуть один момент вглубь, 6) ответить на вероятный комментарий.

Заполни карту из 10 слотов, для каждого укажи:
— формат (Reels / тизер / карусель / пост / сторис / карточка / до-после / лонг / ответ);
— тип нарезки из шести;
— что конкретно берём из съёмки;
— куда ведёт (профиль / Telegram / бронь / диалог).

Требования: минимум 4 разных типа нарезки, ни одной единицы-дубля, живой русский язык, короткие формулировки, минимум у половины единиц выход в Telegram.
```

## 2. Промпт для улучшения
```
Вот моя карта нарезки: [ВСТАВИТЬ]. Усиль её:
— в каждой видео-единице сделай хук острее и короче (до 9 слов);
— проверь, что переупаковка меняет носитель, а не копирует видео в видео;
— где две единицы про одно — разведи их по разным болям или убери одну;
— добавь каждой единице понятный выход воронки.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мою карту нарезки строго, как продюсер, который её завернёт.
Найди: где две единицы на самом деле одна; где слот добит пустышкой ради числа десять; где «переупаковка» — просто копия; где единица никуда не ведёт.
Отдельно скажи, сколько получилось разных типов нарезки из шести.
Дай оценку 1–10 по разнообразию и по полезности каждой единицы. Ничего не хвали из вежливости.
Карта: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь карту нарезки по чек-листу и ответь да/нет по каждому пункту:
— всего 10 единиц (или 9 сильных без пустышек);
— минимум 4 разных типа нарезки из шести;
— нет двух единиц, которые дублируют друг друга;
— у каждой единицы понятна роль и куда она ведёт;
— минимум у половины единиц выход в Telegram;
— нет банальных и запрещённых фраз.
Если где-то «нет» — перепиши этот слот.
Карта: [ВСТАВИТЬ].
```

---

## Заполненный пример (салон красоты)
`[НИША]` = салон красоты, окрашивание и уход · `[АУДИТОРИЯ]` = женщины 25–40, красят волосы, боятся испортить цвет, ищут «своего» мастера · `[СЪЁМКА]` = 6 минут: колорист делает сложное окрашивание из тёмного в холодный блонд, комментирует по шагам, в конце — реакция клиентки · `[ПРОДУКТ]` = запись к колористу + курс для владельца салона по контенту.

**Что вернул основной промпт (сокращённо, 10 единиц):**
- Hero-Reels (вырезать как есть): момент тонирования + приём «почему нельзя за один раз» → профиль → Telegram.
- Второй Reels (повернуть угол): та же съёмка под боль «почему дома блонд желтит» → профиль.
- Тизер 12 сек (дистилляция): сравнение прядей до/после в кадре → крючок на hero.
- Карусель (переупаковать): «4 ошибки при переходе в блонд» → Telegram за чек-листом.
- Telegram-пост (переупаковать): текстовый разбор + сколько занимает переход → прогрев к записи.
- Сторис-серия (расширение): закулисье + опрос «твой оттенок?» + ссылка на запись.
- Цитата-карточка (дистилляция): «блонд — это не цвет, это уход» на тёмном фоне.
- До/после (вырезать как есть): тёмный → холодный блонд крупным планом.
- Лонг для VK (расширение): полный разбор ухода за осветлённым волосом → сайт.
- Ответ на коммент (реакция): микро-Reels на «а можно за один визит?».

Типов нарезки — пять из шести. Дублей нет. Выход в Telegram — у пяти единиц.
