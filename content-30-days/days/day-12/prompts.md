# День 12 · Промпты «Пять кадров одного мира» (NanoBanana)

Инструмент: NanoBanana (Gemini 2.5 Flash Image) на `aistudio.google.com`.
Переменные: `[ПАЛИТРА]`, `[СВЕТ]`, `[ОПТИКА]`, `[ФОН]`, `[ОПОРА]`, `[НАСТРОЕНИЕ]`, `[ОБЪЕКТ]`, `[НИША]`. Копируй и подставляй своё.

---

## 1. Основной промпт — сгенерить эталон (кадр 1)
```
Сделай предметное фото для [НИША].
Паспорт кадра (держи ровно эти правила):
— Палитра: [ПАЛИТРА].
— Свет: [СВЕТ].
— Оптика и ракурс: [ОПТИКА].
— Фон: [ФОН].
— Опора: объект стоит на [ОПОРА].
— Настроение и обработка: [НАСТРОЕНИЕ].
В кадре один объект: [ОБЪЕКТ]. Объект крупно по центру, ничего лишнего.
Вертикальный кадр. Фотореализм. Дай 3–4 варианта.
```

## 2. Промпт улучшения — перенести стиль на кадры 2–5
```
(Прикрепи скачанный эталон как референс-изображение.)
Сделай кадр в том же стиле, что на приложенном изображении.
Точно повтори: палитру, направление и мягкость света, фон, опору и общее настроение.
Ничего в мире кадра не меняй.
Замени только объект в центре на: [ОБЪЕКТ].
Композиция и крупность — как в референсе. Вертикальный кадр, фотореализм.
```

## 3. Промпт жёсткой оценки — найти, где кадр выбивается
```
(Загрузи все 5 кадров.)
Смотри на пять кадров как строгий арт-директор. Они должны выглядеть как одна серия одного бренда.
Найди, где кадр выбивается из общего мира: другой оттенок фона, свет с другой стороны, чужая палитра, другой масштаб объекта, лишний реквизит.
По каждому кадру скажи: в серии он или выбивается и почему. Ничего не хвали из вежливости.
Укажи, какой кадр переделать в первую очередь.
```

## 4. Промпт финальной проверки — да/нет по единству
```
(Загрузи все 5 кадров.)
Проверь серию по чек-листу, ответь да/нет по каждому пункту:
— палитра во всех пяти из одного набора;
— свет во всех пяти падает с одной стороны;
— фон одного типа во всех пяти;
— крупность и ракурс объекта совпадают;
— в каждом кадре один объект, без лишнего реквизита.
Если где-то «нет» — скажи, какой кадр и что в нём переделать.
```

---

## Заполненный пример (маркетплейс, линейка ухода)
`[НИША]` = карточки товара для маркетплейса · `[ПАЛИТРА]` = тёплый беж, кремовый, приглушённый эвкалиптовый как акцент · `[СВЕТ]` = мягкий рассеянный свет слева, тёплый, лёгкие тени · `[ОПТИКА]` = макро, объект крупно по центру, фон размыт, съёмка чуть сверху · `[ФОН]` = однотонный кремовый, чистый, без реквизита · `[ОПОРА]` = плоский природный камень песочного цвета · `[НАСТРОЕНИЕ]` = спокойное, чистое, мягкий контраст, лёгкое зерно · `[ОБЪЕКТ]` (кадр 1) = крем в матовой стеклянной баночке.

**Кадры 2–5 (тот же паспорт, меняем только объект):**
- Кадр 2: сыворотка в стеклянном флаконе с пипеткой.
- Кадр 3: тоник в высокой бутылке.
- Кадр 4: маска в круглой банке.
- Кадр 5: масло в узком пузырьке.

**Что вернул основной промпт:** эталон — баночка крема на песочном камне, кремовый фон, мягкий свет слева. Дальше прикрепляем эталон референсом, меняем строку объекта — и получаем сыворотку, тоник, маску, масло в том же мире. Пять товаров, один бренд.
