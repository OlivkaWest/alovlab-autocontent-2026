# День 27 · Промпты «Первая продажа»

Переменные: `[НИША]`, `[ПРОДУКТ]`, `[АУДИТОРИЯ]`, `[ЧАСТОЕ ВОЗРАЖЕНИЕ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать скрипт диагностики
```
Ты — эксперт по мягким продажам. Собери скрипт первого диалога через диагностику, а не презентацию.
Ниша: [НИША]. Продукт: [ПРОДУКТ]. Аудитория: [АУДИТОРИЯ].

Собери диалог:
1) ОТКРЫТИЕ — как ответить на «расскажите», не вываливая всё сразу.
2) ТРИ ВОПРОСА ДИАГНОСТИКИ — какая задача, что пробовали, что мешало.
3) ПЕРЕХОД К ПРОДУКТУ — как связать ответы человека с продуктом (только после диагностики).
4) МЯГКИЙ ШАГ — предложение без давления.

Требования: живой русский, короткие реплики, вопросы открытые, без «купи» и напора.
Ты помогаешь человеку понять, нужно ему это или нет — а не уговариваешь.
Не выдумывай цифры, скидки и сроки. Нет данных — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот мой скрипт диалога: [ВСТАВИТЬ]. Усиль его:
— открытие сделай коротким, без вываливания всего;
— вопросы — открытыми, чтобы человек проговорил задачу сам;
— переход к продукту привяжи к его ответам, а не к прайсу;
— финальный шаг сделай лёгким и без давления.
Покажи, что изменил и почему диалог стал живее.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой скрипт строго, как человек, который написал «расскажите» и готов уйти. Не хвали.
Найди: где презентация вместо диагностики; где закрытые вопросы; где давление и «купи»;
где переход к продукту оторван от задачи человека.
Дай оценку 1–10 по тому, захочет ли человек продолжить диалог, назови три правки.
Скрипт: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь скрипт по чек-листу, отвечай да/нет:
— открытие не вываливает всё сразу;
— есть три открытых вопроса диагностики;
— продукт появляется после диагностики, привязан к задаче;
— возражения закрываются спокойно, без спора;
— финальный шаг без давления;
— нет выдуманных цифр, скидок и сроков.
Где «нет» — перепиши фрагмент.
Скрипт: [ВСТАВИТЬ].
```

## 5. Промпт для ответов на возражения
```
Помоги ответить на возражение спокойно, без спора и давления.
Продукт: [ПРОДУКТ]. Возражение клиента: [ЧАСТОЕ ВОЗРАЖЕНИЕ].

Дай 2–3 варианта ответа, каждый по схеме:
— принять чувство человека (не спорить);
— задать уточняющий вопрос или показать ценность под его задачу;
— оставить решение за ним.
Без манипуляций, без выдуманных скидок и таймеров.
```

---

## Заполненный пример (онлайн-школа английского)
`[НИША]` = онлайн-школа английского · `[ПРОДУКТ]` = разговорный интенсив · `[АУДИТОРИЯ]` = взрослые, боятся говорить.

**Скрипт (сокращённо):**
- Открытие: «Расскажу, но сначала пойму, что вам нужно — так будет полезнее. Пара вопросов?»
- Вопросы: «Какую задачу хотите закрыть — заговорить, снять страх, подготовиться к поездке?» → «Что уже пробовали?» → «Что мешало?»
- Переход: «Раз главное — ступор в речи, а не слова, то вам подойдёт интенсив, где с первого занятия только говорение».
- Шаг: «Давайте начнём с пробного — без обязательств, просто проверите».

**Возражение «дорого»:** «Понимаю. Дорого относительно чего — относительно бюджета или относительно результата? Давайте посмотрим, что именно входит и что это вам даёт».
