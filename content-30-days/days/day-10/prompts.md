# День 10 · Промпты «Каркас 2–5–15–30»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[УГОЛ]`, `[ПРИЁМ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать сценарий по секундам
```
Ты — сценарист коротких видео. Собери сценарий Reels на 30 секунд по жёсткому каркасу.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Угол ролика: [УГОЛ]. Приём, который показываем: [ПРИЁМ].

Разложи строго по зонам, у каждой — одна задача:
0–2 сек — УДАР: одна фраза, после которой нельзя пролистнуть. Без приветствия и разгона.
2–5 сек — БОЛЬ: назови проблему зрителя конкретно, его словами.
5–15 сек — ОДИН ПРИЁМ: ровно один, показать в кадре (действие + короткая реплика).
15–30 сек — РЕЗУЛЬТАТ: что конкретно меняется (время, деньги, результат). Без выдуманных цифр.
финал — CTA: одна строка, в Telegram за тетрадью дня.

Отдай таблицей из трёх колонок: Таймкод | Что говорю | Что в кадре (действие + текст на экране).
Требования: живой русский, короткие фразы, ни одной банальной формулировки, ровно один приём, ни одной пустой правой колонки.
```

## 2. Промпт для улучшения
```
Вот мой сценарий: [ВСТАВИТЬ].
Усиль его:
— в 0–2 сделай удар острее, убери любой разгон и приветствие;
— в 5–15 оставь ровно один приём, лишнее вычеркни;
— найди секунду, где начинается провисание, и уплотни её;
— заполни пустые клетки «что в кадре» конкретным действием или текстом на экране.
Покажи таблицей: было / стало, и что именно изменил.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой сценарий строго, как редактор, который его отклонит.
Назови конкретную секунду, на которой зритель уйдёт, и объясни почему.
Найди: где разгон вместо удара, где приёмов больше одного, где правая колонка пустая, где результат абстрактный.
Дай оценку 1–10 по силе удара и по удержанию середины. Ничего не хвали из вежливости.
Сценарий: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь сценарий по каркасу и ответь да/нет по каждому пункту:
— в 0–2 удар, а не приветствие, первое слово работает;
— в 2–5 боль названа конкретно;
— в 5–15 ровно один приём, показан в кадре;
— в 15–30 результат конкретный, без выдуманных цифр;
— финал — одна строка CTA в Telegram;
— в каждой строке заполнена колонка «что в кадре».
Если где-то «нет» — перепиши эту зону.
Сценарий: [ВСТАВИТЬ].
```

---

## Заполненный пример (риелтор, вторичка)
`[НИША]` = частный риелтор, вторичное жильё · `[АУДИТОРИЯ]` = покупают первую квартиру, боятся скрытых проблем и переплаты · `[УГОЛ]` = «квартиру показывают в лучшем свете, а правда вылезает потом» · `[ПРИЁМ]` = «приди на повторный просмотр после дождя и проверь три места» · `[ПРОДУКТ]` = сопровождение сделки под ключ.

**Что вернул основной промпт (сокращённо):**

| Таймкод | Что говорю | Что в кадре |
|---|---|---|
| 0–2 | Квартиру тебе показывают в солнце. Смотри её в дождь. | Солнечное окно → серое мокрое стекло |
| 2–5 | В сухую погоду ты не увидишь ни одного протёкшего шва. | Палец по сухому углу, текст «сухо ≠ цело» |
| 5–15 | Приди после дождя и проверь три места: углы под окнами, стык балкона, потолок в санузле. | Крупно три места, счётчик 1-2-3 |
| 15–30 | Пять минут в дождь экономят полмиллиона на переделке от плесени. | Смета «до/после» |
| финал | Чек-лист «что смотреть на просмотре» — в тетради дня. | Логотип A, кнопка «Забрать тетрадь» |
