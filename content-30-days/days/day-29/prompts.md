# День 29 · Промпты «Разбор месяца»

Переменные: `[НИША]`, `[МЕТРИКИ]`, `[МАТЕРИАЛ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — разобрать месяц по связкам
```
Ты — аналитик контента. Помоги разобрать месяц не по одной цифре, а по связкам метрик.
Ниша: [НИША]. Продукт: [ПРОДУКТ].
Мои данные за месяц (по материалам): [МЕТРИКИ].

Сделай разбор:
1) НАЙДИ ПИК — материал с лучшими показателями (по совокупности, не по одним просмотрам).
2) ЧИТАЙ СВЯЗКИ — по каждому заметному материалу свяжи метрики:
   просмотры↔досмотр, досмотр↔сохранения, охват↔переходы, переходы↔заявки.
3) ЧТО ЗАШЛО — что усилить на следующей неделе и почему.
4) ЧТО В ПУСТОТУ — что резать и почему.

Работай только с моими реальными цифрами. Не выдумывай данные, которых я не дал.
Где данных нет — пиши «нет данных», не додумывай.
Живой русский, коротко, выводы конкретные.
```

## 2. Промпт для улучшения разбора
```
Вот мой разбор: [ВСТАВИТЬ]. Усиль его:
— замени оценки по одной цифре на чтение связок;
— по пику объясни, за счёт чего он выстрелил, чтобы это можно было повторить;
— выводы «усилить/резать» сделай конкретными действиями, а не общими словами.
Не добавляй цифр, которых я не давал. Покажи, что изменил.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой разбор строго, как аналитик, который не верит выводам без данных. Не хвали.
Найди: где вывод сделан по одной цифре; где «нравится/не нравится» вместо метрик;
где выводы общие и невыполнимые; где появилась цифра, которой не было в исходных данных.
Дай оценку 1–10 по тому, можно ли по разбору принять решение, назови три правки.
Разбор: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь разбор по чек-листу, отвечай да/нет:
— выводы сделаны по связкам метрик, а не по одной цифре;
— найден и объяснён материал-пик;
— по каждому выводу есть конкретное действие (усилить/резать как);
— все цифры — из моих реальных данных;
— нет выдуманных показателей;
— решение на следующий месяц понятно.
Где «нет» — перепиши.
Разбор: [ВСТАВИТЬ].
```

## Как читать связки (шпаргалка к промпту)
- **Просмотры высокие, досмотр низкий** → хук цепляет, тело слабое. Держи обещание хука.
- **Досмотр высокий, сохранений нет** → развлекло, но нечего забрать. Добавь приём.
- **Охват большой, переходов в профиль нет** → хук выстрелил, контент не подтвердил.
- **В профиль заходят, в Telegram нет** → нет явного выхода воронки в конце.
- **В Telegram переходят, заявок нет** → разбор не доводит до продукта.

## Заполненный пример (по типу реальной статистики)
`[НИША]` = обучение работе с ИИ · `[ПРОДУКТ]` = курс/метод.
Наблюдение из практики @neurumonk (реальные данные бренда): формат охвата — Reels (≈85% просмотров), статика почти не даёт охвата (≈0,2%). Большинство просмотров и взаимодействий — от неподписчиков (холодный трафик). Один ролик-демонстрация («ИИ делает работу на глазах») дал больше половины всех реакций месяца.

**Вывод разбора:** усиливать формат «ИИ делает работу на глазах + метод» (это пик), Reels как единственный формат охвата; резать развлекательные наживки не по теме — дают пустой охват от чужой аудитории. (Все цифры — реальные, из статистики бренда; чего нет — «нет данных».)
