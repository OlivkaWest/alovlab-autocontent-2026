# День 22 · Промпты «Лид-магнит за вечер»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[БОЛЬ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать лид-магнит
```
Ты — продуктовый маркетолог. Помоги собрать сильный лид-магнит из моего опыта.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Одна боль клиента, которую закрываем: [БОЛЬ].

Собери лид-магнит, который решает ровно эту одну боль до конца:
1) ЗАГОЛОВОК под боль (до 10 слов, без «уникальный/полезный»).
2) ОБЕЩАНИЕ результата — что человек получит, забрав файл.
3) ТРИ ШАГА к результату — конкретные действия, а не общие слова.
4) ШАБЛОН или пример, который можно применить сразу.
5) МЯГКИЙ ПЕРЕХОД к продукту — от решённой задачи к следующему шагу.

Требования: живой русский, короткие фразы, одна задача решена до конца,
объём — на один вечер работы. Не выдумывай цифры и кейсы: нет данных — так и пиши.
```

## 2. Промпт для улучшения
```
Вот мой лид-магнит: [ВСТАВИТЬ]. Усиль его:
— заголовок сделай острее и под конкретную боль, убери общие слова;
— оставь ровно одну задачу, всё «заодно ещё» вынеси;
— в трёх шагах замени общие формулировки на конкретные действия;
— переход к продукту сделай мягким, от задачи клиента, а не «купи».
Покажи, что именно изменил и почему стало сильнее.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой лид-магнит строго, как человек, который его НЕ станет скачивать.
Найди: где обещание пустое, где «вода» вместо шагов, где решается сразу три задачи
и ни одна до конца, где переход к продукту звучит как «купи».
Дай оценку 1–10 по силе обещания и по применимости. Ничего не хвали из вежливости.
Лид-магнит: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь лид-магнит по чек-листу и ответь да/нет по каждому пункту:
— решается ровно одна боль клиента;
— задача доведена до результата, а не до «понимания»;
— есть шаблон или пример для немедленного применения;
— заголовок бьёт в боль, без банальных слов;
— переход к продукту мягкий и от задачи;
— нет выдуманных цифр и кейсов.
Если где-то «нет» — перепиши этот фрагмент.
Лид-магнит: [ВСТАВИТЬ].
```

---

## Заполненный пример (онлайн-школа английского)
`[НИША]` = онлайн-школа английского · `[АУДИТОРИЯ]` = взрослые, учат язык 2+ года, боятся говорить · `[БОЛЬ]` = «не с чего начать говорить, ступор на первой фразе» · `[ПРОДУКТ]` = разговорный интенсив.

**Что вернул основной промпт (сокращённо):**
- Заголовок: «10 первых фраз, с которых начинается любой диалог».
- Обещание: после файла у тебя есть готовый вход в разговор — не думаешь «что сказать».
- Три шага: выучить блок → проговорить вслух по картинке → снять себя на 30 сек.
- Шаблон: карточка «ситуация → первая фраза → продолжение».
- Переход: «Отработать это с живым собеседником — на разговорном интенсиве».
