# День 4 · Промпты «Угол, а не тема»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ТЕМА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — развернуть тему в восемь углов
```
Ты — контент-стратег. У меня есть одна общая тема, её разбирают все в нише.
Не меняй тему. Разверни её в восемь разных углов — разных точек входа в одну тему.

Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Тема: [ТЕМА].

Дай ровно восемь углов, по одному каждого типа:
1) Ошибка — «ты делаешь X и получаешь ноль».
2) Разрушение мифа — «то, что ты считаешь правдой, — неправда».
3) Цена / потеря — «сколько ты теряешь, делая по-старому».
4) До / после — контраст двух состояний.
5) Изнутри — что видит профи и не говорит новичку.
6) Вопрос новичка — наивный вопрос, который стесняются задать.
7) Против течения — спор с общепринятым.
8) Конкретный факт — один факт или цифра как вход.

Для каждого угла: короткий хук до 9 слов + одна строка, в чём напряжение.
Живой русский язык, короткие фразы, ни одной банальной формулировки.
Тема во всех восьми — одна, меняется только заход.
```

## 2. Промпт для улучшения
```
Вот мои пять углов на одну тему: [ВСТАВИТЬ].
Заостри каждый:
— хук до 9 слов, первое слово уже работает;
— в каждом углу должно быть узнавание «это про меня» для аудитории [АУДИТОРИЯ];
— убери углы, которые повторяют тему в лоб.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мои пять углов строго, как редактор, который их отклонит.
Тема: [ТЕМА]. Углы: [ВСТАВИТЬ].
Найди: какой угол на самом деле просто повторяет тему в лоб; где нет узнавания;
где напряжение слабое; какие два угла — это один и тот же заход разными словами.
По каждому углу дай оценку 1–10 за силу захода и отметь сильнейший. Не хвали из вежливости.
```

## 4. Промпт для финальной проверки
```
Проверь мой выбранный рабочий угол по критериям и ответь да/нет по каждому:
— зритель в первую секунду думает «это про меня» (узнавание);
— в углу есть напряжение (ошибка, слом, потеря или спор);
— так эту тему в нише ещё не подавали (новизна);
— за углом стоит честный метод, а не пустая провокация;
— хук до 9 слов и первое слово работает.
Если где-то «нет» — перепиши формулировку угла и покажи исправленный вариант.
Угол: [ВСТАВИТЬ]. Тема: [ТЕМА]. Аудитория: [АУДИТОРИЯ].
```

## Заполненный пример (онлайн-тренер по фитнесу)
`[НИША]` = онлайн-тренер по женскому фитнесу · `[АУДИТОРИЯ]` = женщины 30–45, худеют годами, качают пресс, живот не уходит · `[ТЕМА]` = «как убрать живот» · `[ПРОДУКТ]` = 6-недельный марафон стройности с сопровождением.

**Что вернул основной промпт (пять живых из восьми):**
- Ошибка: «Качаешь пресс каждый день. Живот на месте.» — узнавание есть, но заход частый.
- Миф: «Пресс не сжигает жир на животе. Вообще.» — ломает убеждение, в нише почти не заходят.
- Цена: «Три года скручиваний — и ноль сантиметров.» — бьёт в жалко.
- Изнутри: «Что тренеры знают про живот, а тебе не говорят.» — статус посвящённого.
- Вопрос новичка: «С чего начать, если качаю пресс, а толку нет?» — снимает стыд.

**Рабочий угол:** миф — «Пресс не сжигает жир на животе». Максимум по критериям: узнавание + напряжение + новизна.
