# День 3 · Промпты «Боль, которую нельзя пролистнуть»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[МЕСТА]`, `[БАНК БОЛЕЙ]`. Копируй и подставляй своё.
Инструмент дня — **Perplexity** (ищет по живому вебу и даёт источники). Промпты 2–4 удобно гонять в Claude или ChatGPT.

---

## 1. Основной промпт — собрать 10 болей с источниками
```
Ты — исследователь аудитории. Помоги собрать реальные боли, а не придуманные темы.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ].
Где сидит аудитория: [МЕСТА] (комментарии под похожими роликами, отзывы на маркетплейсах и картах, вопросы в поиске).

Найди 10 реальных болей этой аудитории. Для каждой дай:
1) БОЛЬ — дословной живой фразой, как её говорит сам человек (с эмоцией и деталью, не причёсывай);
2) ИСТОЧНИК — где такое встречается (тип: комменты / отзывы / поиск), по возможности ссылка;
3) ПОЧЕМУ БОЛИТ — одна строка.

Правила: не выдумывай, бери только то, что реально встречается. Никаких общих лозунгов вроде «важно здоровье». Разные боли, без дублей по смыслу.
```

## 2. Промпт для улучшения — в живые дословные фразы
```
Вот мой банк болей: [БАНК БОЛЕЙ].
Переформулируй каждую так, как сказал бы сам клиент вслух: короче, конкретнее, с эмоцией и деталью.
Убери экспертные обороты и общие слова. Если боль звучит как лозунг — верни ей человеческую речь.
Покажи было → стало по каждой.
```

## 3. Промпт для жёсткой оценки — отбраковать выдуманное
```
Оцени мой банк болей строго, как редактор, который его отклонит. Банк: [БАНК БОЛЕЙ].
Для каждой боли реши: реальная (человек так правда говорит) или выдумана из головы.
Отбрось выдуманные и лозунги. Оставшиеся оцени по остроте по трём признакам: повтор (у многих), деньги/время (уже теряет), стыд/страх (задевает самооценку) — по плюсу за каждый.
Отсортируй по сумме плюсов и назови 3 самые острые. Ничего не хвали из вежливости.
```

## 4. Промпт для финальной проверки — да/нет по каждой боли
```
Проверь мой финальный список болей и ответь да/нет по каждому пункту: [БАНК БОЛЕЙ].
— боль сформулирована чужими словами, а не как лозунг эксперта;
— у боли есть источник;
— боль реальная, а не выдуманная из головы;
— в топ-3 попали боли с наибольшей остротой (повтор + деньги/время + стыд/страх);
— боли под одну аудиторию, без чужих.
Где «нет» — исправь этот пункт и покажи исправленную версию.
```

---

## Заполненный пример (эксперт-нутрициолог)
`[НИША]` = нутрициолог, онлайн-сопровождение по питанию · `[АУДИТОРИЯ]` = женщины 30–45, перепробовали много диет, вес возвращается, устали от запретов · `[МЕСТА]` = комменты под роликами про похудение, отзывы на БАДы на маркетплейсе, отзывы на диетологов на картах, запросы «почему вес возвращается».

**Что вернул основной промпт (фрагмент банка):**
1. «Скидываю 5 кг, за месяц возвращаются с плюсом. Уже боюсь весов.» — источник: комменты под роликом про диеты. Болит: годы усилий впустую + стыд.
2. «Сажусь на правильное питание в понедельник, к пятнице срываюсь на всё подряд.» — источник: комменты. Болит: вина за срыв.
3. «Перепробовала всё: кето, ПП, голодание. Вес стоит.» — источник: отзыв на диетолога. Болит: деньги и время на ветер.
4. «Ем мало, а вес не уходит. Что со мной не так?» — источник: запрос в поиске. Болит: страх, что «поломанный» обмен.

**Топ-3 после жёсткой оценки:** №1 (повтор + деньги/время + стыд = 3), №3 (повтор + деньги/время = 2), №4 (повтор + страх = 2).
