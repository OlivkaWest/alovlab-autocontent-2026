# День 26 · Промпты «B2B-контент»

Переменные: `[СФЕРА БИЗНЕСА]`, `[РУТИНА]`, `[КТО ПРИНИМАЕТ РЕШЕНИЕ]`, `[УСЛУГА]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать B2B-пост от рутины
```
Ты — B2B-маркетолог. Собери пост для бизнеса, который продаёт снятую рутину, а не «возможности ИИ».
Сфера бизнеса клиента: [СФЕРА БИЗНЕСА].
Рутина, которую снимаем: [РУТИНА].
Кто принимает решение: [КТО ПРИНИМАЕТ РЕШЕНИЕ].
Услуга студии, к которой ведём: [УСЛУГА].

Собери пост:
1) ХУК — про рутину/боль бизнеса, не про технологию.
2) РАЗРЫВ — «делаем руками / по-разному» против «один процесс на всех».
3) РЕШЕНИЕ — как рутина превращается в конвейер (система, а не генерация).
4) ЯЗЫК РЕЗУЛЬТАТА — часы, стабильность, независимость от исполнителя.
5) ВЫХОД НА БРИФ — мягкий переход к «отправить бриф».

Требования: язык бизнеса (процессы, время, стабильность), без «вау» и восторга.
НЕ называй цену студии — её нет. Не выдумывай цифры экономии, проценты и сроки.
Нет данных — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот B2B-пост: [ВСТАВИТЬ]. Усиль его:
— хук переведи с языка технологии на язык рутины бизнеса;
— в разрыве покажи, почему «мы уже пользуемся ИИ» — это ещё не система;
— решение подай как конвейер (стабильность), а не как красивую генерацию;
— выход на бриф сделай мягким, без давления и без цены.
Покажи, что изменил и почему бизнесу стало ближе.
```

## 3. Промпт для жёсткой оценки
```
Оцени B2B-пост строго, как занятой владелец бизнеса, которому некогда. Не хвали.
Найди: где говоришь о технологии вместо его рутины; где «вау» вместо результата;
где обещания без конкретики процесса; где проскочила выдуманная цифра экономии;
где случайно назвал цену студии.
Дай оценку 1–10 по тому, увидит ли бизнес свою снятую задачу, назови три правки.
Пост: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь B2B-пост по чек-листу, отвечай да/нет:
— хук про рутину бизнеса, а не про технологию;
— показан разрыв «руками/хаотично» против «один процесс»;
— решение подано как конвейер, а не генерация;
— язык результата: часы, стабильность, независимость от исполнителя;
— есть мягкий выход на бриф;
— цена студии НЕ названа;
— нет выдуманных цифр экономии, процентов и сроков.
Где «нет» — перепиши фрагмент.
Пост: [ВСТАВИТЬ].
```

---

## Заполненный пример (агентство/продюсерский центр)
`[СФЕРА БИЗНЕСА]` = продюсерский центр, много однотипного видеоконтента · `[РУТИНА]` = ручная нарезка reels из каждого съёмочного дня · `[КТО ПРИНИМАЕТ РЕШЕНИЕ]` = продюсер/руководитель · `[УСЛУГА]` = автоматизация контента (пайплайны под бренд).

**Что вернул основной промпт (сокращённо, без выдуманных цифр):**
- Хук: «Ваш монтажёр каждую неделю режет одни и те же reels руками».
- Разрыв: «Это не автоматизация. Автоматизация — когда нарезка идёт по одному процессу, а не зависит от того, кто сегодня в смене».
- Решение: «Собираем пайплайн под ваш бренд: исходник на входе — готовые вертикальные ролики на выходе, в едином стиле».
- Язык результата: «Выпуск перестаёт зависеть от загрузки монтажёра, стиль держится сам».
- Выход на бриф: «Опишите свой процесс в брифе — вернёмся с тем, что реально автоматизируется». (Цена не называется.)
