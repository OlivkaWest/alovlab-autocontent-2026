# День 19 · Промпты «Обложка, которая останавливает»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ТЕМА РОЛИКА]`, `[ТИП ОБЛОЖКИ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — написать крючки для обложки
```
Ты — редактор обложек для коротких видео. Твоя задача — крючки, которые
останавливают палец в ленте, а не подписывают ролик.

Ниша: [НИША]. Аудитория (кто листает ленту): [АУДИТОРИЯ].
Тема ролика: [ТЕМА РОЛИКА]. Продукт, к которому ведём: [ПРОДУКТ].

Дай 20 крючков для обложки — по типам, по 3–4 на тип:
— результат (что вышло), ошибка (ты делаешь X), до/после,
  факт (одна цифра/объект), аномалия (кадр не сходится), вопрос новичка.

Требования к каждому крючку:
— 3–5 слов, живой русский, без канцелярщины;
— это обещание или конфликт, а НЕ название («Обзор», «Наши услуги» — запрещено);
— его нельзя переставить на чужой ролик той же ниши;
— к каждому крючку — короткая визуальная идея кадра (что в кадре, где конфликт).

Не хвали. Не объясняй теорию. Только список: тип → крючок → визуальная идея.
```

## 2. Промпт для улучшения
```
Вот мои крючки для обложки: [ВСТАВИТЬ].
Усиль каждый:
— сожми до 3–5 слов, убери всё, что не работает на стоп;
— оставь один конфликт, лишнее выкинь;
— укажи ОДНО слово, которое вынести оранжевым (якорь), — то, куда падает глаз.
Покажи было → стало и одним словом почему стало сильнее.
```

## 3. Промпт для жёсткой оценки
```
Оцени мои обложки строго, как редактор, который их отклонит.
Найди по каждой:
— где это название/подпись, а не крючок (можно поставить на чужой ролик);
— где слов слишком много и на размере ленты не прочитается;
— где нет визуального конфликта — кадр ровный, глазу не за что зацепиться;
— где акцентов несколько и фокус распадается.
Дай оценку 1–10 за силу крючка и за читаемость. Ничего не хвали из вежливости.
Обложки: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь одну обложку по чек-листу и ответь да/нет по каждому пункту:
— крючок 3–5 слов, это обещание/конфликт, а не название;
— в кадре один визуальный конфликт;
— один якорь (одно оранжевое слово или объект);
— читается на размере превью в ленте (короткий текст, контраст);
— крючок нельзя переставить на чужой ролik той же ниши.
Если где-то «нет» — перепиши этот элемент и покажи исправленный вариант.
Обложка: [ВСТАВИТЬ описание: крючок + что в кадре + якорь].
```

---

## Заполненный пример (локальный бренд — кофейня)
`[НИША]` = локальная кофейня, ведёт Reels · `[АУДИТОРИЯ]` = жители района, листают ленту в обед, решают за секунду · `[ТЕМА РОЛИКА]` = как варят фирменный раф · `[ТИП ОБЛОЖКИ]` = аномалия · `[ПРОДУКТ]` = курс (владелец хочет сам снимать контент для точки).

**Что вернул основной промпт (сокращённо):**
- Ошибка: «Ты пьёшь раф неправильно» — кадр: чашка, ложка кладёт сахар, красный крест.
- До/после: «Из пакетика → из зерна» — сплит: растворимый слева, фирменный справа.
- Аномалия: «Раф без сахара. Да, так можно» — кадр крупно: чашка, рядом перечёркнутая сахарница.
- Факт: «Три ингредиента. Один вкус» — три предмета в ряд крупно.
- Вопрос: «Чем раф вообще отличается от латте?» — две чашки рядом, знак вопроса.

**Рабочая обложка:** аномалия — «Раф без сахара. Да, так можно». Кадр: чашка крупно, перечёркнутая сахарница, оранжевым — слово «без». Останавливает, потому что ломает ожидание (раф = сладкий) и держит один фокус.
