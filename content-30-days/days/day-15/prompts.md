# День 15 · Промпты «Один смысл — три площадки»

Переменные: `[НИША]`, `[ИДЕЯ]`, `[АДРЕС]` (куда ведём везде), `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать три версии
```
Ты — контент-редактор, который умеет упаковывать один смысл под разные площадки.
Ниша: [НИША]. Продукт, к которому ведём: [ПРОДУКТ]. Адрес назначения (куда ведём во всех версиях): [АДРЕС].
Идея (один смысл, менять его нельзя): [ИДЕЯ].

Собери ТРИ версии одной идеи под площадки. Меняй только три рычага, смысл держи один:
1) INSTAGRAM — вход: цепляющая первая строка под кадр/reels; тело: короткая подпись, воздух; выход: «ссылка в профиле» (кликабельной ссылки в подписи нет).
2) ВКОНТАКТЕ — вход: заголовок поста; тело: развёрнутый лонгрид-история; выход: прямая кликабельная ссылка на [АДРЕС] в тексте.
3) TELEGRAM — вход: первая строка, работающая как превью в списке чатов; тело: живой средний формат на «ты», с буллетами; выход: призыв под кнопку/файл, без IG-эмодзи и хэштегов.

Требования: живой русский язык, короткие фразы, ни одной банальной формулировки, смысл во всех трёх один, но НИ ОДНОГО дословного повтора между версиями.
```

## 2. Промпт для улучшения
```
Вот мои три версии: [ВСТАВИТЬ]. Усиль каждую под её площадку:
— Instagram: сделай первую строку такой, чтобы работала под кадр без текста; тело сократи до сути;
— ВКонтакте: добавь заголовок-крючок и разверни тело в живую историю; проверь, что ссылка стоит прямо в тексте;
— Telegram: сделай первую строку самостоятельным крючком-превью; переведи тон на «ты», убери эмодзи-мусор и хэштеги, оставь буллеты.
Покажи, что именно изменил в каждой версии и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мои три версии строго, как редактор, который отклонит скрытый копипаст.
Найди: где две версии совпадают дословно или почти; где выход не под площадку («ссылка в профиле» во ВКонтакте, мёртвая ссылка в подписи IG, эмодзи-хвост в Telegram); где тело не подстроено по длине; где первая строка в Telegram не тянет как превью.
Дай оценку 1–10 по адаптации и по тому, насколько версии реально разные. Ничего не хвали из вежливости.
Три версии: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь три версии по чек-листу и ответь да/нет по каждому пункту для каждой площадки:
— смысл во всех трёх один и тот же;
— вход переписан под механику площадки (IG — под кадр, VK — заголовок, TG — превью-строка);
— тело подстроено по длине и тону (IG коротко / VK длинно / TG средне-живо);
— выход правильный (IG — «в профиле», VK — прямая ссылка, TG — кнопка/файл);
— в Telegram нет IG-эмодзи и хэштегов;
— ни одна версия не повторяет другую дословно.
Если где-то «нет» — перепиши этот рычаг в этой версии.
Три версии: [ВСТАВИТЬ].
```

---

## Заполненный пример (салон красоты)
`[НИША]` = городской салон красоты (стрижка, окрашивание) · `[ИДЕЯ]` = «клиент уходит к другому мастеру не из-за цвета, а из-за того, что его не переспросили» · `[АДРЕС]` = запись онлайн + Telegram-канал с окошками записи · `[ПРОДУКТ]` = запись на окрашивание с консультацией.

**Что вернул основной промпт (сокращённо):**
- **Instagram:** вход — первая строка «Цвет идеальный. Клиент не вернулся.» под reels с зеркалом кресла. Тело — 2 строки: уходят не из-за рук мастера, а из-за одного невыясненного «а чего ты хотела на самом деле». Выход — «Записаться — ссылка в профиле».
- **ВКонтакте:** заголовок «Почему клиент уходит к другому мастеру, когда цвет идеальный». Тело — лонгрид: история одной записи, где мастер переспросил и где не переспросил, разница в результате. Выход — прямая кликабельная ссылка на онлайн-запись в конце поста.
- **Telegram:** первая строка-превью «Разобрали, почему уходят даже от хорошего мастера — дело не в цвете». Тело — живой разбор на «ты», буллеты «что спросить перед окрашиванием». Выход — кнопка «Записаться» + закреплённое окошко свободных слотов, без эмодзи и хэштегов.
