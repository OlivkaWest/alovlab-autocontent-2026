# День 13 · Промпты «Стабильный персонаж» (NanoBanana)

Переменные: `[НИША]`, `[ГЕРОЙ]`, `[ЯКОРЯ]`, `[СЦЕНА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
`[ЯКОРЯ]` — пять пунктов: лицо · волосы · образ/подпись · палитра/свет · возраст/телосложение.

Промпты 1–2 отправляй в NanoBanana (Gemini 2.5 Flash Image) для генерации. К промптам про сцену **прикрепляй файл эталона**. Промпты 3–4 — сверка кадра с эталоном.

---

## 1. Основной промпт — собрать эталонный портрет
```
Создай портрет одного человека — это будет эталон-референс для серии.
Ниша: [НИША]. Герой: [ГЕРОЙ].
Зафиксируй пять якорей и держи их точно:
— Лицо: [ЯКОРЯ: лицо]
— Волосы: [ЯКОРЯ: волосы]
— Образ и деталь-подпись: [ЯКОРЯ: образ]
— Палитра и свет: [ЯКОРЯ: палитра/свет]
— Возраст и телосложение: [ЯКОРЯ: возраст]

Кадр: анфас, взгляд в камеру, ровный дневной свет, нейтральный фон, по грудь.
Реалистично, чётко, без искажений лица. Один человек в кадре.
```

## 2. Промпт улучшения — заострить якоря
```
Вот описание моего героя: [ЯКОРЯ].
Найди в нём формулировки, из-за которых нейросеть будет рисовать разные лица
(слишком общие, неоднозначные, «приятная внешность» и т.п.).
Перепиши каждый якорь конкретно и однозначно, чтобы лицо, волосы, образ и возраст
читались одинаково в любом кадре. Верни готовые пять якорей списком.
```

## 3. Промпт жёсткой оценки — сверить кадр с эталоном
```
Перед тобой два изображения: первое — эталон героя, второе — кадр из серии.
Сравни строго, как ретушёр, который завернёт брак.
Проверь по пунктам: лицо (черты, форма), волосы, деталь-подпись, свет и тон, возраст.
Назови каждое расхождение конкретно: где второй кадр — уже другой человек.
Вердикт: совпадает / не совпадает. Ничего не сглаживай из вежливости.
Эталон и кадр прикреплены.
```

## 4. Промпт финальной проверки — да/нет по совпадению
```
Ответь да/нет по каждому пункту для кадра относительно эталона:
— это то же лицо (черты, форма);
— волосы совпадают (длина, цвет, укладка);
— деталь-подпись на месте и та же;
— свет и палитра как в серии;
— возраст и телосложение те же.
Если хоть одно «нет» — скажи, что переснять в сцене, не меняя якоря.
Эталон и кадр прикреплены.
```

## Заполненный пример (маркетплейс — бренд женской одежды)
`[НИША]` = бренд женской одежды на маркетплейсе · `[ГЕРОЙ]` = модель «Ника», лицо коллекции · `[ПРОДУКТ]` = капсульная коллекция, карточки товара.

`[ЯКОРЯ]`:
- Лицо: овальное, светлые брови, веснушки на скулах, мягкая улыбка.
- Волосы: русые, до плеч, прямой пробор.
- Образ / подпись: тонкая золотая цепочка, всегда в кадре.
- Палитра / свет: тёплый студийный свет, бежево-песочные тона.
- Возраст / телосложение: 28 лет, стройная, ровная осанка.

**Эталон (промпт 1):** портрет Ники анфас, ровный тёплый свет, нейтральный фон, золотая цепочка видна.

**Сцена 1 (промпт с прикреплённым эталоном):**
```
Это тот же человек с фото. Сохрани лицо, волосы, золотую цепочку и возраст.
Помести её в сцену: [СЦЕНА = стоит у большого окна в бежевом пальто, дневной свет].
```
Дальше сцены 2 и 3 — от того же эталона: та же Ника на светлом фоне для карточки · крупный план с акцентом на цепочку. Одно лицо во всех трёх кадрах.
