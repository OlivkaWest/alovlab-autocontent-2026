# День 25 · Промпты «Кейс, который продаёт»

Переменные: `[НИША]`, `[КЛИЕНТ]`, `[ЧТО СДЕЛАЛИ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать кейс без выдумки
```
Ты — редактор кейсов. Собери кейс как историю клиента из трёх частей, без выдуманных данных.
Ниша: [НИША]. Клиент и его ситуация: [КЛИЕНТ].
Что реально сделали: [ЧТО СДЕЛАЛИ]. Продукт: [ПРОДУКТ].

Собери три части:
1) БЫЛО — честная точка старта клиента (его ситуация и боль до).
2) ЧТО СДЕЛАЛИ — процесс без магии и преувеличений.
3) СТАЛО — реальное изменение. Цифру ставь ТОЛЬКО если я её дал.
   Если цифры нет — покажи сдвиг состояния словами (было страшно → делает сам).

Герой истории — клиент, не я. Живой русский, коротко.
ЖЁСТКОЕ ПРАВИЛО: не выдумывай цифры, суммы, проценты и сроки.
Чего нет в моих данных — того нет в кейсе. Где данных нет — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот мой кейс: [ВСТАВИТЬ]. Усиль его, ничего не выдумывая:
— в «было» добавь конкретную деталь ситуации клиента;
— в «что сделали» убери магию, покажи реальный ход;
— в «стало» сделай сдвиг наглядным (состояние до → после);
— проверь, что герой — клиент, а не я.
Не добавляй цифр, которых я не давал. Покажи, что изменил.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой кейс строго, как скептик, который не верит кейсам. Не хвали.
Найди: где хвастовство вместо истории клиента; где цифра выглядит выдуманной;
где магия вместо процесса; где герой — автор, а не клиент.
Отдельно: отметь любую цифру или факт, которые выглядят непроверяемыми.
Дай оценку 1–10 по доверию и назови три правки.
Кейс: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь кейс по чек-листу, отвечай да/нет:
— есть три части: было → что сделали → стало;
— герой истории — клиент, а не автор;
— каждая цифра реальная (я её давал), выдуманных нет;
— где цифры нет, показан сдвиг состояния словами;
— нет хвастовства и магии;
— звучит как правда, а не как реклама.
Где «нет» — перепиши эту часть. Любую сомнительную цифру убери.
Кейс: [ВСТАВИТЬ].
```

## Заполненный пример (контент с помощью ИИ)
`[НИША]` = помощь с контентом через ИИ · `[КЛИЕНТ]` = эксперт, вёл блог руками, выгорал · `[ЧТО СДЕЛАЛИ]` = собрали связку «одна идея → три формата» и простой конвейер · `[ПРОДУКТ]` = курс / метод AlovLab.

**Что вернул основной промпт (сокращённо, без выдуманных цифр):**
- Было: «Делал контент с нуля каждый день. Утром придумывал тему, вечером не было сил. Бросал на неделю, потом снова».
- Что сделали: «Показали ход: одна идея раскладывается на карусель, Reels и разбор. Собрали первый конвейер на неделю».
- Стало: «Теперь собирает неделю контента за один вечер. Не выгорает от вопроса "что постить"». (Цифр нет — показан сдвиг состояния.)
