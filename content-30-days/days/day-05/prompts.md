# День 5 · Промпты «Конфликт вместо информации»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ФАКТ]`, `[УБЕЖДЕНИЕ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
`[ФАКТ]` — нейтральный полезный тезис. `[УБЕЖДЕНИЕ]` — во что аудитория по этой теме уже верит.

---

## 1. Основной промпт — найти конфликт в факте
```
Ты — редактор, который превращает сухую информацию в контент с напряжением.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Мой факт (нейтральная версия): [ФАКТ].
Во что аудитория по этой теме уже верит: [УБЕЖДЕНИЕ].

Задача: не меняя смысл факта, столкни его с убеждением аудитории.
Дай по одному варианту первой строки на каждую из шести механик:
1) слом убеждения; 2) цена против качества; 3) хаос против системы;
4) любитель против профи; 5) смена точки зрения; 6) что теряешь из-за ошибки.

Требования: живой русский язык, короткие фразы, конфликт внутри темы, без крика и капса.
Ни одного обещания, которого нет в факте. Ничего выдуманного.
После первой строки должно возникать «в смысле?».
```

## 2. Промпт для улучшения
```
Вот моя версия: [ВСТАВИТЬ].
Усиль её:
— вынеси конфликт в самую первую строку;
— убери кликбейт и любые обещания, которых нет в факте;
— оставь ровно одну механику конфликта, лишнее вычеркни;
— сохрани исходный смысл факта полностью.
Покажи, что именно изменил и почему стало сильнее.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой текст строго, как редактор, который его отклонит.
Раздели: где реальное напряжение (факт честно спорит с привычкой),
а где просто громкая пустая фраза без содержания.
Найди: где потерялся факт, где обещание не подтверждено материалом, где конфликт натянут.
Дай оценку 1–10 по силе конфликта и по честности. Ничего не хвали из вежливости.
Текст: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь текст по чек-листу и ответь да/нет по каждому пункту:
— смысл исходного факта сохранён полностью;
— конфликт стоит в первой строке;
— использована ровно одна механика;
— обещание честное, ничего выдуманного нет;
— нет крика и капса, напряжение внутри темы;
— есть переход в Telegram.
Если где-то «нет» — перепиши этот фрагмент.
Текст: [ВСТАВИТЬ].
```

## Заполненный пример (онлайн-нутрициолог)
`[НИША]` = онлайн-нутрициолог, сопровождение по питанию · `[АУДИТОРИЯ]` = женщины 30–45, считают калории, вес встал, устали от таблиц · `[ФАКТ]` = «утром лучше есть белок — он дольше держит сытость» · `[УБЕЖДЕНИЕ]` = «я завтракаю правильно: овсянка и фрукт» · `[ПРОДУКТ]` = 6-недельное сопровождение «Питание без подсчётов».

**Что вернул основной промпт (по шести механикам, первая строка):**
- Слом убеждения: «Твой „правильный“ завтрак держит тебя в жире».
- Цена против качества: «Спортпит за 8 тысяч проиграл варёному яйцу».
- Хаос против системы: «Ты считаешь калории каждый день. А худеет та, что считает раз в неделю».
- Любитель против профи: «Новичок режет еду. Профи меняет порядок блюд».
- Смена точки зрения: «Ты борешься с аппетитом. А проблема — во сне».
- Что теряешь из-за ошибки: «Каждое утро без белка — минус час сытости и лишний перекус».

**Выбрано для поста:** слом убеждения. Смысл факта («утром нужен белок») сохранён, добавлен один честный конфликт, обещание не раздуто.
