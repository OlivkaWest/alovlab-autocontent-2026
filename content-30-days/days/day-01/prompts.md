# День 1 · Промпты «Одна идея — три формата»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ИДЕЯ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать связку
```
Ты — контент-стратег. Помоги разложить одну идею на три формата.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Идея дня: [ИДЕЯ].

Собери связку из трёх ролей одной идеи:
1) КАРУСЕЛЬ (останавливает): хук до 9 слов + конфликт + одна сильная мысль.
2) REELS (объясняет): один применимый приём + пример за 15 секунд.
3) TELEGRAM (доводит до результата): что положить в разбор, чтобы человек получил результат.

Требования: живой русский язык, короткие фразы, ни одной банальной формулировки, один смысл во всех трёх форматах без дословных повторов.
```

## 2. Промпт для улучшения
```
Вот моя связка: [ВСТАВИТЬ]. Усиль её:
— в карусели сделай хук острее и короче (до 9 слов);
— в Reels оставь ровно один приём, лишнее убери;
— в Telegram добавь конкретный шаг, который даёт результат сегодня.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мою связку строго, как редактор, который её отклонит.
Найди: где банально, где вода, где формат повторяет другой дословно, где хук объясняет вместо того чтобы остановить.
Дай оценку 1–10 по силе идеи и по конкретности. Ничего не хвали из вежливости.
Связка: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь связку по чек-листу и ответь да/нет по каждому пункту:
— есть один смысл во всех трёх форматах;
— карусель останавливает, Reels объясняет, Telegram доводит до результата;
— нет банальных и запрещённых фраз;
— есть конкретный пример;
— есть явный переход в Telegram.
Если где-то «нет» — перепиши этот фрагмент.
Связка: [ВСТАВИТЬ].
```

---

## Заполненный пример (онлайн-школа английского)
`[НИША]` = онлайн-школа английского · `[АУДИТОРИЯ]` = взрослые, учат язык 2+ года, боятся говорить · `[ИДЕЯ]` = «учишь слова, а говорить всё равно страшно» · `[ПРОДУКТ]` = разговорный интенсив.

**Что вернул основной промпт (сокращённо):**
- Карусель: хук «Ты знаешь 3000 слов и молчишь». Конфликт: словарь ≠ речь. Мысль: говорить учит только говорение.
- Reels: приём «5 минут вслух в день по одной картинке», пример на экране.
- Telegram: разбор + чек-лист «как за неделю заговорить на простых темах» + приглашение на интенсив.
