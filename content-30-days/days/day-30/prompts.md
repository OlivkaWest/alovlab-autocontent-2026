# День 30 · Промпты «Твоя система»

Переменные: `[НИША]`, `[ЧТО ОСВОИЛ]`, `[ЧТО УСИЛИТЬ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать личную систему
```
Ты — стратег по личным системам. Помоги собрать мой контент-конвейер в одну повторяемую систему.
Ниша: [НИША]. Продукт: [ПРОДУКТ].
Что я освоил за месяц: [ЧТО ОСВОИЛ].

Собери систему из трёх блоков:
1) ПОНЕДЕЛЬНИК (делаю сам) — идея недели, связка «одна идея — три формата», смысл.
2) БОТ (отдал машине) — что автоматизировано: выдача, автоответы, приветствия.
3) ПЯТНИЦА (смотрю цифры) — какие метрики читаю и какие выводы делаю.

Всё — на одну страницу, как повторяемый недельный цикл.
Отметь, где нужен именно я, а где работает система без меня.
Живой русский, коротко, конкретные шаги. Не выдумывай того, чего я не осваивал.
```

## 2. Промпт — план на 30 дней вперёд
```
Ты — планировщик. Собери мне план на следующие 30 дней на основе моей системы.
Ниша: [НИША]. Что усилить (из разбора месяца): [ЧТО УСИЛИТЬ].

Собери:
1) РИТМ НЕДЕЛИ — что и в какой день делаю (пропорция: польза 2 / смысл 1 / кейс 1 / приглашение 1).
2) ЧТО УСИЛИВАЮ — как повторяю то, что сработало в прошлом месяце.
3) ПЕРВАЯ ТЕМА — с чего начинаю первую неделю.
4) ТОЧКИ РАЗБОРА — когда смотрю цифры и корректирую.

Приглашение — не чаще одного на неделю, без давления. Живой русский.
Не выдумывай цифр и дедлайнов. Нет данных — пиши «нет данных».
```

## 3. Промпт для жёсткой оценки
```
Оцени мою систему и план строго, как человек, который бросит это через неделю. Не хвали.
Найди: где система слишком сложная, чтобы повторять; где нет чёткого «делаю сам / отдал боту»;
где план на месяц размытый; где приглашение чаще одного на неделю (давление).
Дай оценку 1–10 по тому, реально ли повторять это каждую неделю, назови три правки.
Система и план: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь систему и план по чек-листу, отвечай да/нет:
— система умещается на одну страницу и повторяема;
— ясно разделено «делаю сам / отдал боту / смотрю цифры»;
— в плане есть ритм недели с пропорцией опор;
— учтено, что усилить из разбора;
— приглашение не чаще одного на неделю;
— нет выдуманных цифр и дедлайнов.
Где «нет» — перепиши.
Система и план: [ВСТАВИТЬ].
```

## Заполненный пример (эксперт с контентом и воронкой)
`[НИША]` = обучение/эксперт · `[ЧТО ОСВОИЛ]` = связка «одна идея — три формата», воронка, оффер, кейс, диалог, автоматизация, разбор · `[ЧТО УСИЛИТЬ]` = формат «результат на глазах + метод» (пик месяца) · `[ПРОДУКТ]` = курс/метод.

**Что вернул основной промпт (сокращённо):**
- ПОНЕДЕЛЬНИК: выбрать одну идею недели → собрать связку (карусель + Reels + разбор) → написать смысловой пост.
- БОТ: кодовое слово → выдача магнита; автоответ на 5 вопросов; приветствие с маршрутом.
- ПЯТНИЦА: смотрю досмотр, долю неподписчиков, переходы, заявки → один вывод «усилить», один «резать».
- План 30 дней: ритм 2:1:1:1, усиливаю формат-пик, первая тема — сильнейший приём месяца, разбор по пятницам.
