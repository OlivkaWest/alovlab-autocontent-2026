# День 8 · Промпты «Бриф для ИИ»

Переменные: `[НИША]`, `[ПРОДУКТ]`, `[АУДИТОРИЯ]`, `[РОЛЬ ИИ]`, `[КРИТЕРИЙ]`, `[ЗАДАЧА]`. Копируй и подставляй своё.

---

## 1. Основной промпт — ответ по брифу
```
КОНТЕКСТ. Ниша: [НИША]. Продукт: [ПРОДУКТ]. Аудитория (конкретно): [АУДИТОРИЯ].
РОЛЬ. Ты — [РОЛЬ ИИ]. Пишешь живым русским языком, штампы вычёркиваешь.
КРИТЕРИЙ хорошего ответа: [КРИТЕРИЙ].
(например: один хук в первой строке; одна деталь, которую нельзя выдумать; до 400 знаков;
без «мы рады представить», «незабываемый», «уникальный»; финал — конкретный следующий шаг.)

ЗАДАЧА: [ЗАДАЧА].

Сначала выполни задачу строго по критерию. Затем одной строкой скажи, какой блок брифа
дал тебе больше всего — контекст, роль или критерий.
```

## 2. Промпт для улучшения
```
Вот мой ответ: [ВСТАВИТЬ]. И вот мой критерий: [КРИТЕРИЙ].
Усиль ответ, не меняя смысла:
— выкинь каждое слово, которое подойдёт любому конкуренту (штампы, общие прилагательные);
— оставь и заостри одну конкретную деталь, которую нельзя выдумать;
— проверь длину и финал по критерию.
Покажи, что именно убрал и что усилил, и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой ответ строго, как редактор, который его отклонит.
Найди: где штамп, где вода, где текст подошёл бы любому в нише, где нет обещанной детали.
Отдельно скажи: какого блока брифа мне не хватило — контекста, роли или критерия —
и что именно дописать, чтобы ответ перестал быть серым.
Дай оценку 1–10 по конкретности и по живости языка. Ничего не хвали из вежливости.
Ответ: [ВСТАВИТЬ]. Мой бриф: [ВСТАВИТЬ КОНТЕКСТ/РОЛЬ/КРИТЕРИЙ].
```

## 4. Промпт для финальной проверки
```
Проверь текст по чек-листу и ответь да/нет по каждому пункту:
— есть один хук в первой строке;
— есть хотя бы одна конкретная деталь, которую нельзя выдумать;
— нет штампов и запрещённых слов из критерия;
— соблюдены формат и длина;
— финал ведёт к конкретному следующему шагу.
Если где-то «нет» — перепиши только этот фрагмент, не трогая остальное.
Текст: [ВСТАВИТЬ]. Критерий: [КРИТЕРИЙ].
```

---

## Заполненный пример (семейная итальянская траттория)
`[НИША]` = семейная итальянская траттория в Казани · `[ПРОДУКТ]` = ужины на двоих, новинка меню качо э пепе · `[АУДИТОРИЯ]` = пары 28–40, приходят вечером, ценят атмосферу · `[РОЛЬ ИИ]` = SMM-редактор, ненавидит штампы · `[КРИТЕРИЙ]` = один хук в первой строке; одна деталь, которую нельзя выдумать; до 400 знаков; без «мы рады представить» и «незабываемый»; финал — приглашение забронировать столик · `[ЗАДАЧА]` = пост про новинку меню.

**Что вернул основной промпт (сокращённо):**
> «Пасту крутят прямо у вашего столика — в круге пекорино, который старше некоторых наших официантов. Качо э пепе: три ингредиента, ноль соусов из банки. Вечер вторника, стол на двоих у окна ещё свободен. Бронь — в описании профиля».
> Больше всего дал **критерий**: запрет на «мы рады представить» и требование конкретной детали убрали штамп и вытащили сцену «крутят при госте».
