# День 14 · Промпты «Оживить кадр»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[КАДР]`, `[ЗАДАЧА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
Эти промпты собирают сценарий оживления. Само видео делают Seedance, ElevenLabs и HeyGen — сюда идёт текстовая раскадровка для них.

---

## 1. Основной промпт — собрать сценарий оживления
```
Ты — режиссёр коротких видео. Помоги оживить один статичный кадр в ролик 9:16.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Что на кадре: [КАДР]. Задача ролика: [ЗАДАЧА].

Собери связку из четырёх ролей:
1) ДВИЖЕНИЕ (для Seedance): опиши ОДНО тихое движение — оживание среды или медленный проезд камеры. Не трогай лица и мелкий текст. Движение тише кадра.
2) ГОЛОС (для ElevenLabs): одна короткая фраза бренда — спокойная, тёплая, с приглашением. Одно предложение.
3) ЛИЦО (для HeyGen): две реплики аватара — открытие (2-4 сек) и финальный CTA в Telegram.
4) СБОРКА: порядок склейки трёх частей в один ролик.

Требования: живой русский язык, короткие фразы, ни одной банальной формулировки, один смысл на весь ролик, спокойный тон наставника, без зазыва.
```

## 2. Промпт для улучшения
```
Вот мой сценарий оживления: [ВСТАВИТЬ]. Усиль его:
— движение для Seedance сделай тише и естественнее, убери всё, что может сломать кадр;
— фразу голоса сократи и сделай теплее, без напора;
— реплики аватара заостри: открытие должно останавливать, CTA — вести в Telegram за конкретным.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой сценарий оживления строго, как режиссёр, который его завернёт.
Найди: где движение перекручено и развалит кадр, где голос звучит как зазывала, где реплики банальны, где ролик красивый, но без выхода в Telegram.
Дай оценку 1-10 по естественности движения и по силе CTA. Ничего не хвали из вежливости.
Сценарий: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь сценарий по чек-листу и ответь да/нет по каждому пункту:
— движение одно и тихое, лица и текст не трогает;
— голос — одна спокойная фраза бренда, без зазыва;
— у аватара есть открытие и финальный CTA в Telegram;
— три части складываются в цельный ролик, а не в нарезку;
— виден один смысл на весь ролик.
Если где-то «нет» — перепиши этот фрагмент.
Сценарий: [ВСТАВИТЬ].
```

---

## Заполненный пример (маркетплейс)
`[НИША]` = продавец на маркетплейсе, категория товаров для дома · `[АУДИТОРИЯ]` = женщины 25–40, листают карточки в приложении, устали от одинаковых статичных фото на белом фоне · `[КАДР]` = фото керамической кружки ручной работы на белом фоне · `[ЗАДАЧА]` = перевести из ленты в карточку товара и на покупку · `[ПРОДУКТ]` = кружка ручной работы.

**Что вернул основной промпт (сокращённо):**
- **Движение (Seedance):** медленный наезд камеры на кружку, лёгкий пар поднимается над краем, мягкий блик скользит по глазури. Фон и текст не трогаем.
- **Голос (ElevenLabs):** спокойный тёплый женский — «Такая кружка греет руки и делает утро тише».
- **Лицо (HeyGen):** аватар-мастер открывает «Покажу кружку, которую хочется держать» и закрывает «Забирай в карточке, ссылка ниже».
- **Сборка:** аватар (3 сек) → ожившая кружка с паром под голос (5 сек) → аватар с CTA.
