# День 28 · Промпты «Автоматизация»

Переменные: `[НИША]`, `[ПРОЦЕССЫ]`, `[ИНСТРУМЕНТ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — карта автоматизации
```
Ты — специалист по автоматизации процессов. Помоги разделить мою работу на «машине» и «мне».
Ниша: [НИША]. Продукт: [ПРОДУКТ].
Мои повторяющиеся процессы за неделю: [ПРОЦЕССЫ].

Разложи все процессы на две колонки:
1) МАШИНЕ — то, что делается одинаково каждый раз (выдача файла, автоответы, приветствия).
2) МНЕ — то, где нужен человек (идея, смысл, позиция, живой диалог).

Для колонки «машине» предложи для КАЖДОГО процесса:
— простую связку, с чего начать (бот, автоответ, шаблон);
— что для этого нужно минимально.

Начни с одного самого частого процесса. Не предлагай сложных систем на старте.
Живой русский, коротко. Не выдумывай инструментов и цен. Нет данных — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот моя карта автоматизации: [ВСТАВИТЬ]. Усиль её:
— проверь, не попало ли в «машине» то, где на самом деле нужен я;
— для самого частого процесса упрости связку до минимума;
— убери всё, что усложняет старт;
— оставь один процесс для автоматизации сегодня, остальное — на потом.
Покажи, что изменил и почему стало проще запустить.
```

## 3. Промпт для жёсткой оценки
```
Оцени мою карту автоматизации строго, как человек, у которого нет времени на настройку. Не хвали.
Найди: где в «машине» оказалось творчество; где связка слишком сложная для старта;
где автоматизируется всё сразу вместо одного; где предложен инструмент, которого у меня нет.
Дай оценку 1–10 по реалистичности запуска сегодня, назови три правки.
Карта: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь карту автоматизации по чек-листу, отвечай да/нет:
— рутина и творчество разделены верно (машине — одинаковое, мне — где нужен я);
— для каждого процесса «машине» есть простая связка;
— выбран ОДИН процесс для запуска сегодня;
— связки реалистичны без сложных систем;
— нет выдуманных инструментов и цен.
Где «нет» — перепиши.
Карта: [ВСТАВИТЬ].
```

## 5. Промпт для проверки недели 4
```
Помоги провести самооценку недели 4 (воронка и монетизация).
Задай мне по одному вопросу за раз и жди ответа:
1) Собран ли лид-магнит? 2) Нарисована ли воронка? 3) Есть ли оффер от задачи?
4) Собран ли честный кейс? 5) Готов ли скрипт диалога? 6) Автоматизирован ли один процесс?
После ответов — назови, что доделать в первую очередь и с чего начать неделю 5.
```

---

## Заполненный пример (эксперт-одиночка с контентом и воронкой)
`[НИША]` = эксперт, ведёт контент и воронку сам · `[ПРОЦЕССЫ]` = выдача магнита, ответы на частые вопросы, приветствие подписчиков, придумывание идей, написание постов, ведение диалогов · `[ИНСТРУМЕНТ]` = Telegram-бот · `[ПРОДУКТ]` = курс/метод.

**Что вернул основной промпт (сокращённо):**
- МАШИНЕ: выдача магнита по кодовому слову; автоответ на 5 частых вопросов; приветствие новому подписчику с маршрутом.
- МНЕ: идеи для контента; смысл и позиция в постах; живой диалог в продаже.
- Связка на старт (самое частое): кодовое слово → бот отдаёт PDF + первое сообщение. Нужно минимально: бот-конструктор и загруженный файл.
