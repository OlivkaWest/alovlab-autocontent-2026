# День 20 · Промпты «Монтаж, который держит»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ТЕКСТ РОЛИКА]`, `[ДЛИНА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — найти провисания
```
Ты — монтажёр коротких вертикальных роликов, который отвечает за удержание.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Вот текст/расшифровка ролика (длина ~[ДЛИНА] сек):
[ТЕКСТ РОЛИКА]

Пройди по тексту и найди все места, где зритель залистает:
1) РАЗГОН В НАЧАЛЕ — приветствия и подводки вместо удара в первом кадре.
2) ПАУЗЫ И ВОДА — «эээ», «ну», «короче», лишние вводные, повторы мысли.
3) ПЛАТО — куски, где долго говорится об одном без нового поворота (зритель заскучает).
Для каждого места дай: что резать, и как переписать под удар.
Отдельно предложи первый кадр-хук до 9 слов вместо текущего начала.
Пиши живым русским, коротко, без банальностей.
```

## 2. Промпт для улучшения
```
Вот мой текст ролика: [ТЕКСТ РОЛИКА]. Усиль под удержание:
— перепиши первую фразу так, чтобы после неё нельзя было пролистнуть (до 9 слов);
— убери всю воду и повторы, оставь плотную речь;
— расставь, где по смыслу должна меняться картинка (смена плана / врезка / зум).
Покажи версию «было → стало» по каждому изменению и почему так держит лучше.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой ролик строго, как редактор, который его снимет с публикации.
Текст: [ТЕКСТ РОЛИКА].
Найди: где всё равно провиснет в эфире, где начало не бьёт, где мысль тянется,
где зритель без звука ничего не поймёт без субтитров.
Дай оценку 1–10 по силе хука и по плотности. Ничего не хвали из вежливости.
Скажи прямо, на какой секунде уйдёт средний зритель и почему.
```

## 4. Промпт для финальной проверки
```
Проверь смонтированный ролик по чек-листу удержания, ответь да/нет по каждому пункту:
— первый кадр это хук, а не приветствие;
— в речи нет пауз, «эээ» и воды;
— картинка меняется каждые 2–4 секунды;
— ролик понятен без звука (нужны ли субтитры);
— нет мельтешения ради мельтешения;
— есть явный переход в Telegram в финале.
Текст/описание ролика: [ТЕКСТ РОЛИКА].
Если где-то «нет» — скажи, что именно поправить на таймлайне.
```

---

## Заполненный пример (мастер маникюра)
`[НИША]` = мастер маникюра · `[АУДИТОРИЯ]` = девушки и мастера-новички, смотрят без звука в дороге · `[ТЕКСТ РОЛИКА]` = «Привет, девочки, сегодня расскажу, почему гель-лак скалывается… эээ… ну в общем дело в подготовке ногтя…» · `[ДЛИНА]` = 40 сек · `[ПРОДУКТ]` = обучение для начинающих мастеров.

**Что вернул основной промпт (сокращённо):**
- Разгон: «Привет, девочки, сегодня расскажу» — под нож. Первый кадр-хук: «Скалывается через два дня? Дело не в лаке».
- Вода: «эээ», «ну в общем» — вырезать, речь сжать с 40 до ~31 сек.
- Плато: подготовка ногтя объясняется ровно 12 секунд одним планом — разбить на шаги с врезками рук крупно, смена кадра каждые 3 сек.
- Без звука: наложить субтитры на весь ролик, «два дня» и «подготовка» — оранжевым.
