# День 24 · Промпты «Оффер, а не купи»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ЗАДАЧА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать оффер от задачи
```
Ты — копирайтер по офферам. Собери оффер, который начинается с задачи клиента, а не с продукта.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ].
Задача клиента, которую закрываем: [ЗАДАЧА]. Продукт: [ПРОДУКТ].

Собери оффер по формуле, блок за блоком:
1) КОНТЕКСТ — опиши ситуацию человека так, чтобы он узнал себя.
2) ПРОБЛЕМА — назови, где именно болит, без общих слов.
3) РЕШЕНИЕ — как продукт закрывает эту задачу (здесь впервые называем продукт).
4) ШАГ — простой следующий шаг, без давления и таймеров.

Требования: язык клиента, а не язык продукта; продукт появляется только в блоке «решение»;
живой русский, коротко, без «купи» и «успей». Не выдумывай цифры, кейсы, скидки и сроки.
Нет данных — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот мой оффер: [ВСТАВИТЬ]. Усиль его:
— в «контексте» добавь деталь, по которой человек точно узнает себя;
— в «проблеме» убери общие слова, назови конкретную боль;
— в «решении» покажи связь продукта именно с этой задачей, без перечисления фич;
— «шаг» сделай маленьким и лёгким.
Покажи, что изменил и почему стало убедительнее.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой оффер строго, как человек, у которого нет денег и нет доверия. Не хвали.
Найди: где начинается с продукта вместо задачи; где язык продукта вместо языка клиента;
где давление и «купи»; где выдуманные цифры или сроки.
Дай оценку 1–10 по тому, узнаёт ли человек свою задачу, и назови три правки.
Оффер: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь оффер по чек-листу, отвечай да/нет:
— начинается с задачи клиента, а не с продукта;
— человек узнаёт себя в контексте и проблеме;
— продукт появляется только в блоке «решение»;
— следующий шаг простой, без давления;
— язык клиента, а не язык продукта;
— нет выдуманных цифр, скидок и сроков.
Где «нет» — перепиши блок.
Оффер: [ВСТАВИТЬ].
```

## Заполненный пример (онлайн-школа английского)
`[НИША]` = онлайн-школа английского · `[АУДИТОРИЯ]` = взрослые, учат язык 2+ года, боятся говорить · `[ЗАДАЧА]` = «перестать молчать и начать говорить» · `[ПРОДУКТ]` = разговорный интенсив.

**Слабый оффер (было):** «Разговорный интенсив. 8 занятий, носители, сертификат. Старт скоро — записывайтесь».

**Сильный оффер (стало, по формуле):**
- Контекст: «Ты учишь язык не первый год. Слова знаешь, тесты сдаёшь».
- Проблема: «Но в реальном разговоре — ступор. Голова пустая, говорить страшно».
- Решение: «Дело не в словах, а в отсутствии практики речи. Разговорный интенсив — это только говорение, с первого занятия».
- Шаг: «Приходи на пробное занятие — проверишь, как это, без обязательств».
