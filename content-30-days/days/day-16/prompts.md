# День 16 · Промпты «Профиль как мост»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ЧТО ЗАБРАТЬ]`, `[ССЫЛКА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать мост
```
Ты — контент-стратег по упаковке профиля. Перепиши профиль из «витрины про меня» в «мост, который ведёт зрителя в Telegram».
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Что зритель забирает: [ЧТО ЗАБРАТЬ]. Ссылка: [ССЫЛКА]. Продукт, к которому ведём: [ПРОДУКТ].

Контекст: зритель приходит холодным с одного Reels. У профиля 3 секунды.

1) ШАПКА — дай 3 варианта по формуле из четырёх блоков:
   — про что (польза зрителю, не должность),
   — для кого (одна фраза узнавания «это про меня»),
   — что забрать (конкретика: гайд/чек-лист/промпт),
   — куда нажать (ссылка + стрелка ↓).
2) ЗАКРЕП — идея первого поста/Reels, который ловит новичка и даёт шаг в Telegram.
3) ХАЙЛАЙТЫ — 5 коротких глагольных названий по пути новичка: старт → метод → забрать → результаты → в Telegram.

Требования: живой русский, короткие фразы, ни одной должности вместо выгоды, ни одной банальной формулировки. Всё ведёт в одну точку — Telegram.
```

## 2. Промпт для улучшения
```
Вот моя шапка и план профиля: [ВСТАВИТЬ]. Усиль:
— в шапке замени любую должность/статус на выгоду зрителя;
— обостри «для кого» так, чтобы нужный человек узнал себя за 3 секунды;
— сделай «что забрать» конкретным, убери «подписывайся»;
— проверь, что ссылка и стрелка на месте.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой профиль строго, как редактор, который его отклонит.
Найди: где шапка описывает меня вместо шага зрителя, где должность вместо выгоды, где нет узнавания, где нет конкретного «что забрать», где хайлайты — витрина, а не маршрут.
Дай оценку 1–10 по «ведёт ли зрителя в Telegram» и по конкретности. Ничего не хвали из вежливости.
Профиль: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь профиль по чек-листу и ответь да/нет по каждому пункту:
— шапка про выгоду зрителя, а не про должность;
— есть «для кого» с узнаванием за 3 секунды;
— есть конкретное «что забрать»;
— есть прямая ссылка со стрелкой;
— закреп ловит новичка с Reels;
— 5 хайлайтов идут по пути новичка, а не как витрина;
— все три зоны ведут в одну точку — Telegram.
Если где-то «нет» — перепиши этот фрагмент.
Профиль: [ВСТАВИТЬ].
```

## Заполненный пример (частный психолог)
`[НИША]` = частный психолог, Reels про тревогу · `[АУДИТОРИЯ]` = взрослые 28–45, тревожные, устали от «просто дыши» · `[ЧТО ЗАБРАТЬ]` = чек-лист «тревога вечером» + разбор · `[ССЫЛКА]` = t.me/AlovLab · `[ПРОДУКТ]` = мини-курс «Тревога под контролем».

**Что вернул основной промпт (сокращённо):**
- Шапка (сильный вариант): «Разбираю тревогу простыми словами. Если устал от "просто дыши" — тебе сюда. Разбор и чек-лист в Telegram ↓ t.me/AlovLab».
- Закреп: Reels «Тревога вечером — не случайность» + подпись «Новенький? Забери разбор в Telegram».
- Хайлайты: «Старт» · «Забрать чек-лист» · «Как я разбираю тревогу» · «Стало легче (примеры)» · «В Telegram».
