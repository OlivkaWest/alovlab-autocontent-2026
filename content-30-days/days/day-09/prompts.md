# День 9 · Промпты «Факты, а не вода» (для Perplexity)

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ТЕМА]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
Работай в Perplexity с Focus → **Web** (рынок, свежие данные) или **Academic** (исследования, закономерности).

---

## 1. Основной промпт — собрать факты с источниками
```
Ты — ресёрчер-фактчекер. Собери проверяемые факты по теме, только с источниками.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Тема: [ТЕМА]. Продукт, к которому веду: [ПРОДУКТ].

Дай 7 фактов, релевантных этой аудитории. Требования к каждому факту:
— конкретная цифра, дата, имя или место (никаких «многие», «часто», «быстро»);
— ссылка на источник и год публикации;
— приоритет первоисточникам: исследование, отчёт, гос-данные, официальная статистика;
— для рыночных и ценовых данных — источники за последние 1–2 года.

Формат: пронумерованный список. Каждая строка: факт — цифра — источник (год) — ссылка.
Не придумывай. Если проверяемого факта нет — так и напиши, не заполняй пустоту.
```

## 2. Промпт для улучшения — дожать до первоисточника
```
Вот мои факты: [ВСТАВИТЬ].
По каждому:
— найди первоисточник (само исследование/отчёт/гос-данные), а не пересказ в блоге;
— если источник старше двух лет и тема рыночная — найди свежие данные;
— уточни цифру, если она приблизительная, и дай точную со ссылкой.
Верни обновлённый список в том же формате: факт — цифра — источник (год) — ссылка.
```

## 3. Промпт для жёсткой оценки — вычистить воду в маске факта
```
Проверь мой список строго, как фактчекер, который его завернёт.
Найди и помечай:
— факты без работающей ссылки на источник;
— оценки, выданные за факт («растёт», «многие», «доказано, что») без числа;
— источники уровня «блог без первоисточника»;
— устаревшие данные, поданные как актуальные.
По каждому факту вердикт: ОСТАВИТЬ / ДОЖАТЬ / ВЫКИНУТЬ и одна строка почему.
Ничего не оставляй из вежливости.
Список: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки — три теста
```
Прогони каждый факт по трём тестам и ответь да/нет по каждому:
— Проверяемость: ссылка открывается и цифра действительно есть на источнике?
— Конкретность: есть число, дата, имя или место?
— Свежесть: источник достаточно свежий для этой темы?
Оставь только факты 3 из 3. Итог: пронумерованный чистовой лист фактуры.
Список: [ВСТАВИТЬ].
```

---

## Заполненный пример (эксперт-нутрициолог)
`[НИША]` = эксперт-нутрициолог · `[АУДИТОРИЯ]` = женщины 30–45, устали от диет, переедают вечером · `[ТЕМА]` = «почему не получается похудеть, хотя ешь вроде немного» · `[ПРОДУКТ]` = курс по осознанному питанию без ручного подсчёта калорий.

**Что вернул основной промпт после проверки ссылок (сокращённо, форма — не готовые данные для поста):**
- Люди недооценивают съеденное при записи от руки — эффект underreporting — источник: исследования пищевых дневников (открыть ссылку, сверить).
- Белок сильнее насыщает при равной калорийности — выше термический эффект пищи — источник: обзоры по TEF.
- На сверхобработанной еде при свободном доступе съедают заметно больше — контролируемое исследование NIH, K. Hall, Cell Metabolism, 2019 — открыть ссылку из выдачи и сверить цифру.

> Цифры и источники в примере показывают **форму** факта. Не копируй в свой контент — собери свои по своей теме и открой каждую ссылку: цифра живёт только на первоисточнике.
