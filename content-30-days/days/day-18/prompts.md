# День 18 · Промпты «Пакетное производство»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[РУБРИКИ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.
`[РУБРИКИ]` — твоя сетка из дня 17 (4 опоры в пропорции 2:1:1:1).

---

## 1. Основной промпт — собрать пакет недели
```
Ты — контент-стратег. Собери пакет из пяти материалов на неделю за один проход.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].
Мои рубрики и опоры: [РУБРИКИ].

Разложи неделю на пять слотов по пропорции 2:1:1:1:
— два материала Польза (приём/разбор/инструкция),
— один Смысл/позиция (взгляд, как надо и как нет),
— один Практика/кейс (что вышло в работе, с деталью),
— один Приглашение (мягкий шаг).

Для каждого слота дай:
1) день и рубрику;
2) тему с конкретным углом (не тему в лоб);
3) формат (Reels / карусель / пост);
4) хук до 9 слов.

Требования: пять материалов — пять разных ролей, ни два не про одно и то же;
живой русский язык, короткие фразы, ни одной банальной формулировки; хуки все разные.
Выведи таблицей: день | рубрика | тема+угол | формат | хук.
```

## 2. Промпт для улучшения
```
Вот мой пакет недели: [ВСТАВИТЬ]. Усиль его:
— сделай каждый хук острее и короче (до 9 слов), все пять — разные по типу;
— найди, где два материала пересекаются по смыслу, и разведи их;
— проверь, что Практика опирается на конкретную деталь, а не на общие слова.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мой пакет строго, как редактор, который его отклонит.
Найди: где два материала дублируют друг друга; где сбита пропорция 2:1:1:1;
где приглашение встречается чаще одного раза; где хук объясняет вместо того чтобы остановить;
где тема подана в лоб, как у всех.
Дай оценку 1–10 по цельности недели и по разнообразию ролей. Ничего не хвали из вежливости.
Пакет: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь пакет по чек-листу и ответь да/нет по каждому пункту:
— ровно пять материалов, пропорция 2 Польза : 1 Смысл : 1 Практика : 1 Приглашение;
— ни два материала не про одно и то же;
— все пять хуков разные по типу;
— приглашение одно, не давит;
— у каждого материала понятный формат и явный переход в Telegram.
Если где-то «нет» — перепиши этот материал.
Пакет: [ВСТАВИТЬ].
```

## Заполненный пример (эксперт-нутрициолог)
`[НИША]` = частный нутрициолог, онлайн-сопровождение · `[АУДИТОРИЯ]` = женщины 30–50, срываются с диет, устали считать калории · `[РУБРИКИ]` = Польза «Разбор тарелки», Польза «Один продукт», Смысл «Не про силу воли», Практика «Как вышло у клиента», Приглашение «Разбор питания» · `[ПРОДУКТ]` = месячное сопровождение по питанию.

**Что вернул основной промпт (сокращённо):**

| День | Рубрика | Тема + угол | Формат | Хук |
|---|---|---|---|---|
| Пн | Польза — Разбор тарелки | «Здоровый завтрак, от которого срываешься к обеду» | Reels | «Твой правильный завтрак и держит тебя до обеда» |
| Ср | Польза — Один продукт | «Творог, который мешает похудеть — читаем состав» | Карусель | «Не весь творог одинаково полезен. Проверь пачку» |
| Чт | Смысл — Не про силу воли | «Срыв — это не слабость. Это дефицит» | Пост | «Ты не безвольная. Ты недоела за день» |
| Пт | Практика — Кейс | «Убрали один перекус — ушёл вечерний жор» | Reels | «Один лишний перекус держал её на срывах» |
| Сб | Приглашение | «Разбор твоего питания за неделю» | Сторис + пост | «Покажу, где в твоём дне спрятан срыв» |

Пропорция 2:1:1:1 выдержана, приглашение одно, хуки разного типа (ошибка / разрушение мифа / разрушение мифа-снятие вины / кейс / приглашение). Собран за один проход тем, тексты — вторым проходом.
