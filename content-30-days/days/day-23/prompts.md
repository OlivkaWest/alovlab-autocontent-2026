# День 23 · Промпты «Telegram-воронка»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[МАГНИТ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — собрать воронку
```
Ты — маркетолог по автоворонкам. Собери простую Telegram-воронку под мой продукт.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ].
Лид-магнит на входе: [МАГНИТ]. Продукт, к которому ведём: [ПРОДУКТ].

Разложи путь одного человека на пять шагов:
1) ПОДПИСКА — что он видит в закрепе/описании, чтобы понять, зачем остаться.
2) КОДОВОЕ СЛОВО — какое слово он пишет в ответ и что оно запускает.
3) ЛИД-МАГНИТ — как бот отдаёт файл, какое первое сообщение.
4) ПРОГРЕВ — 3–4 темы постов, которые ведут от магнита к продукту.
5) ЗАЯВКА — какое действие предлагаем и в какой момент.

Для каждого шага: что видит человек и что происходит автоматически.
Требования: живой русский, коротко, без давления, каждый шаг тянет к следующему.
Не выдумывай цифры и сроки. Нет данных — пиши «нет данных».
```

## 2. Промпт для улучшения
```
Вот моя воронка: [ВСТАВИТЬ]. Усиль её:
— в шаге «подписка» сделай причину остаться конкретной, не «полезный контент»;
— кодовое слово сделай простым и логичным для темы;
— в прогреве убери посты, которые не двигают к продукту;
— шаг «заявка» сделай мягким и в правильный момент, не сразу.
Покажи, что изменил и почему цепочка стала крепче.
```

## 3. Промпт для жёсткой оценки
```
Оцени воронку строго, как подписчик, который дойдёт до второго шага и уйдёт. Не хвали.
Найди: где человек не поймёт, что делать; где обрыв между шагами;
где прогрев не ведёт к продукту; где заявка предлагается слишком рано или как «купи».
Дай оценку 1–10 по связности пути и назови три места обрыва.
Воронка: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь воронку по чек-листу, отвечай да/нет:
— в описании есть понятная причина остаться;
— кодовое слово простое и запускает выдачу магнита;
— каждый шаг ведёт к следующему без обрыва;
— прогрев логично доводит от магнита к продукту;
— заявка предлагается в правильный момент, без давления;
— нет выдуманных цифр и сроков.
Где «нет» — перепиши этот шаг.
Воронка: [ВСТАВИТЬ].
```

## Заполненный пример (онлайн-школа английского)
`[НИША]` = онлайн-школа английского · `[АУДИТОРИЯ]` = взрослые, боятся говорить · `[МАГНИТ]` = «10 первых фраз для любого диалога» · `[ПРОДУКТ]` = разговорный интенсив.

**Что вернул основной промпт (сокращённо):**
- Подписка: в закрепе — «Забери 10 фраз, с которых начинается разговор. Напиши ФРАЗЫ».
- Кодовое слово: `ФРАЗЫ` → бот отдаёт PDF + первое сообщение с приветствием.
- Магнит: файл + «Попробуй сегодня проговорить вслух блок 1».
- Прогрев: пост про ступор на первой фразе → пост «почему словарь не спасает» → пост-история ученика (без выдуманных цифр) → анонс интенсива.
- Заявка: «Хочешь отработать вживую? Разговорный интенсив — вот здесь» после третьего поста прогрева.
