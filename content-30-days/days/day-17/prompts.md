# День 17 · Промпты «Рубрики вместо случайностей»

Переменные: `[НИША]`, `[АУДИТОРИЯ]`, `[ПРОДУКТ]`. Копируй и подставляй своё.

---

## 1. Основной промпт — придумать рубрики под опоры
```
Ты — контент-стратег. Помоги собрать постоянные рубрики под четыре опоры контента.
Ниша: [НИША]. Аудитория: [АУДИТОРИЯ]. Продукт, к которому ведём: [ПРОДУКТ].

Четыре опоры и их работа:
1) ПОЛЬЗА — учит одному приёму, даёт зрителю результат (доля 2).
2) ПОЗИЦИЯ — заявляет принцип автора, как надо и как нет (доля 1).
3) КЕЙС — доказывает результат на конкретном случае из работы (доля 1).
4) ПРИГЛАШЕНИЕ — мягко зовёт на следующий шаг, без давления (доля 1).

Для каждой опоры дай 2–3 варианта названия рубрики.
Требования к названию: короткое (1–3 слова), узнаваемое, своё для этой ниши,
по нему сразу понятно, какую работу делает рубрика. Не «Полезное» и не «Мысли».
Под каждым названием — одной строкой задача рубрики и пример первого поста.
Язык живой, короткие фразы, без банальностей.
```

## 2. Промпт для улучшения
```
Вот мои четыре рубрики: [ВСТАВИТЬ]. Усиль их:
— сделай имена короче и узнаваемее (1–3 слова, чтобы опознавались с ходу);
— проверь, что каждая рубрика привязана к своей опоре (польза/позиция/кейс/приглашение);
— под каждой дай пример первого поста, конкретный для ниши.
Покажи, что именно изменил и почему.
```

## 3. Промпт для жёсткой оценки
```
Оцени мои рубрики строго, как редактор, который их отклонит.
Найди: где имя размытое, где рубрика по теме, а не по опоре,
где тем хватит только на 1–2 поста, где приглашение маскируется под пользу.
По каждой рубрике скажи, сколько постов из неё реально можно снять — 2 или 20.
Дай оценку 1–10 по узнаваемости и по повторяемости. Ничего не хвали из вежливости.
Рубрики: [ВСТАВИТЬ].
```

## 4. Промпт для финальной проверки
```
Проверь мою сетку рубрик и ответь да/нет по каждому пункту:
— четыре рубрики, по одной на каждую опору (польза/позиция/кейс/приглашение);
— у каждой короткое узнаваемое имя;
— из каждой рубрики можно снять минимум 10 постов;
— неделя собирается в пропорции 2:1:1:1 (2 пользы, по 1 остального);
— приглашение не чаще одного на 3–4 поста;
— есть явный переход в Telegram в рубрике-приглашении.
Если где-то «нет» — предложи, что переписать.
Сетка: [ВСТАВИТЬ].
```

---

## Заполненный пример (мастер маникюра)
`[НИША]` = частный мастер маникюра · `[АУДИТОРИЯ]` = клиентки 25–40 по городу + начинающие мастера · `[ПРОДУКТ]` = запись клиентов + мини-курс «Носибельность гель-лака».

**Что вернул основной промпт (сокращённо):**
- Польза → рубрика **«Ошибка мастера»**. Задача: учить одному приёму. Первый пост: «Почему гель-лак скалывается на третий день — дело не в лаке».
- Позиция → рубрика **«Я так не делаю»**. Задача: заявить принцип. Первый пост: «Не беру дешёвую базу, даже если просят дешевле».
- Кейс → рубрика **«До / после клиента»**. Задача: доказать результат. Первый пост: «Пришла с обломанными — разбор восстановления за две записи».
- Приглашение → рубрика **«Разбор бесплатно»**. Задача: позвать на шаг. Первый пост: «Скинь фото ногтей — разберу, что не так, в Telegram».

**Неделя по пропорции 2:1:1:1:** Пн «Ошибка мастера» · Вт «До/после клиента» · Ср «Ошибка мастера» · Чт «Я так не делаю» · Пт «Разбор бесплатно».
