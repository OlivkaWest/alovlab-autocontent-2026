# content-30-days · Программа AlovLab «Автоконтент 2026»

30-дневный путь (4 августа — 2 сентября 2026) от хаотичного использования нейросетей до собственной системы контента.

## Структура
```
content-30-days/
├── README.md
├── calendar/            # 30-day-calendar.md · weekly-roadmap.md · production-schedule.md
├── master-workbook/     # workbook.md (единая навигация по всем 30 дням)
├── weekly-checks/       # проверки недель 1–4
├── days/                # day-01 … day-30 (overview · carousel · heygen-reel · workbook · prompts · telegram-post)
└── data/                # content-plan.json (единый источник)
```

## Четыре этапа пути
1. **Неделя 1 — основа сильного контента:** аудитория, боль, идея, угол, конфликт, хук, связка.
2. **Неделя 2 — создание с ИИ:** бриф, факты, сценарий, тексты, визуал, персонаж, видео/голос/аватар.
3. **Неделя 3 — упаковка и система:** площадки, профиль, рубрики, пакетное производство, обложки, монтаж, повторное использование.
4. **Неделя 4 — воронка и монетизация:** лид-магнит, Telegram-воронка, оффер, кейс, B2B, продажа, автоматизация.
5. **Финал (дни 29–30):** разбор месяца и сборка личной системы.

## Статус
- Каркас, календарь, данные, мастер-тетрадь, проверки, график — готовы.
- **День 1 — полный пакет** (карусель, HeyGen, тетрадь, промпты, Telegram).
- Дни 2–30 — `overview.md` готов; полные пакеты собираются партиями по неделе.

Единый источник данных — `data/content-plan.json`.
